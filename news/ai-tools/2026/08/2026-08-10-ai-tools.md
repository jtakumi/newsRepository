### 1. Claude Code / v2.1.224・v2.1.225・v2.1.226

- 種別: CLI（ターミナル・コーディングエージェント／安定版）
- 関連: Anthropic / Claude / Claude Code
- 公開・更新日: US 2026-08-07（v2.1.224）／US 2026-08-08（v2.1.225・v2.1.226）＝JST 08-08〜09
- 概要: v2.1.224 で **Self-hosted environments** を追加。`claude self-hosted-runner` を実行すると、自分のマシンやコンテナが Claude Code の web / mobile / desktop セッションの実行先になる（Team・Enterprise プラン）。あわせて **`archive` プラグインソース**（git も npm も使わず zip を HTTPS で取得、任意で SHA-256 ピン留め）、**セッション間 `SendMessage`**（同一アカウントの別マシンのセッションを `ListAgents` で発見して会話）を追加。v2.1.225 は **ゲートウェイの spend-limit をクレジット警告に反映**（上限名・リセット時刻・運用者メッセージを表示）、**`claude agents` の未信頼ディレクトリで workspace trust プロンプト**、**長寿命 `CLAUDE_CODE_OAUTH_TOKEN` が短命トークンに置き換わりヘッドレスが壊れる一時 401 の修正**、macOS の MCP OAuth 401 バースト修正など。v2.1.226 は安定性・バグ修正。
- 何が便利か: 自前インフラ（社内マシン/コンテナ）をリモート実行先にできるため、**手元の秘匿環境や特定ネットワーク内でクラウド型セッションを回せる**。プラグインを **git/npm なしで zip 配布・ハッシュ検証込みで導入**できるので、社内配布やエアギャップ寄りの運用がしやすい。
- 使いどころ: 社内 GPU/専用ネットワークでのエージェント実行、CI ランナーの自前化、審査済みプラグインの zip 配布、複数マシンをまたいだセッション連携。
- 開発者にとっての価値: 実行環境とプラグイン供給を自分の管理下に置ける。spend-limit 表示や workspace trust により**チーム運用時のコスト/安全ガードレール**が明確になる。
- 注意点: Self-hosted environments は **Team・Enterprise プラン向け**。`claude self-hosted-runner` は `--base-dir` を作成/書き込みできないと起動時にエラー終了する仕様に変更済み。archive ソースの信頼性は配布元と SHA-256 ピンで担保すること。
- 公式リンク: https://code.claude.com/docs/en/changelog
- 参考リンク: https://code.claude.com/docs/en/claude-code-on-the-web
- メモ: 本リポジトリは v2.1.222 まで採用済み。v2.1.223（08-06 付、Bash 権限バイパス修正や `/review`→`/code-review` エイリアス化）は前回記事の対象外だったため、今回まとめて追随。

#### 使用例

```bash
# 更新して自前ランナーを起動（Team/Enterprise）
claude update
claude self-hosted-runner --base-dir ~/claude-runner
# ↑ 実際のフラグ/挙動は必ず公式 changelog / docs で確認すること
```

### 2. OpenAI Codex / 0.147.0

- 種別: CLI（コーディングエージェント／安定版）
- 関連: OpenAI / Codex
- 公開・更新日: US 2026-08-07（JST 08-08）
- 概要: **ポータブルな Agent Plugins**（複数カタログを横断検索してエージェントに機能を差し込む）、会話を**永続セクション化**して段階的にブラウズできる整理機能、そして **`--approve-for-me`**（自動でレビュー済み承認を有効化する CLI フラグ）を追加。プロトコル面では **MCP 2026-07-28 対応**（ページ送り discovery・マルチラウンドリクエスト）を実装。ターミナル入力保持・日本語表示・Windows プロセス処理の修正、シークレット秘匿やプラグイン分離のセキュリティ強化も含む。
- 何が便利か: **Agent Plugins でエージェントの能力をカタログから追加**でき、**`--approve-for-me` で承認待ちの手間を減らして半自動運用**しやすい。MCP 2026-07-28 対応で、ステートレス/マルチラウンドな最新 MCP サーバとつなぎやすい。
- 使いどころ: 反復的なコード修正の半自動化、MCP ツール群を束ねたエージェント、長い作業ログをセクション単位で見返すレビュー用途。
- 開発者にとっての価値: プラグイン方式で**共通のエージェント機能を配布・再利用**でき、承認フローを絞れば CI 的な自動実行に寄せられる。
- 注意点: `--approve-for-me` は**承認を自動化するため、実行内容の安全性は自分で担保**すること（重要な破壊的操作を伴うタスクでは限定的に）。また **US 08-31 に Codex 上で GPT‑5.4 / GPT‑5.4 mini が終了**予定（`gpt-5.4`→`gpt-5.6-terra`、`gpt-5.4-mini`→`gpt-5.6-luna` へ移行）。0.148.0-alpha 系は開発ビルドのため本番採用は非推奨。

- メモ: MCP 2026-07-28 は 07-28 に安定化した大型改訂（ステートレス化・ヘッダルーティング `Mcp-Method`・キャッシュ可能な list 結果など）。Codex 側の対応は 08-07 の当該リリースで入った点が今回の 24〜48h の新規性。
