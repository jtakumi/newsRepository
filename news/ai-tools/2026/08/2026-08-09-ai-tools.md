### 1. Claude Code / v2.1.224・v2.1.225・v2.1.226

- 種別: CLI（ターミナル・コーディングエージェント／安定版）
- 関連: Anthropic / Claude / Claude Code
- 公開・更新日: v2.1.224 = 2026-08-06 19:00 UTC 相当（表示 08-07 04:00 UTC、JST 08-07 13:00）、v2.1.225 = 2026-08-08 01:09 UTC（JST 10:09）、v2.1.226 = 2026-08-08 02:48 UTC（JST 11:48）
- 概要: セルフホスト実行環境、プラグイン配布経路の追加、マシンをまたぐエージェント通信、サブエージェント上限撤廃といった運用系の大型更新に、支出上限表示や信頼プロンプト、OAuth 修正が続いた安定版群。
- 何が便利か:
  - **`claude self-hosted-runner`（v2.1.224、Team／Enterprise）**: 自前インフラでランナーを立てて Claude Code を回せる。実行環境を自社管理下に置きたいチーム向け。
  - **`archive` プラグインソース（v2.1.224）**: zip 化した HTTPS URL からプラグインを導入でき、**SHA-256 でピン留め**して改ざん検知できる。社内配布や再現性のあるプラグイン管理に効く。
  - **cross-session `SendMessage`（v2.1.224）**: 別マシン上のエージェントセッションへ名前を指定してメッセージを送れる。複数マシンにまたがるエージェント連携が組める。
  - **200 サブエージェント／セッション上限の撤廃（v2.1.224）**: 大規模なファンアウト（多数の並行サブエージェント）を上限に阻まれず実行できる。
  - **ゲートウェイ支出上限を使用量警告に表示（v2.1.225）**: 上限額とリセット時刻つきで警告が出るため、コスト超過に気づきやすい。
  - **`claude agents` の workspace trust プロンプト（v2.1.225）**: 未信頼ディレクトリでのエージェント起動時に信頼確認が入り、意図しない実行を防ぐ。
  - OAuth トークン差し替え時の一時的 401、macOS の MCP OAuth サーバのバースト 401、ヘッドレスでのクロスセッションメッセージ滞留などを修正（v2.1.225）。v2.1.226 はさらなるバグ修正と安定化。
- 使いどころ:
  - 実行環境を自社管理したい、あるいは**プラグインを検証済みハッシュで固定配布したい**チーム運用。
  - 多数のサブエージェントを一気に走らせる**大規模な並行処理**や、複数マシンをまたぐエージェント構成。
- 開発者にとっての価値: `npm i -g @anthropic-ai/claude-code` の 1 コマンドで更新でき、**配布・実行・連携の運用面が一段強化**された。特に archive ソースの SHA-256 ピン留めと信頼プロンプトはサプライチェーン／誤実行の観点で実用的。
- 注意点: `self-hosted-runner` は Team／Enterprise プラン向け機能。サブエージェント上限撤廃は使い方次第でトークン消費が急増し得るため、コスト設計とあわせて運用すること。
