### 2. Ollama / v0.32.7・v0.32.8・v0.32.9（ローカル・エージェント向けモデル追加）

- 種別: OSS（ローカル LLM ランタイム）＋ モデル追加
- 関連: Ollama / ローカルLLM / エージェント
- 公開・更新日: v0.32.7 = 2026-08-10 10:49 UTC（JST 19:49）、v0.32.8 = 2026-08-10 23:49 UTC（JST 08-11 08:49）、v0.32.9 = 2026-08-11 13:23 UTC（JST 08-11 22:23）
- 概要: ローカル実行を前提とした 30B 級のエージェント向けモデルを 2 本追加。まず MLX（Apple Silicon）から提供し、順次プラットフォームを拡大する流れ。
- 何が便利か:
  - **Muse Glimmer（v0.32.7）**: 30B のマルチモーダルモデル。ローカルで動くエージェント用途を想定。まず Ollama の MLX エンジン（Apple Silicon）で提供、以降 v0.32.8 で提供プラットフォームを拡大。
  - **NVIDIA Nemotron 3.5 Lightning（v0.32.9）**: 30B の MoE（アクティブ 3B）。Nemotron 3 アーキテクチャ対応を追加。アクティブパラメータが小さく、ローカルでの推論負荷を抑えつつエージェント処理を回す狙い。

  - MoE でアクティブ 3B の Nemotron 3.5 Lightning は、**ローカルマシンのリソースを抑えつつツール実行を伴うワークフロー**に向く。
- 開発者にとっての価値: OpenAI 互換 API として叩けるローカルランタイムに、エージェント用途を明示した 30B モデルが増えたことで、**ローカル→クラウドの切替を前提にした開発・検証**の選択肢が広がる。
- 注意点: 初期提供は MLX（Apple Silicon）中心で、他プラットフォームは順次対応。モデル名・提供形態は Ollama のリリースノート表記に準拠（ダウンロード容量・VRAM 要件は各自の環境で要確認）。

### 3. LiteLLM / v1.96.0

- 種別: OSS（LLM ゲートウェイ／プロキシ・Python SDK）
- 関連: OpenAI / Anthropic / Vertex AI / Bedrock ほかマルチプロバイダ・MCP
- 公開・更新日: 2026-08-10 22:25 UTC（JST 08-11 07:25、安定版）。バックポート修正の v1.95.1／v1.96.2 は 2026-08-11 22:08–22:09 UTC（JST 08-12 07:08–07:09）
- 概要: 100 以上の LLM プロバイダを OpenAI 互換の単一 API で束ねるゲートウェイの更新。ルーティング、MCP 連携、設定同期、UI の強化が中心。
- 何が便利か:
  - **Auto-Router 専用タブ＋直前ターン評価**: Models + Endpoints に Auto-Router 専用画面を追加。分類器が直前ターンのコンテキストを受け取り、アシスタント側ターンも評価できる。ティア選択の理由が spend logs に残る。
  - **MCP 連携の強化**: OAuth フローをサーバ単位の MCP URL パスへ拡張、ツール権限（entitlements）を全ディスパッチ経路で強制、**MCP ツール結果に対する post-call ガードレールでスキャン・マスキング**が可能に。
  - **Redis pub/sub による Pod 間設定同期**: マルチ Pod 運用で設定を揃えられる。`general_settings` で DB ステートメント／ロック時間を制限。
  - **プロバイダ更新**: Vertex AI のコンテキストキャッシュ改善・モデル別 GCS バケット対応、Anthropic の混在コンテンツチャンクのストリーム処理改善、Bedrock の AssumeRole 認証キャッシュ。
- 使いどころ:
  - 複数プロバイダを 1 ゲートウェイに束ね、**MCP ツールを含む経路で権限とガードレールを一元管理**したいチーム。
  - **マルチ Pod でプロキシを冗長運用**し、設定を同期したいプラットフォーム運用。
- 開発者にとっての価値: エージェントが叩く MCP ツールの結果にまでガードレールを掛けられる点は、**エージェント運用のセキュリティ・コンプライアンス**面で効く。ルーティングの可観測性（選択理由のログ化）も運用に有用。
- 注意点: 破壊的変更として **Team key の予算強制が削除**、モックテスト用パラメータが単一の設定フラグ配下に集約された。既存設定を使っている場合は移行確認が必要。
- 公式リンク: https://github.com/BerriAI/litellm/releases/tag/v1.96.0
- 参考リンク: https://github.com/BerriAI/litellm/releases
- メモ: 前回採用の v1.95.0 からの更新。08-12 のバックポート修正（v1.95.1／v1.96.2）も同時に確認。
