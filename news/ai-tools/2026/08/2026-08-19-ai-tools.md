### 1. Claude Code / v2.1.235

- 種別: CLI（ターミナル・コーディングエージェント／安定版）
- 関連: Anthropic / Claude / Claude Code
- 公開・更新日: 2026-08-18 20:38 UTC（JST 2026-08-19 05:38）
- 概要: 前日の v2.1.234 に続く保守中心の安定版更新。スペルチェック設定の追加、キャッシュ無効化・表示崩れの修正、クラウドセッションのリソース改善など、日常運用の細かな品質改善がまとまっている。
- 何が便利か:
  - **プロンプト入力のスペルチェック（`spellcheck` 設定）**: aspell/hunspell/ispell を使って入力中のスペルミスに下線を表示。長い指示文を書くときのタイプミスに気づきやすくなる（オプトイン設定）。
  - **言語サーバ切断時のキャッシュ無効化バグ修正**: LSP が切断・再接続したときにプロンプトキャッシュ全体が無効化されてしまう問題を修正。大きなコンテキストを扱う作業で、無駄な再送・コスト増を防げる。
  - **バックグラウンドのクラウドセッションのメモリ／CPU 改善**: バックグラウンド実行時のリソース消費を抑制。複数セッションや長時間の常駐で効く。
  - **表示・入力まわりの修正**: 深さ3以上のネスト Markdown リストの整列崩れ、複数行プロンプトでのハイライトずれ、権限プロンプトでの Shift+Tab の誤動作、VSCode タブのフォーカス飛びなどを修正。
- 使いどころ:
  - 前日 v2.1.234（GitLab MR 連携・上限リセット自動継続・NT パス拒否のセキュリティ強化）を入れた利用者が、続けて表示・キャッシュまわりの安定性を上げたいケース。
  - **大きなコンテキスト＋言語サーバを併用する作業**で、キャッシュ無効化による再処理コストが気になっていた人。
- 開発者にとっての価値: `npm i -g @anthropic-ai/claude-code` の 1 コマンドで更新でき、今日すぐ試せる。新機能より品質・安定性寄りだが、LSP 切断時のキャッシュ無効化修正は**トークンコストに直結する実利的な修正**。
- 注意点: スペルチェックは既定オフのオプトイン。辞書バックエンド（aspell/hunspell/ispell）が環境に必要。破壊的変更は特になし。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.235
- 参考リンク: https://github.com/anthropics/claude-code/releases / https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- メモ: 本リポジトリは前日記事（2026-08-18）で v2.1.234 まで採用済み。v2.1.235 を新規採用。

#### 使用例

```bash
# 更新してバージョン確認
npm install -g @anthropic-ai/claude-code
claude --version   # 2.1.235 を確認

# スペルチェックを有効化（オプトイン、/config から設定）
```

### 3. Cursor / Origin（エージェント志向のコードホスティング）

- 種別: Webサービス＋CLI（コードホスティング／早期ベータ）
- 関連: Cursor / GitHub 代替 / コーディングエージェント
- 公開・更新日: 2026-08-17（有料プランへの早期ベータ提供開始）
- 概要: Cursor が「エージェント規模（agent scale）」向けを掲げるコードホスティングプラットフォーム Origin を発表・提供開始。リポジトリ、プルリクエスト、コードブラウズ、GitHub 同期、Cursor エージェントとの統合を備え、デスクトップクライアントの新タブと専用 CLI から操作できる。
- 何が便利か:
  - **GitHub 同期で低摩擦に試せる**: 既存の GitHub リポジトリを同期して取り込み、どこまで Origin に移すかを段階的に判断できる。いきなり乗り換える必要がない。
  - **エージェント統合**: 保管・レビュー・マージと、Cursor エージェントによるプロジェクト横断の作業依頼を 1 か所で回せる。
  - **CI／デプロイ連携**: Vercel、Buildkite、Depot などの CI／デプロイプロバイダとの統合をうたう。
  - **CLI での操作**: `+New` でリポジトリ作成後、CLI のインストール手順・clone/push コマンドが案内される。
- 使いどころ:
  - Cursor を主エディタにしていて、**PR レビューやマージまでエージェント前提のワークフローに寄せたい**個人・チームの検証用途。
  - GitHub をメインに残しつつ、Origin を同期先として**部分的に試す**構成。
- 開発者にとっての価値: AI エディタベンダによる本格的な git ホスティング参入で、「エージェントが大量に読み書きする前提」で設計された点が既存ホスティングとの差別化ポイント。GitHub 同期があるため試用コストは低い。
- 注意点:
  - **早期ベータ**であり、有料プラン（Pro/Teams/Enterprise）限定。無料プランは対象外、Enterprise は管理者がオプトアウト可能。
  - **データ取り扱い条項の不透明さが複数メディアで指摘されている**。業務・機密コードの投入は規約と保存先を確認してから慎重に判断すること。
  - Cursor 公式チェンジログ（`cursor.com/changelog/origin-code-hosting`）は本環境から直接取得できず、日付・機能は複数の独立メディア報道で裏取りした（公式ページ URL は下記）。
- 公式リンク: https://cursor.com/changelog/origin-code-hosting
- 参考リンク: https://www.testingcatalog.com/cursor-begins-origin-code-hosting-rollout-for-paid-plans/ / https://techstartups.com/2026/08/17/cursor-launches-origin-a-github-rival-built-for-ai-coding-agents/
- メモ: 一次情報（Cursor 公式ページ）が直接取得できなかったため、複数の独立系メディアで日付・提供範囲・機能を相互確認。データ条項の懸念は注意点として明記。
