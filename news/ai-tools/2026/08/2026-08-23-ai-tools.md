## 今日の注目

### 1. Claude Code / v2.1.239（+ v2.1.237・v2.1.238・v2.1.240）

- 種別: CLI（ターミナル・コーディングエージェント／安定版）
- 関連: Anthropic / Claude / Claude Code
- 公開・更新日: v2.1.239 = 2026-08-21 19:54 UTC（JST 2026-08-22 04:54）／最新 v2.1.240 = 2026-08-22 14:45 UTC（JST 2026-08-22 23:45）
- 概要: v2.1.236 以降に積まれた安定版更新。コスト可視化、Python SDK 移行支援、claude.ai 同期プラグインの扱い、Alpine/musl サポートなど、日常運用に効く実務系の追加が中心。
- 何が便利か:
  - **`/claude-api upgrade`**: 既存の Python プロジェクトを `anthropic` 0.x → 1.x へ移行する補助コマンド。1.x ではタイムアウトが `httpx.Timeout` ではなく `anthropic.Timeout` になるなどの破壊的変更を含め、スキルの Python リファレンスも 1.x 準拠に更新済み。SDK メジャーアップの手戻りを減らせる。
  - **コスト見積もりの精緻化**: `/cost`・ステータスライン・`--max-budget-usd` が、データ所在地（data-residency）ワークスペースの US 限定推論に対する 1.1× 上乗せを反映。使用量上限メッセージにセッション／週次リセット時刻も表示。予算管理の見積もりずれが減る。
  - **claude.ai 同期プラグイン**: 同期されたプラグインが `name@synced` として表示され、`claude plugin enable/disable <name>@synced` で管理可能。自分でインストールした同名プラグインは上書きされない。
  - **Alpine/musl ビルド**: 画像貼り付け・クリップボード・音声キャプチャのネイティブアドオンがロードされるようになり、musl ビルドのバイナリへ切替（従来 glibc ビルドはランタイムに拒否されていた）。コンテナ／軽量ディストロでの利用が実用域に。
- 使いどころ: `anthropic` SDK を使う既存 Python リポジトリの一括アップグレード、予算を明示した長時間セッションのコスト管理、Alpine ベースの CI/コンテナでの Claude Code 実行。
- 開発者にとっての価値: SDK 移行という「面倒だが避けられない作業」をコマンド化。コンテナ運用の裾野が広がる。
- 注意点: US 限定推論の 1.1× はデータ所在地ワークスペース向けの仕様。`/claude-api upgrade` は自動移行の補助であり、破壊的変更の最終確認は自分で行うこと。最新 v2.1.240 自体は「バグ修正・信頼性改善」中心。
- 公式リンク: https://github.com/anthropics/claude-code/releases
- 参考リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.239
- メモ: v2.1.237 で LLM ゲートウェイ／カスタム base URL 向けプロンプトキャッシュ修正と "Concise" 出力スタイル、v2.1.238 で `keybindingFlavor` 設定やプラグインマーケットプレイスの `headersHelper` 追加も入っている。

#### 使用例

```bash
# 既存 Python プロジェクトを anthropic 0.x -> 1.x へ移行
claude
# セッション内で:
/claude-api upgrade

# 予算上限を明示してセッションを開始（コスト見積もりに反映される）
claude --max-budget-usd 5
```

### 2. Ollama / v0.33.0-rc2（Ollama ↔ Claude 連携）

- 種別: OSS / ローカル LLM ランタイム（プレリリース RC）
- 関連: Ollama / Claude / Anthropic / ローカル LLM
- 公開・更新日: v0.33.0-rc0 = 2026-08-21 22:04 UTC（JST 08-22 07:04）／最新 rc2 = 2026-08-22 18:51 UTC（JST 08-23 03:51、プレリリース）
- 概要: v0.33.0 RC の目玉は Claude（Claude デスクトップ）との連携。メニューバー UI からローカルモデルを Claude 側で使えるように切り替えられ、接続まわりの UX と、エージェント系クライアント向けのプレフィル／キャッシュ挙動を改善している。
- 何が便利か:
  - **モデル単位の ON/OFF**: メニューバーから、どの Ollama モデルを Claude で使えるようにするかを個別に切替。クラウドモデルは認証済みのときだけ表示。
  - **「Apps」ビュー**: アプリ連携用の新セクションで、接続コマンドをコピーして使える。
  - **キャッシュ／プレフィル改善**: 長いプレフィルをキャンセルするエージェントクライアントのハング解消、無効なリストア点の削減、**Claude Code のトークンカウントダウン用システムメッセージが毎リクエストで KV キャッシュを壊す問題を無効化**。ローカルモデルをエージェントで回す際の再送・キャッシュ効率が上がる。
- 使いどころ: 手元の Ollama モデルを Claude デスクトップから呼び出すハイブリッド運用、ローカルモデル＋エージェント（Cline/Claude Code 等）でのプレフィル多用ワークフロー。
- 開発者にとっての価値: 「ローカルモデルをクラウド製 UI/エージェントから使う」導線が公式に整い、機密データをローカルに留めつつ使い慣れた UI を使える。
- 注意点: **v0.33.0-rc0〜rc2 はプレリリース**。本番運用は安定版 v0.32.15 を推奨。Claude 連携は Claude デスクトップ側の対応状況にも依存する。
- 公式リンク: https://github.com/ollama/ollama/releases/tag/v0.33.0-rc2
- 参考リンク: https://github.com/ollama/ollama/releases/tag/v0.32.15
- メモ: 安定版 v0.32.15（JST 08-21 03:47）はメタデータキャッシュで TTFT を約 995ms→524ms に短縮、初回オンボーディングフロー刷新、ストリーム途中で無応答になるパーサーエラー修正などを含む。

### 3. Cline / v4.1.13・CLI v3.0.57（企業向け MCP 制御を強化）

- 種別: OSS / VS Code 拡張＋CLI（コーディングエージェント／安定版）
- 関連: Cline / MCP / OpenAI 互換モデル
- 公開・更新日: v4.1.13 = 2026-08-22 20:23 UTC（JST 08-23 05:23）／CLI v3.0.57 = 2026-08-22 20:25 UTC（JST 08-23 05:25）。系列は v4.1.11（JST 08-21 14:30）から。
- 概要: MCP マーケットプレイスの企業向けガバナンス強化と、OpenAI 互換モデルの tool-calling 復旧、トレーサビリティ向上を含む安定版更新。
- 何が便利か:
  - **企業向け MCP 制御**: リモートで無効化された MCP サーバをマーケットプレイスから非表示にし、アクセスを許可リスト（allowlist）サーバに限定できる。組織で使える MCP サーバを中央管理したいケースに効く。
  - **tool-calling 復旧**: capability がフラグ由来の推論で空になっていた OpenAI 互換モデル（カスタムエンドポイント含む）で、ツール呼び出しが再び機能。
  - **観測性向上**: Langfuse トレースにセッション／クライアント ID を付与。誰の・どのセッションの実行かを追いやすい。
- 使いどころ: 社内で MCP サーバの利用範囲を絞りたいチーム運用、自前 or サードパーティの OpenAI 互換モデルを Cline で使う構成、Langfuse でエージェント実行を監査する運用。
- 開発者にとっての価値: 個人だけでなくチーム／企業導入時のガバナンスと再現性の課題に踏み込んだ更新。OpenAI 互換モデル利用者には実害のある回帰の修正。
- 注意点: 企業向け MCP 制御はリモート設定（管理側）ありきの機能。tool-calling 復旧は「フラグから capability を推論して空になっていた」構成向けの修正。
- 公式リンク: https://github.com/cline/cline/releases
- 参考リンク: https://github.com/cline/cline/releases/tag/v4.1.13
- メモ: v4.1.12（JST 08-22 07:39）で MCP の allowlist / 非表示制御が入り、v4.1.13 で OpenAI 互換モデルの tool-calling 復旧と Hub バックドセッションの再起動維持（イベント重複配信の回避）が入った。
