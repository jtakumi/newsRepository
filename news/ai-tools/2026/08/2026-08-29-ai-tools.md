### 1. Claude Code / v2.1.251（モデル切替フック・支出上限・`--restricted`）

- 種別: CLI（ターミナル・コーディングエージェント／安定版）
- 関連: Anthropic / Claude / Claude Code
- 公開・更新日: 2026-08-28 18:19 UTC（JST 2026-08-29 03:19）※ v2.1.251。v2.1.248 は 2026-08-27 22:12 UTC（JST 08-28 07:12）、v2.1.250 は 2026-08-28 00:49 UTC（JST 08-28 09:49）
- 概要: 前回記事の v2.1.247 から v2.1.248 → v2.1.250 → v2.1.251 へ安定版が前進。運用制御・コスト可視化・セキュリティに効く**開発者向けの実務機能**がまとまって入った。
- 何が便利か:
  - **`PreModelSwitch` / `PostModelSwitch` フック（v2.1.251）**: モデル切り替えをブロック・確認・注記できる。`SessionStart` の resume フックはセッションの陳腐化度合いと再キャッシュ推定コストを受け取れる。モデル選択をポリシーで縛りたいチームに効く。
  - **`/usage` の支出上限バー・`/cost` のキャッシュ統計（v2.1.251）**: `/usage` に支出上限バー、`/cost` に**セッション単位のプロンプトキャッシュ統計（ヒット率・ミス・再キャッシュされたトークン・warm/cold）**を追加。ステータスライン用に `prompt_cache` オブジェクトも公開。キャッシュ効率を数値で見ながらプロンプト設計を詰められる。
  - **`--restricted` モード（v2.1.248）**: `--restricted`（または `CLAUDE_CODE_RESTRICTED=1`）で、コマンド／コード実行系ツールと WebFetch（明示指定を除く）を外し、ファイルツールを作業ディレクトリ内に限定、`bypassPermissions` を拒否し user/project/local の設定ファイルを無視。CI や共有環境で**権限を絞って安全に走らせたい**とき。
  - **`experimental.cacheTtl`（v2.1.248）**: エージェント frontmatter で `"5m"` / `"1h"` など**エージェント単位のプロンプトキャッシュ TTL** を設定できる。
  - **セッション間通信 `SendMessage` / `ListAgents`（v2.1.248）**: 同一マシン上の別セッションへメッセージ送信・一覧取得。Bedrock / Vertex / Foundry やテレメトリ無効時にも利用可。マルチセッションでの受け渡しに使える。
  - **フォアグラウンドサブエージェントのライブストリーミング（v2.1.251）**: フォアグラウンドのサブエージェントのツール呼び出し・結果を Remote Control クライアントへライブ配信（バックグラウンドは状態のみ）。
  - **セキュリティ修正（v2.1.251）**: Read/Write/Edit のシンボリックリンク差し替え、マーケットプレイス・プラグインのパス・トラバーサル、Grep/Glob がシンボリックリンク経由で Read の deny ルールを適用しない問題、詳細トレース／生 API ログの設定漏れなどを修正。
- 使いどころ:
  - **モデル切り替えを組織ポリシーで制御**したい、あるいは切替時にコスト・注意を挟みたいチーム。
  - Claude API のコストを**キャッシュ効率の実測値を見ながら**下げたいとき（`/cost` の新統計）。
  - CI・共有マシン・レビュー用途で**権限を絞ったエージェント実行**をしたいとき（`--restricted`）。
- 開発者にとっての価値: `npm i -g @anthropic-ai/claude-code` の 1 コマンドで更新でき、今日すぐ試せる安定版。セキュリティ修正が含まれるため、旧版利用者は更新推奨。
- 注意点: `--restricted` は明示的に機能を外すため、既存のワークフローが command 実行や WebFetch に依存していると動かなくなる点に注意。`PreModelSwitch` などフックは設定が必要。破壊的変更は特に告知されていないが、リリースノートで各自確認のこと。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.251
- 参考リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.248 / https://github.com/anthropics/claude-code/releases / https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- メモ: 前回記事（08-28）は v2.1.247 まで採用済み。v2.1.248 / v2.1.250 / v2.1.251 を新規採用。

### 3. Cline Desktop / desktop-v0.0.20（Windows 対応・自動更新）

- 種別: デスクトップアプリ（安定版）
- 関連: Cline / マルチプロバイダ対応コーディングエージェント
- 公開・更新日: 2026-08-28 01:33 UTC（JST 2026-08-28 10:33）
- 概要: 前回記事の desktop-v0.0.19 に続くデスクトップ更新。最大の目玉は **Windows 対応**の追加。
- 何が便利か:
  - **Windows 対応**: **コード署名済みの x64 インストーラ**を提供し、macOS と同じ更新フィードで**自動更新**。バックグラウンドプロセスのコンソール窓を非表示化し、更新はバックグラウンドで静かにダウンロード。これまで macOS 中心だったデスクトップ版を Windows でも常用しやすくなった。
  - **画像のインライン表示＋カルーセル**: base64 の生テキストではなく画像をインライン表示し、複数画像をカルーセルで送れる。
  - **セッション検索の強化**: 全インデックス履歴を対象に、サーバ側ランキング付きで検索。過去セッションからの掘り起こしがしやすい。
  - **スケジュールタスクの集約**: スケジュール済みタスクをユーザレベルの単一ディレクトリ `~/.cline/schedules` に集約。アプリ更新後にタスクが消える問題も修正。
  - **その他修正**: ポート 1455 使用時の OpenAI Codex サインイン失敗、チェックポイント復元時のワークスペースリセット、グローバルルールの探索先（`~/Cline/Rules`）などを修正。
- 使いどころ:
  - **Windows で Cline デスクトップを常用**したい開発者（署名済みインストーラ＋自動更新で導入・維持が楽）。
  - 画像を多用する作業や、**過去セッションを検索して再利用**したい運用。
- 開発者にとっての価値: マルチプロバイダを 1 つのデスクトップ UI で扱う構成が Windows でも組めるようになり、対象ユーザ層が広がった。自動更新で維持コストも低い。
- 注意点: デスクトップ版は依然 v0.0.x の初期バージョン帯。VS Code 拡張（v4.1.x）・CLI（v3.0.x）・SDK（v0.0.x）とはバージョン系列が分かれる。Windows インストーラは x64 が対象。
- 公式リンク: https://github.com/cline/cline/releases/tag/desktop-v0.0.20
- 参考リンク: https://github.com/cline/cline/releases
- メモ: 前回記事は desktop-v0.0.19 まで採用済み。desktop-v0.0.20 を新規採用。
