### 1. Claude Code / v2.1.236

- 種別: CLI（ターミナル・コーディングエージェント／安定版）
- 関連: Anthropic / Claude / Claude Code
- 公開・更新日: 2026-08-19 20:02 UTC（JST 2026-08-20 05:02）
- 概要: 前日の v2.1.235 に続く安定版更新。既定モデルの固定、セッション間通知、macOS サンドボックスの秘匿ファイル保護強化など、日常運用に効く新機能と多数のバグ修正がまとまっている。
- 何が便利か:
  - **`ANTHROPIC_DEFAULT_MODEL` 環境変数**: 新規セッションの既定モデルを環境変数で固定できる（`/model` ピッカーで随時上書き可）。チームやスクリプトで「起動時は必ずこのモデル」を強制でき、モデル指定の取り違えを防げる。
  - **`notify_when_idle`（セッション間 `SendMessage`）**: 別の Claude Code セッションがアイドルになったら通知を受け取れる（macOS/Linux）。長時間のバックグラウンド作業を並行で回すときに「そろそろ空いた」を取りこぼさない。
  - **macOS サンドボックスのワイルドカード read-deny 優先**: `**/.env` のような拒否ルールが許可領域の内側でも優先され、**ファイルのリネームによる回避も防止**。秘匿ファイルをエージェントに読ませない運用が固くなる。
  - **描画・UI の堅牢化**: フルスクリーン描画がクラッシュしても従来レンダラへフォールバック、`/model` ピッカーが端末より高くならずスクロール表示、tmux のタブタイトル飛び・iTerm2 のマスコット描画などを修正。起動性能も改善。
  - **アクセシビリティ**: VSCode でトランスクリプトのスクリーンリーダー対応（読み上げ・ターン移動）。
- 使いどころ:
  - 前日 v2.1.235（スペルチェック・LSP 切断時キャッシュ無効化修正）を入れた利用者が、続けて**モデル固定とサンドボックス保護の強化**を取り込みたいケース。
  - 複数セッションを並行運用していて、**アイドル通知で手戻りを減らしたい**人。
  - `.env` などの秘匿ファイルをエージェントに触らせたくない、セキュリティ要件のある環境。
- 開発者にとっての価値: `npm i -g @anthropic-ai/claude-code` の 1 コマンドで更新でき、今日すぐ試せる。`ANTHROPIC_DEFAULT_MODEL` とサンドボックスの `.env` 保護は、チーム運用の再現性とセキュリティに直結する実利的な追加。
- 注意点: `notify_when_idle` は macOS/Linux 限定。サンドボックス強化は macOS 向けの挙動。破壊的変更は特に告知されていないが、既定モデルを環境変数で固定した場合はセッション起動時の挙動が変わる点に留意。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.236
- 参考リンク: https://github.com/anthropics/claude-code/releases / https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- メモ: 本リポジトリは前日記事（2026-08-19）で v2.1.235 まで採用済み。v2.1.236 を新規採用。

#### 使用例

```bash
# 更新してバージョン確認
npm install -g @anthropic-ai/claude-code
claude --version   # 2.1.236 を確認

# 新規セッションの既定モデルを環境変数で固定（例）
export ANTHROPIC_DEFAULT_MODEL="claude-opus-4-8"
claude   # 起動時にこのモデルが既定になる（/model で上書き可）
```
