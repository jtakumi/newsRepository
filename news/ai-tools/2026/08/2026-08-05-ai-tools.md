### 1. Claude Code / v2.1.221

- 種別: CLI（ターミナル・コーディングエージェント）
- 関連: Claude / Anthropic
- 公開・更新日: 2026-08-04（00:14 UTC / JST 09:14）
- 概要: ツール実行表示を折りたためる Focus View と、サンドボックスの認証情報マスキングを入れた更新。前回 v2.1.220（JST 07-25）以来の新規。
- 何が便利か:
  - **Focus View（`Ctrl+Alt+F`／「Toggle Focus view」）**: ツール実行の冗長なログをターンごとのサマリに畳み、実行中ツールのライブインジケータだけを表示。長い自律実行でも進行が追いやすくなる。
  - **サンドボックスの認証情報マスキング（`mode: "mask"`、Linux/WSL）**: サンドボックス内のコマンドには認証情報ファイルの **sentinel コピー** を読ませ、egress（外向き通信）時にプロキシが実値へ置換。`extract` 正規表現で部分抽出も可能（macOS は `deny` にフォールバック）。**鍵をサンドボックス内に露出せず外部 API を叩ける**。
  - **セキュリティ/権限修正**: Bash の `[[ ]]` 正規表現による権限チェック回避、PowerShell の引用符入りパスの権限チェック、Windows での Bedrock AWS SSO 認証を修正。
  - print モードで `--mcp-config` の MCP が接続されない不具合、Esc→再送で @-mention ファイルが落ちる不具合、thinking トグルが効かない不具合などを修正。`/status` でセッション種別（interactive/attached/unattended）を表示。
- 使いどころ:
  - 自律タスクを回しつつ、**画面はサマリ表示で進行だけ監視**したい日常運用（Focus View）。
  - CI/サンドボックス実行で **API キーを実値のまま渡したくない**が外部サービスは呼びたい構成（credential masking）。
- 開発者にとっての価値: `npm i -g @anthropic-ai/claude-code` で入る主力 CLI に、**実行表示の整理**と**サンドボックス鍵マスキング**という運用直結の機能が入った。特にマスキングは自動化パイプラインでの鍵漏えい対策として実用的。
- 注意点: credential masking は Linux/WSL 対象で macOS は `deny` フォールバック。マスキングは egress プロキシ前提のため、サンドボックス設定の理解が必要。バージョンは高頻度で更新されるため導入時は最新の CHANGELOG を確認。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.221
- 参考リンク: https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- メモ: 前回採用の v2.1.220（JST 07-25）以降で確認できた最初の新規リリース。Focus View と credential masking を新規採用理由とした。

#### 使用例

```bash
# 更新
npm install -g @anthropic-ai/claude-code@latest

# 起動後、Focus View をトグル
#   Ctrl+Alt+F （または コマンドパレットで "Claude Code: Toggle Focus view"）

# セッション種別の確認
/status
```

### 3. Qwen Code / v0.21.5

- 種別: CLI（ターミナル・コーディングエージェント／Gemini CLI 派生）
- 関連: Qwen / OpenAI 互換プロバイダ対応 CLI
- 公開・更新日: 2026-08-04（安定版）
- 概要: MCP の再送安全策とツール実行の結果トラッキング、finding 中心のレビュー表示を入れた安定版更新。前回（08-03）は v0.21.4 まで。
- 何が便利か:
  - **MCP の再送安全策**: 接続断が起きたあと、**idempotent と明示されていないツール呼び出しは再送しない**ようにし、二重実行による副作用を防止。
  - **ツール実行の結果トラッキング**: invocation の **成功／失敗／キャンセル**を区別して記録。エージェントの挙動把握・デバッグがしやすくなる。
  - **finding 中心の `/review` 表示**: 指摘を **severity・confidence・修正案（suggested fix）** 付きの構造化ビューで提示。レビュー結果を優先度順に扱える。
  - **macOS の移行ブリッジ**: Electron デスクトップアプリから新しい Tauri シェルへ移る**オプトインの一回限りアップデート橋渡し**を追加。
  - Goal モードで証拠カタログ枯渇後の無限リトライを停止、Qwen 3.8 の reasoning effort レベル対応。
- 使いどころ:
  - Qwen 系や OpenAI 互換 API を使い、**ターミナルからコード生成・レビュー・修正**を回す個人開発。
  - MCP ツールを多用し、**接続断時の二重実行を避けたい**エージェント運用。
- 開発者にとっての価値: `npm install -g` で入る軽量 CLI に、MCP 安全策・実行トラッキング・構造化レビューが揃い、**実装→レビュー→修正**を副作用リスクを抑えつつ CLI 完結で回せる。
- 注意点: 利用にはプロバイダ設定（`/auth`）が必要。macOS の Tauri 移行はオプトイン。挙動はモデル・プロバイダ側の対応にも依存。
- 公式リンク: https://github.com/QwenLM/qwen-code/releases/tag/v0.21.5
- 参考リンク: https://github.com/QwenLM/qwen-code
- メモ: 前回記事（08-03）採用の v0.21.4 以降の増分 v0.21.5 を新規採用。MCP 再送安全策と finding 中心レビューを採用理由とした。

#### 使用例

```bash
# インストール／更新
npm install -g @qwen-code/qwen-code@latest

# 起動 → プロバイダ/APIキー設定 → 変更レビュー（severity/confidence 付き）
qwen
/auth
/review
```
