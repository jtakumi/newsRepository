# 2026-08-07 AI Tools News

## 今日の注目

### 1. Claude Code / v2.1.223 / v2.1.224

- 種別: CLI
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: `v2.1.223` は 2026-08-05（UTC 22:51 / JST 08-06 07:51）、`v2.1.224` は 2026-08-07（UTC 01:36 / JST 10:36）
- 概要: `v2.1.223` はセキュリティ修正が中心で、Bash の権限バイパス、タブや不可視 Unicode のパディングによる承認ダイアログの隠蔽、ワークフロースクリプトが動的 `import()` でサンドボックス外のコードを実行できる問題、エージェント定義の `bypassPermissions` が組織の bypass 無効ポリシーを無視する問題を修正した。ほかに、`strictKnownMarketplaces`/`blockedMarketplaces` で `"owner/*"` による org 単位の許可・ブロック、クラウドセッションでの `/teleport` ヒント、`CLAUDE_CODE_DISABLE_1M_CONTEXT` が 1M ネイティブの全 Claude モデルを 200K に抑える変更、`/review` を `/code-review` のエイリアスにして直近の effort レベルを再利用する変更などが入った。`v2.1.224` は、自分のマシンやコンテナで Claude Code の Web／モバイル／デスクトップのセッションを動かせる**セルフホスト環境**（Team／Enterprise）、HTTPS の zip から入れる `archive` プラグインソース（SHA-256 固定可）、複数マシンのセッション同士がメッセージを送り合う**クロスセッション `SendMessage`**（`ListAgents` で探索、macOS/Linux）、`crossSessionInbound`／`dialogExpiry` 設定、Bedrock の `ANTHROPIC_BEDROCK_REGION_PREFIX` を追加。1 セッション 200 サブエージェントの生成上限も撤廃された。
- 何が便利か: 承認ダイアログとサンドボックスの「見えない抜け穴」が塞がれ、権限承認を人が見て判断する運用の信頼性が上がる。`v2.1.224` ではセッション間連携とセルフホスト実行が使えるようになり、社内ネットワークや専用マシンでの実行基盤を組みやすくなる。
- 使いどころ: 社内ネットワーク内の計算資源で Claude Code を動かしたい Team／Enterprise、複数マシンのセッションを連携させたいケース、プラグインを社内配布したいケース。
- 開発者にとっての価値: `v2.1.223` は権限バイパス系の修正を複数含むため、承認フローに依存する運用は早めの更新が望ましい。セルフホスト環境とクロスセッション連携は、エージェント運用の「どこで動かすか」の選択肢を広げる。
- 注意点: クロスセッションのメッセージは、権限をバイパスして動くセッション宛ての場合は承認待ちで保留される設計（`crossSessionInbound`）。サンドボックス認証情報マスキングの一部オプションはネットワーク設定が前提。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.223 / https://github.com/anthropics/claude-code/releases/tag/v2.1.224
- 参考リンク: https://code.claude.com/docs/en/changelog
- メモ: `/code-review` を引数なしで使うと直近に入力したレベルを再利用する。
