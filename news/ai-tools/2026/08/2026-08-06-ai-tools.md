### 2. LiteLLM / v1.95.0

- 種別: OSS（LLM ゲートウェイ／プロキシ・Python SDK）
- 関連: OpenAI / Anthropic / Azure ほかマルチプロバイダ・ルーティング
- 公開・更新日: 2026-08-03 19:48 UTC（JST 08-04 04:48、安定版）
- 概要: 100 以上の LLM プロバイダを OpenAI 互換の単一 API で束ねるゲートウェイの大型更新。Rust バックエンドの適用範囲拡大と管理・予算・認証の強化が中心。
- 何が便利か:
  - **Anthropic `/messages` のネイティブ Rust ルーティング（`LITELLM_RUST` で有効化）**: Anthropic ネイティブ形式をそのまま高速な Rust 経路で処理。
  - **OpenAI Responses API の WebSockets を litellm-rust に 1:1 移植**: Responses API のストリーミングをゲートウェイ越しに扱える。
  - **管理 UI 向け SAML 2.0 SSO**: 企業の ID 基盤と統合しやすい。
  - **キー／ユーザ単位で予算リセット時刻を設定可能／フェイルクローズ付きアトミック予算予約**: 予算超過を厳密に止められる。
  - Cost Optimization 画面（ツール別支出・キャッシュ漏れ分析）、Claude Opus 5／Gemini 3.6 Flash などの価格情報追加。
- 使いどころ:
  - 複数プロバイダ（OpenAI・Anthropic・Azure・ローカル）を**1 つの OpenAI 互換エンドポイントに集約**し、キー配布・課金・レート制御を一元管理したいとき。
  - チーム・部署ごとに**予算とリセット時刻を設定**し、コスト上限を厳格に運用したいとき。
- 開発者にとっての価値: `pip install litellm` で入り、プロキシとしてもライブラリとしても使える。**アプリ側のコードを OpenAI SDK のまま保ちつつ、裏のプロバイダを差し替え・多重化**できるのが実用的。予算・SSO 強化で個人利用から社内共有基盤までスケールしやすい。
- 注意点: Rust 経路（`LITELLM_RUST`）は適用範囲が拡大中の機能のため、本番投入前に対象エンドポイントで挙動確認を推奨。SAML SSO・予算予約などは Enterprise 機能を含む。
- 公式リンク: https://github.com/BerriAI/litellm/releases/tag/v1.95.0
- 参考リンク: https://github.com/BerriAI/litellm
- メモ: 本リポジトリで LiteLLM を採用するのは今回が初。JST 08-04 の安定版 v1.95.0 を新規採用。

#### 使用例

```bash
# インストール
pip install litellm

# プロキシとして起動（OpenAI 互換エンドポイントを提供）
litellm --model gpt-4o-mini

# アプリ側は OpenAI SDK のまま base_url を差し替えて利用
#   base_url="http://localhost:4000"
```
