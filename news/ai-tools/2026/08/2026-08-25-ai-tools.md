# 2026-08-25 AI Tools News

## 今日の要点

- Claude Code `v2.1.243` が公開。`/usage` に **Loops の内訳**（`/loop` ごとの実行回数・総トークン・1 回あたりトークン・最終実行）を追加し、暴走・冗長な `/loop` を見つけやすく。`modelPicker`・`promptCacheTtl`・`modelPricing` など**組織向け設定**も追加。

## 今日の注目

### 1. Claude Code / v2.1.243

- 種別: CLI
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-08-24（UTC 23:10 / JST 08-25 08:10）
- 概要: 追加点: `/usage` の Loops 内訳、`/model` ピッカーを並び替え・ラベル付きで調整できる `modelPicker` 設定（Vertex/Bedrock の ID も可）、メイン会話は 1 時間キャッシュ・サブエージェントは 5 分に分けられる `promptCacheTtl`／`subagentPromptCacheTtl`、組織の契約単価・割引率を `/cost`・ステータスライン・テレメトリに反映する `modelPricing`（managed 設定）、API キーを許可しない組織向けの Anthropic Console キーレスサインイン、`/status` の `Skipped sources` 行（優先度の高い managed ソースにより適用されなかった設定ソースの表示）、`/mcp`・`/plugins` の `managed` 表示、`/tasks` に各サブエージェントのモデルと effort を表示。改善は起動時間（サンドボックスや MCP の立ち上げが初回フレームをブロックしなくなった）、ネイティブインストール／自動更新のダウンロードサイズ縮小。修正は、`-p`／SDK セッションで切断された remote MCP サーバーが復帰しない問題、デスクトップから開始した MCP サインインで Linear など client ID metadata document 対応サーバーが「Invalid redirect URI」になる問題、`/resume` が直近 50 件しか出ない問題など。
- 何が便利か: `/loop` を常用する運用では、暴走しているループをトークン量で特定できる。コスト管理（`modelPricing`、キャッシュ TTL 分離）や入れ替え自由なモデルピッカーなど、組織導入時の管理機能が前進した。
- 使いどころ: スケジュール実行・`/loop` を多用する自動化運用、契約単価でコスト可視化したい組織、API キー禁止の組織。
- 開発者にとっての価値: 「何にトークンを使っているか」の可視化が `/loop` 単位まで細かくなり、無人運用の費用管理に使える。
- 注意点: `modelPricing` や `modelPicker` は managed 設定が前提の機能。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.243
- 参考リンク: https://code.claude.com/docs/en/changelog
- メモ: `/resume` が 50 件超でもスクロールで読み込むようになった。
