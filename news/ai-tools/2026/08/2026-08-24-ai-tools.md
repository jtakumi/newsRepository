### 1. OpenAI Codex / rust-v0.149.0

- 種別: CLI（ターミナル・コーディングエージェント／安定版）
- 関連: OpenAI / Codex
- 公開・更新日: 2026-08-20 21:04 UTC（JST 2026-08-21 06:04）
- 概要: 前記事で扱った `rust-v0.148.0` に続く安定版。複数タスクを回すエージェント運用まわりが大きく強化され、TUI の操作性も向上した。
- 何が便利か:
  - **`codex agents` 対話型ダッシュボード**: 実行中／過去タスクを一覧で検索・起動・オープン・リネーム・停止できる。並列でエージェントを走らせるときの「どれが何をしているか」を1画面で把握できる。
  - **`codex queue`**: ローカル／リモートの既存セッションにメッセージを送れる。走行中のエージェントに後から指示を積める。
  - **TUI ディレクトリ移動 `/cd` `/pwd` `/cwd`**: セッションを抜けずに作業ディレクトリを移動・確認できる。モノレポやマルチプロジェクトの往復が楽になる。
  - **SDK の推論レベル `max`/`ultra`**: SDK 利用時に高難度タスク向けの推論強度を明示指定できる。
  - **`codex doctor` 強化**: エンドポイント保護（EDR 等）や接続性の問題を診断。企業環境での「なぜか繋がらない」の切り分けに使える。
- 使いどころ: 複数の修正・調査タスクを Codex に並行で任せ、`codex agents` で監督しつつ `codex queue` で追い指示を出す運用。CI やスクリプトから SDK で回す長時間タスクの推論強度チューニング。
- 開発者にとっての価値: 「1タスク=1セッション」から「複数タスクを束ねて監督する」運用へ寄せやすくなり、エージェント並列化の実務コストが下がる。
- 注意点: 本タグ以降に `0.150.0-alpha` 系が多数出ており、alpha は不安定。安定運用は `rust-v0.149.0` を基準に。セキュアな devcontainer での DNS 経由の情報漏えいリスクがドキュメントで注意喚起されている点も確認を。
- 公式リンク: https://github.com/openai/codex/releases/tag/rust-v0.149.0
- 参考リンク: https://github.com/openai/codex/releases
- メモ: 前記事採用の `rust-v0.148.0` からの明確な機能追加のみを採用。alpha 群は調査メモ扱い。

#### 使用例

```bash
# 最新版へ更新（npm 配布の場合）
npm install -g @openai/codex@latest

# 対話型エージェントダッシュボードを開く
codex agents

# 既存セッションに追いメッセージを送る
codex queue "テストが落ちている原因も併せて調べて"

# 環境の接続性・保護状況を診断
codex doctor
```

- 使いどころ: 自社 LLM ゲートウェイ運用でのコスト最適化（キャッシュ有効化）、Bedrock/Vertex/Foundry 上での日常運用、コスト見積もりの正確化を重視するチーム。

- 何が便利か:
  - **Hub のドレイン＆アップグレード**: 稼働中の作業を失わずに Hub を更新・切り替えできる。長時間タスク中でもアップグレードのタイミングに悩まない。

  - **カスタム OpenAI 互換モデルのツール呼び出し修正**（v4.1.13・CLI・SDK）: 自前エンドポイント運用の安定性向上。
- 使いどころ: 自前 Hub で複数クライアント／長時間タスクを運用するチーム、MCP を多用する自動化、OpenAI 互換のローカル／セルフホストモデルでのエージェント運用。
- 開発者にとっての価値: エージェント運用の「途中で切れて作業が消える」を構造的に減らし、MCP・カスタムモデルの実運用の穴が塞がった。
- 注意点: MCP 全自動承認は利便性と引き換えに、信頼できない MCP サーバでは危険。トグルON時の挙動が変わった点を理解して使うこと。

- 開発者にとっての価値: エンタープライズのコスト計上とキャッシュ制御が細かくなり、Claude Code をゲートウェイ配下で使う導線が正式に整った。
