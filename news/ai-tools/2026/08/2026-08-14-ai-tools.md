## 今日の注目

### 1. Claude Code / v2.1.231 / v2.1.232

- 種別: CLI
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: `v2.1.231` は 2026-08-13（UTC 08:27 / JST 17:27）、`v2.1.232` は 2026-08-13（UTC 21:30 / JST 08-14 06:30）
- 概要: `v2.1.232` の修正は権限まわりに集中している。PowerShell で変数を書き込むパラメータが `$PSDefaultParameterValues` を上書きし、後続コマンドのファイルアクセスを誘導できた問題、Windows で Git Bash が Cygwin 風シンボリックリンクを辿り、パス検証には通常ファイルに見えていた問題（書き込みは承認が必要に）、入れ子の git リポジトリが親ディレクトリの信頼を継承していた問題（各リポジトリで個別に信頼確認が必要に）を修正。MCP がプロトコルバージョンのプローブに応答しない／不正応答するサーバーで 30 秒ハングする問題、Remote Control の bridge が cloud セッションのトランスクリプトや認証情報を継承する問題も修正した。追加は、`/config` の「Dialog expiry」「Messages from your other sessions」（クロスセッション受信の承認・保留・拒否）、GitLab のトークン形式（`glrt-`・`gloas-` など）の秘匿、`gitlab.com` の URL をプラグインマーケットプレイスで `github.com` 同様にクローンする対応。`sandbox.ripgrep` はユーザー／managed／`--settings` からのみ有効になり、プロジェクト設定では上書きできなくなった。
- 何が便利か: Windows や PowerShell で Claude Code を使うチームにとって、権限バイパス修正が入った更新。GitLab 利用者はプラグイン配布とトークン秘匿が整う。
- 使いどころ: Windows／PowerShell 環境、GitLab 中心の開発組織、リポジトリ内に別リポジトリを置く構成、Slack 等の事前登録 OAuth クライアントを使う MCP サーバー。
- 開発者にとっての価値: 権限・信頼境界の穴を塞ぐ修正が主眼なので、承認運用をしている環境では更新を推奨。
- 注意点: 入れ子の git リポジトリは各々で信頼確認が必要になるため、初回に確認ダイアログが増える。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.231 / https://github.com/anthropics/claude-code/releases/tag/v2.1.232
- 参考リンク: https://code.claude.com/docs/en/changelog
- メモ: `v2.1.232` では、完了したサブエージェントは即座に非表示になり `/tasks` へのヒントが出る。
