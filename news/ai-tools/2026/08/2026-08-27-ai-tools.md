### 1. OpenAI Codex / rust-v0.150.0（安定版が前進）

- 種別: CLI（ターミナル・コーディングエージェント／安定版）
- 関連: OpenAI / Codex
- 公開・更新日: 2026-08-26 19:37 UTC（JST 2026-08-27 04:37）
- 概要: 前回記事の安定版 rust-v0.149.1 から 0.150 系へ安定版が前進。タスク間参照・コピー操作・リンク表示など対話 UX の改善に加え、中断ハンドリングと untrusted プロジェクトのセキュリティ強化が入る、105 コミット規模の更新。
- 何が便利か:
  - **`@` メンションで他タスクを参照**: 実行中／別の Codex タスクを `@` で参照し、エージェントが読み取り・作成・メッセージ連携できる。**複数タスクを横断してコンテキストを渡す**運用がやりやすくなる。
  - **`/copy` のピッカー**: レスポンス全体・コードブロック・引用（blockquote）を選んでコピー。**生成物の一部だけを手早く取り出す**手間が減る。
  - **クリック可能な Markdown リンク**: 対応ターミナルではリンクをクリックでき、非対応環境では URL を可視表示。ログや回答からの遷移が速い。
  - **パーミッションモード循環キーバインド／Vim の dot-repeat**: 承認モードの切り替えをキー一発で回せ、Vim モードで `.` の繰り返しが効く。対話中の操作コストが下がる。
  - **`Interrupt` フック**: ターンを中断したときにコマンドや MCP ハンドラを走らせるフックを追加。**中断時の後処理（クリーンアップ等）を自動化**できる。
  - **セキュリティ**: untrusted プロジェクトのプロジェクト直下 `AGENTS.md` 指示を読み込まないよう変更、診断の資格情報マスキング強化、リモート MCP の bearer トークン解決・必須サーバ起動の修正。
- 使いどころ:
  - `codex exec` や対話セッションを **複数タスクにまたがって運用**し、タスク間でコンテキストを引き回したいケース。
  - 信頼できないリポジトリを Codex で開く際に、**`AGENTS.md` 経由の指示注入リスクを避けたい**運用（セキュリティ観点の検証）。
  - 中断時に一時ファイル削除やプロセス停止など**後処理を自動化**したいワークフロー。
- 開発者にとっての価値: `npm install -g @openai/codex` の 1 コマンドで更新でき、安定版ラインなので本番運用に載せやすい。今日の注目のうち**最も新しい安定版**で、対話 UX とセキュリティの両面に実利がある。
- 注意点: 窓内には alpha ライン（0.150.0-alpha.x／0.151.0-alpha.2）も併走するが、本項は**安定版 rust-v0.150.0** を採用。利用には OpenAI アカウント／対応プランが必要。リリース本文は要約ベースのため、全変更点は公式リリースノートで各自確認のこと。
- 公式リンク: https://github.com/openai/codex/releases/tag/rust-v0.150.0
- 参考リンク: https://github.com/openai/codex/releases
- メモ: 前回記事（08-26）は安定版 rust-v0.149.1 を採用済み。0.150 系への安定版前進を新規採用。
