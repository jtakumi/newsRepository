### 2. Claude Code / v2.1.238（+ v2.1.237）

- 種別: CLI（ターミナル・コーディングエージェント／安定版）
- 関連: Anthropic / Claude / Claude Code
- 公開・更新日: v2.1.238 = 2026-08-20 20:33 UTC（JST 2026-08-21 05:33） / v2.1.237 = 2026-08-20 00:54 UTC（JST 2026-08-20 09:54）
- 概要: 前日 v2.1.236 に続く安定版更新。長時間セッションのメモリ肥大化修正という実利の大きいバグ修正に加え、キーバインド・プラグイン・セルフホストランナー・Remote Control まわりの多数の改善が入っている。v2.1.237 では `Concise` 出力スタイルと LLM ゲートウェイ向けのプロンプトキャッシュ修正が追加。
- 何が便利か:
  - **長時間対話セッションのメモリ肥大化を修正**: サブエージェントのツール結果を、表示ウィンドウから外れた時点で解放するように変更。長く回すセッションの安定性・省メモリに直結する。
  - **`keybindingFlavor: "readline"`**: Ctrl+W をプロンプト内で「直前の空白まで削除」（Bash 風）にできる。既定の `"classic"` はそのまま。ターミナル操作の手癖に合わせられる。
  - **プラグインマーケットプレイスの `headersHelper`**: 短命トークンなどの HTTP ヘッダをコマンドで発行し、カタログ／同一オリジンのアーカイブ取得に付与できる。認証付きの社内プラグイン配布がしやすくなる（インストール／更新時に `[y/N]` 確認あり）。
  - **セルフホストランナーの `--defer-shutdown-max-min`**: SIGTERM 後に接続中セッションを一定時間まで保ち続け、残りをパークしてから終了。デプロイ・再起動時のセッション切断を減らせる。プロキシ認証を毎接続で発行する `--proxy-authorization-command/--file` も追加。
  - **（v2.1.237）`Concise` 出力スタイル**: 結果を先頭に置き、前置き・ナレーションを省く組み込みスタイル（作業の丁寧さは維持）。`/config` から選択。
  - **（v2.1.237）LLM ゲートウェイ／カスタム base URL でのプロンプトキャッシュ修正**: ゲートウェイ経由や独自 base URL のセッションでキャッシュが効かなかった問題を修正。トークンコストに直結。
- 使いどころ:
  - **バックグラウンドや長時間の常駐セッション**を回していて、メモリ増加が気になっていた人（v2.1.238）。
  - **LLM ゲートウェイ／プロキシ経由**で Claude Code を使うチームで、キャッシュが効かずコストが膨らんでいたケース（v2.1.237）。
  - 出力を短くしたい／CI ログ用途などで**前置き抜きの結果先頭表示**が欲しいとき（`Concise`）。
- 開発者にとっての価値: `npm i -g @anthropic-ai/claude-code` の 1 コマンドで更新でき、今日すぐ試せる安定版。メモリ肥大化修正とゲートウェイ向けキャッシュ修正は、長時間運用とコストという実利面に効く。
- 注意点: `keybindingFlavor` と `Concise` はオプトイン設定。`headersHelper` はプロジェクト `.mcp.json` 由来だとフォルダの信頼ダイアログ承認が必要で、継承した認証系環境変数なしで実行される（セキュリティ配慮）。Remote Control 関連の修正が多いが、破壊的変更は特に告知なし。Ctrl+L / Cmd+K のダブル押し `/clear` ショートカットは削除された点に留意。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.238
- 参考リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.237 / https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- メモ: 前日記事（2026-08-20）で v2.1.236 まで採用済み。v2.1.237・v2.1.238 を新規採用。

#### 使用例

```bash

# Ctrl+W を Bash 風の単語削除にする（settings で設定）
```

### 3. Ollama / v0.32.15（安定版に昇格・TTFT 約半減）

- 種別: CLI／ローカルLLMランタイム（安定版）
- 関連: Ollama / ローカルLLM
- 公開・更新日: 2026-08-20 18:47 UTC（JST 2026-08-21 03:47）
- 概要: 前日記事で採用した RC（`v0.32.15-rc1`）が安定版 `v0.32.15` に昇格。**モデルメタデータのキャッシュにより time-to-first-token を約半減**する性能改善が目玉で、加えてデスクトップの初回オンボーディングとストリーミングの不具合修正が入る。
- 何が便利か:
  - **メタデータキャッシュで TTFT が約半減**: リクエスト間でモデルのメタデータをキャッシュし、ベンチで最初のトークンまでが ~995ms → ~524ms に短縮。**同一モデルへ短い推論を何度も投げる**エージェント用途で体感が変わる。
  - **ストリーミングの固まり修正**: ストリーム途中のパーサエラーで chat/generate がハングし得た不具合を修正。常駐サーバの安定性が上がる。
  - **デスクトップの初回オンボーディング**: 初回起動時の導入フローが追加され、セットアップが分かりやすくなった。
- 使いどころ:
  - ローカルLLM をコーディングエージェントや自動化のバックエンドにしていて、**小さなリクエストの積み重ねでレイテンシが気になる**環境。安定版なので本番投入の判断がしやすい。
  - `ollama serve` を常駐させたワークフローで、ストリーミングのハングに悩んでいたケース。
- 開発者にとっての価値: RC で先行確認できた TTFT 改善が安定版として使えるようになった。ローカル推論の固定費（初トークンまでの待ち）を減らせるのは、対話・エージェント双方で効く実利的な更新。
- 注意点: 前日記事は RC（`-rc1`）を採用済み。今回は RC → 安定版の昇格。ベンチ値は環境依存のため各自計測を推奨。
- 公式リンク: https://github.com/ollama/ollama/releases/tag/v0.32.15
- 参考リンク: https://github.com/ollama/ollama/releases
- メモ: 前日記事は `v0.32.15-rc1`（プレリリース）を採用。今回は安定版昇格を新規採用。

### 4. Cline Desktop / desktop-v0.0.15-beta.1（ローカル→クラウドの `/handoff`）

- 種別: デスクトップアプリ（ベータ／プレリリース）
- 関連: Cline / マルチプロバイダ対応コーディングエージェント
- 公開・更新日: 2026-08-20 18:18 UTC（JST 2026-08-21 03:18）
- 概要: 安定版 `desktop-v0.0.14` に続くベータライン。ローカルで進めていたセッションを **`/handoff` で Cline Cloud に引き継ぐ**機能を追加。手元のマシンを閉じても、クラウド側で作業を継続できる。
- 何が便利か:
  - **`/handoff` でクラウドへ引き継ぎ**: 会話・添付画像・任意の後続コマンドをクラウドのワークスペースへ移送し、アプリを閉じても実行を継続。事前チェックでリポジトリ・ブランチ・コミットが push 済みかを確認してから引き継ぐ。
  - **Local/Remote メニューに Cloud を統合**: 別トグルではなく既存の環境メニュー内に Cloud を統合し、切り替え導線が一本化。
  - **中断時のセッション復元**: アプリ再起動・ネットワーク断・ブランチ変更で引き継ぎが中断しても、再オープンで入力中のドラフトや添付を復元。
- 使いどころ:
  - **手元で始めた長い作業をクラウドに逃がして継続**したい場面（外出・マシン再起動・省電力）。push 済み前提のプリフライトがあるので状態の取り違えを防げる。
  - VS Code 拡張ではなく**独立アプリとして Cline を運用**し、ローカルとクラウドをシームレスに行き来したい利用者。
- 開発者にとっての価値: ローカルとクラウドの境目を跨ぐ引き継ぎは、長時間エージェント実行の「置き場所」を柔軟にする。中断復元まで含めてベータで評価できる。
- 注意点: **ベータ（`beta.1`）のプレリリース**であり本番運用は要検証。`/handoff` は Cline Cloud への送信を伴うため、業務・機密コードの取り扱いは規約と送信先を確認すること。VS Code 拡張本体の更新ではなくデスクトップアプリのライン。
- 公式リンク: https://github.com/cline/cline/releases/tag/desktop-v0.0.15-beta.1
- 参考リンク: https://github.com/cline/cline/releases
- メモ: 前日記事は安定版 `desktop-v0.0.14` を採用済み。今回はベータラインの `/handoff` 追加を別トピックとして新規採用。
