## 今日の注目

### 1. Claude Code / v2.1.237

- 種別: CLI
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-08-19（UTC 23:57 / JST 08-20 08:57）
- 概要: 小規模だが実務に効く更新。出力スタイル「Concise」は、作業の徹底度は保ちつつ前置きや逐次の語りを省いて結果から始める。もう 1 点の修正は、LLM ゲートウェイやカスタム base URL を使うセッションでプロンプトキャッシュが効かなかった問題。
- 何が便利か: ゲートウェイ経由の利用でキャッシュが効くようになり、トークンコストと応答時間の改善が期待できる。出力が冗長で読みづらいと感じる場合は Concise に切り替えるだけで済む。
- 使いどころ: 社内 LLM ゲートウェイを通して Claude Code を使う組織、短い応答を好む利用者。
- 開発者にとっての価値: コスト面の改善（キャッシュ）が小さな更新で得られる。
- 注意点: キャッシュの効果は構成依存。実際のキャッシュヒット率は利用状況の確認が必要。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.237
- 参考リンク: https://code.claude.com/docs/en/changelog
- メモ: Output style は `/config` で選択。

#### 使用例

```bash
npm install -g @anthropic-ai/claude-code@latest
claude --version

# セッション内で: /config → Output style → Concise
```
