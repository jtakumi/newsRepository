- 概要: サブエージェント連携とセッション間メッセージング、GitLab 対応、複数のセキュリティ修正を入れた安定版更新。
- 何が便利か:
  - **サブエージェントの fork がデフォルト有効（v2.1.232）**: `subagent_type: "fork"` で、親の会話履歴とプロンプトキャッシュを継承したサブエージェントを立てられる。文脈を渡し直さずに分岐調査・並行作業ができ、キャッシュ再利用でコストも抑えやすい。
  - **`@` によるセッション間メッセージング（v2.1.232）**: プロンプト内で `@` を打って別の Claude セッションを名前で指定し、`SendMessage` で直接送信。ライブセッションと一致する裸の名前には確認なしで届く。複数セッションを並行運用する開発フローで連携しやすくなる。
  - **GitLab 対応（v2.1.232）**: プラグインマーケットプレイスが `gitlab.com` の裸のリポジトリ URL に対応。GitLab トークン族（`glrt-`／`gloas-`／`glptt-` など）とルーティング可能トークンの秘匿（redaction）も追加。GitLab 中心の組織で導入しやすくなった。
  - **セキュリティ修正（v2.1.232）**: PowerShell の変数書き込みパラメータ経由の権限バイパス、Windows の Cygwin 形式シンボリックリンクによる権限バイパス、ネストした git リポジトリが親ディレクトリの trust を継承する問題を修正。
  - **MCP OAuth 修正（v2.1.231）**: 事前登録済み OAuth クライアント（例: Slack）でリダイレクト URI 不一致によりサインインが失敗する不具合を修正。MCP サーバ連携の認証が通りやすくなる。
  - **その他（v2.1.232）**: `/code-review` を high／xhigh／max でバックグラウンドエージェントとして実行、Bedrock／Vertex／ゲートウェイのストリームアイドルタイムアウト修正、Remote Control の各種安定化、`/model fable` での Fable 5 アドバイザ提供（利用クレジット同意付き）。
- 使いどころ:
  - **1 つの調査を複数の視点に分岐させたいとき**（fork したサブエージェントで並行探索）。
  - **GitLab 上で社内プラグインや MCP 認証を運用しているチーム**。
  - Windows／PowerShell 環境で**権限まわりの安全性を上げたい**利用者。
