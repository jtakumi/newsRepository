### 1. Cline / SDK v0.0.68

- 種別: OSS（TypeScript SDK・安定版）
- 関連: Cline
- 公開・更新日: 2026-08-01 05:29 UTC（JST 08-01 14:29）／commit `8e68b14`／前版 `sdk/sdk/v0.0.67`
- 概要: Cline のホスト統合向け SDK の安定版パッチ。**エラー表示・モデル名解決・Windows コマンド実行・ルート起点セッション**まわりの実運用系を集中的に改善した更新。
- 何が便利か:
  - **プロバイダーエラーの本文をそのまま出す**: Vercel AI Gateway を経由したときにモデル上限などの上流メッセージが握りつぶされず、原因が読める。
  - **`fetchClineRecommendedModels` がカタログ解決済み表示名を返す**: ホスト側で ID→表示名の変換を書かなくてよい。無料モデルは OpenRouter の表示名に解決され、ライブカタログは動画入力対応を維持。
  - **Windows PowerShell を UTF-8 stdin 実行に変更**: コマンドを引数ではなく標準入力で渡すため、**非 ASCII 文字化けとコマンド長上限**の両方を回避。
  - **ルート（`/`）起点セッションの失敗を修正**: 空の workspace hint によるスキーマ検証エラーで実行できなかった不具合を解消。
  - エージェントエラーを説明するヘルパー関数を API として export。
- 使いどころ: Cline を**独自ホスト／自動化に組み込んでいる**ケースで、エラーログの可読性向上とモデル一覧 UI 実装の簡素化が効く。Windows 上で Cline のコマンド実行を使う開発者は文字化け・長大コマンド系の不具合が減る。
- 開発者にとっての価値: **SDK を土台にした Cline 統合（v4.1.x の Next 実装含む）**の下回りが安定化。ホスト実装のボイラープレート削減と Windows 実行の堅牢化は、そのまま自作エージェント基盤の信頼性に効く。
- 注意点: あくまで下回りのパッチで、派手な新機能はない。SDK は `0.0.x` 系で API 変更の可能性が残る。
- 公式リンク: https://github.com/cline/cline/releases/tag/sdk%2Fsdk%2Fv0.0.68
- 参考リンク: https://github.com/cline/cline/releases ／ https://www.npmjs.com/package/@cline/sdk
- メモ: 前回記事（08-01）は SDK v0.0.67（セッション fork API・MCP サーバー単位タイムアウト）まで。今回は v0.0.68 を新規採用。

#### 使用例

```bash
# Cline SDK を最新（0.0.68）で導入
npm install @cline/sdk@latest
# または明示バージョン指定
npm install @cline/sdk@0.0.68
```

### 2. GitHub Copilot CLI / v1.0.78-0・v1.0.78-2（プレリリース）

- 種別: CLI（プレリリース）
- 関連: GitHub Copilot
- 公開・更新日: v1.0.78-0 = 2026-07-31 16:01 UTC（JST 08-01 01:01）、v1.0.78-2 = 2026-08-01 04:18 UTC（JST 08-01 13:18）。安定版は v1.0.77 のまま
- 概要: 対話 CLI のプレリリース系列。**承認モード切り替えコマンド、長大セッション再開の大幅高速化、サンドボックス設定**などを追加した実運用強化。
- 何が便利か:
  - **`/permissions` コマンド**: セッション中に承認モード（ask / auto など）を切り替えられる。
  - **長大トランスクリプトの再開を約 10 倍高速化・メモリ約 75% 削減**: 履歴を毎回読み直さず起動時に一度だけ CPU コア横断で読む方式に変更。**230MB のトランスクリプトで「約 10 秒→1 秒未満」**。長い履歴のセッションを resume する運用が快適に。
  - **`allowDevToolCaches`（既定 on）**: サンドボックスビルドからツールチェーンキャッシュへアクセス可能に。
  - **GitHub MCP ツールセット設定を尊重**: 明示 opt-in により、勝手に `gh` CLI へ誘導されない。
  - `settings.json` の未知キーに起動時警告、`--model` のシェル補完、セッション切り替え時に MCP サーバーを中断せずフック状態も作り直さない、OAuth 認証後に遅延 MCP ツールを再取得、などの改善。
- 使いどころ: **履歴の長いエージェントセッションを resume して継続作業する**用途、CI/サンドボックスでビルドキャッシュを使いたい用途、承認レベルを都度切り替えたい運用に効く。
- 開発者にとっての価値: セッションの**再開コストが実質ゼロに近づく**ため、長時間の反復作業を止めずに続けられる。承認モードの動的切り替えは、探索フェーズと確定フェーズで安全度を変える運用に向く。
- 注意点: **これらは安定版ではなくプレリリース（`-0` / `-2` サフィックス）**。安定版で使いたい場合は v1.0.78 の正式リリースを待つのが無難。
- 公式リンク: https://github.com/github/copilot-cli/releases/tag/v1.0.78-0
- 参考リンク: https://github.com/github/copilot-cli/releases

#### 使用例

```bash
# 安定版
npm install -g @github/copilot@latest
# プレリリース（1.0.78 系）を試す場合は明示バージョン指定
npm install -g @github/copilot@1.0.78-2
# セッション中に承認モードを切り替え
/permissions
```

### 3. Gemini CLI / v0.54.0-preview.1（＋ v0.55.0-nightly）

- 種別: CLI（プレビュー／ナイトリー）
- 関連: Google Gemini
- 公開・更新日: v0.54.0-preview.1 = 2026-07-31 21:39 UTC（JST 08-01 06:39）、v0.55.0-nightly.20260801 = 2026-08-01 01:27 UTC（JST 10:27）。安定版は v0.53.1 のまま
- 概要: レート／容量まわりの**エラー処理を安定化**するプレビュー・ナイトリー更新。
- 何が便利か:
  - **容量枯渇（capacity exhaustion）を「終端エラー」として分類**: リトライを繰り返してハングする挙動を防止。混雑時に固まりにくくなる。
  - **空 API 応答時に `InvalidStreamError` の詳細を UI に表示**: 何が起きたか分かる形でエラーを提示。
  - v0.53.1 のストリームエラー伝播修正（PR #28566 の cherry-pick）を同系統で取り込み。
- 使いどころ: **混雑時・レート制限時に Gemini CLI が固まる**症状に当たっている開発者向け。バッチ／自動実行で「無応答でハング」を避けたいケースに効く。
- 開発者にとっての価値: 自動化パイプラインで CLI がハングすると全体が詰まるため、**「落とすべき所で確実に落ちる」**エラー分類は運用安定性に直結する。
- 注意点: **v0.54.0-preview.1 はプレビュー、v0.55.0-nightly はナイトリー**。安定運用は v0.53.1 を使い、修正が安定版へ入るのを待つのが安全。
