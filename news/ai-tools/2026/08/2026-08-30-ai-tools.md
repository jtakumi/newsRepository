- 種別: CLI（ターミナル・コーディングエージェント／安定版）

- 何が便利か:
  - **MCP サーバ発見の猶予時間（grace period）**: オプション扱いの MCP サーバからツールを発見する待機時間を**設定可能**にし、起動タイミングを制御できる。遅い MCP サーバでの起動失敗や取りこぼしを避けられる。

  - **ネストしたサブエージェントのトークン会計**: 入れ子のサブエージェントのトークン使用量を**ルート目標の予算に正しく計上**。多段エージェントのコスト見積もりが正確になる。
  - **プラグインカタログ改善**: リポジトリ単位の設定を統合し、**無効なプロジェクトマーケットプレイスを報告しつつ有効なプラグインは隠さない**。
  - **その他**: 構造化された MCP ツール/リソースエラーを app-server 応答で保持、権限変更後に**古い Guardian 分類が誤って許可を出さない**よう修正、CI 用フィクスチャ/WebSocket テストの安定化。
- 使いどころ:
  - **MCP サーバを複数束ねて Codex から使う**構成で、起動タイミングや結果整形を制御したいとき。
  - CI・共有環境で**サンドボックスを厳密に効かせたい**とき（`/cd` での穴が塞がれた）。
  - 多段サブエージェントを走らせ、**トークン予算を正確に管理**したいとき。
- 開発者にとっての価値: `npm install -g @openai/codex`（または `brew install codex`）の 1 コマンドで更新でき、今日すぐ試せる安定版。MCP・サンドボックス関連の実利ある修正のため、旧安定版利用者は更新推奨。

### 3. LangChain / `langchain.mcp` アダプタ（1.4.0a2・任意の MCP サーバを create_agent に直結）

- 種別: OSS ライブラリ（Python／アルファ・プレビュー）
- 関連: LangChain / MCP / Agent Framework
- 公開・更新日: langchain==1.4.0a1 は 2026-08-27 22:21:11 UTC（JST 08-28 07:21）、langchain==1.4.0a2 は 2026-08-28 16:58:59 UTC（JST 08-29 01:58）
- 概要: LangChain 1.4 系のアルファで、**一次対応（first-party）の MCP アダプタ `langchain.mcp`** が入った。任意の MCP サーバをそのまま LangChain ツール化して `create_agent` に渡せる。
- 何が便利か:
  - **MCP サーバ → LangChain ツールの直結**: `MCPAdapter(...)` で MCP サーバに接続し、`await adapter.get_tools()` で得たツールを `create_agent` にそのまま渡せる。FastMCP をベースにしており、クライアント機能を再実装せず利用できる。
  - **多様な接続元**: URL・ローカルスクリプトパス・インプロセスサーバ・複数サーバ設定・カスタム FastMCP クライアントを受け付ける。
  - **認証・キャッシュ・タイムアウト**: OAuth／Bearer トークン認証、レスポンスキャッシュ、タイムアウトを設定可能。
  - **複数サーバ対応**: 1 つのアダプタで複数の MCP サーバを束ね、**ツール名前空間**で衝突を防止。
  - **プロトコル互換と elicitation**: レガシー/新プロトコルを自動ネゴシエーション。ツールが実行中にユーザ入力を要求する場合は **LangGraph の interrupt** として表面化し、人間が回答できる。失敗したツール呼び出しは構造化エラーで返り、エージェントの自己修正に使える。
- 使いどころ:
  - **既存の MCP サーバ資産を LangChain エージェントに組み込みたい**とき。
  - 複数の MCP サーバを 1 つのエージェントから使い分けたい構成。
- 開発者にとっての価値: これまで別パッケージや自前実装が必要だった MCP 連携が**公式アダプタで一本化**され、`create_agent` との相性がよい。MCP エコシステムを LangChain 側から取り込む導線が整った。
- 注意点: **アルファ（1.4.0aN）** のため API は変わり得る。本番投入は避け、検証用途で試すこと。インストールは `--pre` が必要。
- 公式リンク: https://github.com/langchain-ai/langchain/releases/tag/langchain%3D%3D1.4.0a2
- 参考リンク: https://github.com/langchain-ai/langchain/releases/tag/langchain%3D%3D1.4.0a1 / https://github.com/langchain-ai/langchain/releases
- メモ: NewsRepository の既存 ai-tools 記事に `langchain.mcp` / `MCPAdapter` の記載なし（新規）。アルファのため「今日試すならこれ」には非選定。

#### 使用例

```python
# アルファ版を導入
# pip install --pre -U langchain

from langchain.agents import create_agent
from langchain.mcp import MCPAdapter

async with MCPAdapter("https://example.com/mcp") as adapter:
    agent = create_agent(
        "anthropic:claude-sonnet-5",
        await adapter.get_tools(),
    )
```
