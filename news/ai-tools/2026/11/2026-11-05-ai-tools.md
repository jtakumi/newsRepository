## 今日の注目

### 1. Claude Code / v2.1.318

- 種別: CLI
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-11-03（UTC 21:55 / JST 11-04 06:55）
- 概要: 追加点: Claude Code が書く mod を有効にするかの回答の記録、Claude apps ゲートウェイ `mantle` アップストリームの `assume_role`（別 AWS アカウントのロール、開発者単位の AWS コスト配賦）、mod の `$.model.fork` への `effort` オプション、claude.ai サインインの終了日を示す `loginExpiresAt`（`claude auth status`）／`credential_expires_at`（`claude -p` の JSON）、サインイン終了 10 日前からの stderr 警告。改善は、共有ネットワークホームで `~/.claude.json` や設定・ログインが削除されたり空にされたり古いコピーに置き換わる事故を減らす保存処理、ネットワークファイルシステムで設定ファイルが「存在しない」と誤報告されたときの再確認、MCP ツールがロード前に呼ばれたときに入力スキーマを返す動作、macOS 標準 `/bin/bash` での git コミット／PR 作成の信頼性。修正は `--continue` が不正なツール呼び出しのリトライ超過後に以前の会話を失う問題（2.1.314 の回帰）、多数の Bash コマンド実行中に macOS セッションが停止する問題、権限プロンプトがメッセージ送信直後のキー入力で誤って応答される問題、`/logout`・`claude mcp remove` が失敗しても成功と報告される問題、`claude mcp add`／`remove` がロックなしで書き込む問題など。
- 何が便利か: NFS などの共有ホームで Claude Code を使う環境では、設定やログインが壊れる事故が減る。サインイン期限が `claude auth status` で見えるため、CI のトークン切れを事前に検知できる。
- 使いどころ: ホームディレクトリを共有する研究室・企業環境、claude.ai サインインで `claude -p` を CI から回している構成、macOS の標準 bash を使う環境。
- 開発者にとっての価値: 長期運用で効く「設定破損」「サインイン期限切れ」に対する予防策が入った。
- 注意点: `--continue` の会話消失は 2.1.314 の回帰として修正された。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.318
- 参考リンク: https://code.claude.com/docs/en/changelog
- メモ: 同日付近の前版 `v2.1.317` は 11-04 記事で扱う。

#### 使用例

```bash
npm install -g @anthropic-ai/claude-code@latest
claude --version

# サインインの有効期限を確認
claude auth status
```
