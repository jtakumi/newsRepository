## 今日の注目

### 1. Claude Code / `v2.1.316`

- 種別: CLI
- 関連: Anthropic / Claude Code
- 公開・更新日: 2026-10-31（GitHub Releases, Latest）
- 概要: サブエージェントの effort を明示指定がないときに揃える `CLAUDE_CODE_SUBAGENT_EFFORT` を追加。`CLAUDE_CODE_DISABLE_ULTRATHINK` で `ultrathink` キーワードを無効化できる。VS Code ではチャットパネルから Claude apps ゲートウェイへサインイン可能に。Code Review は重大度別の集計カードを分析ページに追加。
- 何が便利か: 「Claude Code が自分で終了した後も macOS/Linux でシェルコマンドが動き続ける」不具合を修正し、バックグラウンド実行の後始末が安定。切り詰め／破損した圧縮レスポンスでネットワーク要求がハングする問題や、Vertex AI・Bedrock 上で `sonnet`/`opus`/`haiku` が旧モデルへ切り替わらずエラーになる問題も修正。`/diff` が大規模リポジトリでフルリポジトリ git コマンドの実行を減らす。
- 使いどころ: 大きめリポジトリでエージェントを長時間回す日常作業。社内ゲートウェイ／Vertex・Bedrock 経由でモデルを使うチーム運用。サブエージェントを多用する調査フロー。
- 開発者にとっての価値: サブエージェントの effort を環境変数で一括設定でき、挙動を揃えやすい。終了後のプロセス残留や圧縮レスポンスのハングが解消され、自動実行の信頼性が上がる。`--restricted` が作業ディレクトリ外にファイルをアップロードしていた問題の修正で、制限セッションの安全性も向上。
- 注意点: Opus 4.8 の Fast モードは 2026-10-30 付で非推奨となり、2026-11-30 に削除予定。削除後は Opus 4.8 への Fast モード要求がエラーになるため、速度が必要なら Opus 5.5 へ移行が必要。Team/Enterprise ログインのサーバ管理設定は承認プロンプトなしで適用されるようになった（検証できない保存コピーは拒否）。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.316
- 参考リンク: https://github.com/anthropics/claude-code/releases
- メモ: 2026-10-31 版は `v2.1.314` まで。`v2.1.315` は公開ページに現れず、本項は新規の `v2.1.316` を扱う。

#### 使用例

```bash
# 更新して最新版を確認
claude update
claude --version

# サブエージェントの既定 effort を環境変数で揃える例
export CLAUDE_CODE_SUBAGENT_EFFORT=medium
```

### 2. OpenCode / `v2.2.5`（＋ `v2.2.1`〜`v2.2.4`）

- 種別: OSS / CLI（ターミナル向けコーディングエージェント）
- 関連: OpenCode / Anthropic（Claude Code 連携）
- 公開・更新日: 2026-10-30（`v2.2.5`, Latest） / 2026-10-29〜30（`v2.2.1`〜`v2.2.4`）
- 概要: `v2.2.3` でローカルの Claude Code を「Claude Agent」プロバイダとして内蔵（`claude auth login` 後に `/connect` で選択、`OPENCODE_CLAUDE_PATH` でパス指定可）。`v2.2.1` で、レビュアーが目標達成を確認するまでセッションを回し続ける `/goal` コマンドとオプトインの画像生成ツールを追加。`v2.2.5` で割合指定（`"20%"`）のコンパクションバッファ、worktree／シェルモードのキーボードショートカットを追加。
- 何が便利か: 手元の Claude Code ログインとモデルを OpenCode の UI からそのまま使える。`/goal` で「完了条件を満たすまで自走」を指示でき、`compaction.buffer` を割合で指定して文脈管理を柔軟にできる。MCP サーバが 10 MiB 超の stdio メッセージで切断されない修正、LiteLLM の context window エラーで自動コンパクションが走る修正も入った。
- 使いどころ: Claude Code のアカウント／モデルを別フロントエンド（OpenCode の TUI・Desktop）で使いたい場面。長めのタスクを目標ベースで自走させたい開発。worktree を多用するブランチ並行作業。
- 開発者にとっての価値: プロバイダ選択肢が広がり、既存の Claude Code 環境を活かしつつ OpenCode の機能（worktree 選択、Desktop の成果物表示など）を使える。コンパクション挙動の改善で長時間セッションが安定。
- 注意点: 破壊的変更あり。TUI プラグインは `@opentui/core` / `@opentui/solid` 0.8.0 以上が必要（`v2.2.3`）。管理ポリシーの `integration.use` は連携のみを対象に変更され、MCP／スキル／プラグインは新アクション `mcp.use` / `skill.use` / `plugin.use` に分離。`v2.2.1` で一部 `@opencode/ai` のプロバイダ／エントリポイントが削除・改名。画像生成はオプトイン／実験扱い。
- 公式リンク: https://github.com/sst/opencode/releases/tag/v2.2.5
- 参考リンク: https://github.com/sst/opencode/releases
- メモ: 既存の AI Tools News では OpenCode の該当バージョンは未掲載。本項は新規の `v2.2.1`〜`v2.2.5`（Claude Agent プロバイダ・`/goal` ほか）を扱う。

#### 使用例

```bash
# Claude Code を OpenCode の「Claude Agent」プロバイダとして使う
#   1) Claude Code を導入してログイン
claude auth login
#   2) OpenCode を起動し /connect で "Claude Agent" を選択
opencode
#   （カスタム実行ファイルを使う場合）
export OPENCODE_CLAUDE_PATH=/path/to/claude
```

### 3. Charmbracelet Crush / `v0.99.0`

- 種別: OSS / CLI（ターミナル向けコーディングエージェント）
- 関連: Charmbracelet / Crush
- 公開・更新日: 2026-10-29（GitHub Releases, Latest）
- 概要: "Catwalk v3, hooks!"。プロバイダの `type` が API 形式（completions / responses / messages）を表すようになり、既存設定は自動移行。`provider add` / `model add` のフラグが変わり、`--thinking` が `--can-reason` を置き換えた。フックがセッション・ターン・権限などのライフサイクルイベントに追従できるよう拡張され、フック名は既知イベント一覧で検証される。
- 何が便利か: クライアント/サーバモードが強化され、ホストアプリから TUI のテーマ指定、開いているファイルの共有、次プロンプトへのテキスト追記、他クライアントが見ているセッションの把握、`CRUSH_PERMISSIONS_PIPED=1` 設定時の権限応答ができる（`http://` が `tcp://` の別名に）。`SIGHUP` でサーバを止めずに設定を再読み込みでき、終了時は作業中の内容を保存して穏当にシャットダウンする。
- 使いどころ: Crush を自作エディタ／ホストアプリに組み込んで TUI を制御したい開発。フックでセッションや権限イベントに処理を差し込みたい自動化。常駐サーバとして運用し設定を無停止で更新したいケース。
- 開発者にとっての価値: プロバイダ定義が API 形式ベースに整理され、responses / messages 系 API を扱いやすい。ライフサイクルフックとクライアント/サーバ連携で、Crush をエージェント基盤として組み込みやすくなる。ツール失敗でエージェントのターンが終了しない修正も入り、途中失敗に強くなった。
- 注意点: `provider add` / `model add` のフラグ変更（`--can-reason` → `--thinking`）があるため、既存スクリプトは要確認。Catwalk v3 への自動移行はされるが、カスタムプロバイダ設定は挙動を確認すること。同日以降の `nightly`（10/31）はプレリリースで変更履歴なし。
- 公式リンク: https://github.com/charmbracelet/crush/releases/tag/v0.99.0
- 参考リンク: https://github.com/charmbracelet/crush/releases
- メモ: 既存の AI Tools News では Crush の該当バージョンは未掲載。本項は新規の安定版 `v0.99.0` を扱う。

#### 使用例

```bash
# インストール / 更新（Homebrew の例）
brew upgrade charmbracelet/tap/crush
crush --version

# 権限応答をパイプ経由で受け付けるクライアント/サーバ運用の例
export CRUSH_PERMISSIONS_PIPED=1
```

