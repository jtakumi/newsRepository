### 2. Claude Code / `v2.1.327`

- 種別: CLI
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-11-17（UTC 23:17 / JST 2026-11-18 08:17）
- 概要: ターミナル向け AI コーディングエージェントの定期更新。追加点として、`/install-github-app` がリポジトリを変更する前に確認するようになった、`claude mcp add-json <name> -` が stdin から MCP サーバの JSON を読み込める（トークンをコマンドラインに残さない。セッション内では不可）、`/status` が壊れた agent/skill/command/output style ファイルやキーバインドエラー・一致しない hook マッチャなどの問題を一覧表示、Claude アプリゲートウェイ向けに課金グループを指定する `attributionProject` 設定、非フルスクリーンレンダラの名称として `/tui classic` を追加（`/tui default` も有効）。
- 何が便利か: `mcp add-json -` で API トークンをシェル履歴やプロセス一覧に残さず MCP サーバを登録できる（地味だが効くセキュリティ改善）。`/status` の設定不備一覧で、動いていない agent/skill/hook を一目で把握できる。
- 使いどころ: MCP サーバを秘密情報付きで登録する運用。多数の agent/skill/hook/output style を抱えて「なぜか効かない」設定を切り分けたいとき。`.mcp.json` に `$schema` など独自キーを持たせている構成（project スコープの add/remove が他キーを消さなくなった）。
- 開発者にとっての価値: `/export` が既存ファイルの上書き前に確認、WebFetch が 2,000 文字超の URL を権限プロンプト前に拒否、Read ツールが 10MB 超ファイルの実サイズを正しく報告するなど、取りこぼし・事故を減らす修正が揃う。
- 注意点: `mcp add-json <name> -` の stdin 読み込みは Claude Code セッションの中からは使えない（シェルから実行する）。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.327
- 参考リンク: https://code.claude.com/docs/en/changelog
- メモ: 前回記事（11-18）は `v2.1.326`。`v2.1.327` は本記事が初出。

#### 使用例

```bash
# 更新してバージョン確認
npm install -g @anthropic-ai/claude-code@latest
claude --version

# トークンをコマンドラインに残さず MCP サーバを登録（シェルから）
cat my-server.json | claude mcp add-json my-server -
```

### 3. OpenCode / `v2.3.2`・`v2.3.1`

- 種別: OSS / CLI・デスクトップ
- 関連: OpenAI（GPT-6.2）/ GitHub Copilot / その他（sst/opencode）
- 公開・更新日: 2026-11-18
- 概要: OpenCode 2 系の連続更新。`v2.3.2` では **GPT-6.2 向けのプロンプトキャッシュ最適化**として、Responses ルートでシステムプロンプトを先頭の developer メッセージとして毎回送るようにし、GPT-6.2 モデルが 2 ステップ目以降でそれをキャッシュできるようにした（毎ステップ未キャッシュ入力として再課金されなくなる）。加えて `webfetch` の構造化出力が呼び出し時の `url`/`format` を繰り返さない修正。`v2.3.1` では、タイムアウトしたシェルコマンドを kill せずバックグラウンドへ移す（フォアグラウンドの `timeout: 0` は既定 120 秒）、**バックグラウンド compaction をデフォルト有効化**（自動 compaction 直前に要約をバックグラウンド生成。`compaction.background: false` で無効化）、ChatGPT サインインでの GPT-6.2 Sol/Astra とその fast 系をモデルピッカーに表示、拡張の「Check for updates」ボタン、diff/ファイルビューアでのコード選択時に「Add comment」ツールバー、`AGENTS.md` がないディレクトリで `CLAUDE.md` を再び読む、などを追加。
- 何が便利か: GPT-6.2 を使う場合、Copilot の `gpt-6.2-sol` でステップあたりの未キャッシュ入力が約 14,000 → 3 トークンに下がる実測が示されており、マルチステップのエージェント実行コストが大きく下がる。バックグラウンド compaction で、長いセッションが自動要約で止まらなくなる。
- 使いどころ: OpenCode 2 系で GPT-6.2 を使ったエージェント作業を多く回すケース。長時間・大量ステップのセッションでコストと中断を抑えたいとき。
- 開発者にとっての価値: プロンプトキャッシュの効かせ方という「見えにくいがコストに直結する」部分をフレームワーク側で最適化。タイムアウト時にコマンドを殺さずバックグラウンド化する挙動は、長時間コマンドを扱うエージェントで取りこぼしを減らす。
- 注意点: GPT-6.2 のキャッシュ効果は対象モデル／プロバイダ側の対応に依存する。2 系の更新で、OpenCode 1 系（前回記事の `v1.19.6`）とはライン違い。
- 公式リンク: https://github.com/sst/opencode/releases/tag/v2.3.2
- 参考リンク: https://github.com/sst/opencode/releases/tag/v2.3.1
- メモ: 前回記事（11-18）は 1 系 `v1.19.6` を扱った。2 系 `v2.3.1`/`v2.3.2` は本記事が初出。

- 注意点: パッチ更新だが steering の挙動が変わるため、steer を使っている箇所はテストしてから上げること。多くの周辺パッケージが同時に版上げされるため、使用パッケージのバージョン整合に注意。

### 5. Pydantic AI / `v2.70.0`

- 種別: OSS（Python エージェントフレームワーク）
- 関連: OpenAI（GPT-6.2）/ Hugging Face / xAI / その他
- 公開・更新日: 2026-11-17
- 概要: 型安全なエージェント構築フレームワークの機能＋**セキュリティ**リリース。`pydantic-ai-harness 0.70.0` で high-severity の 2 件を修正（`ToolOutputLimits` で `strip_ansi=True` 時の ANSI エスケープ除去が遅い問題、`jwt` の秘密情報マスク用パターンのバックトラッキング遅延）。新機能として、ストリーム中の text/thinking/tool-call を呼び出し側に渡す前に検査する `StreamGuardrail`、受け取った tool 結果をモデル自身が要約で置き換えられる `PruneToolResults`、一過性 API エラーを同一モデルで再試行する `RetryOnModelErrors`、事前検索の遅延に向けた tools セレクタ `ToolSearch`、OpenAI `gpt-6.2-sol`/`gpt-6.2-astra` 対応、`AgentRunError` が失敗した run の会話を保持（`capture_run_conversation()` 追加）などを追加。
- 何が便利か: `StreamGuardrail` でストリーミング出力を「ユーザーに見える前」に検査・遮断できる。`RetryOnModelErrors` で一過性エラーの自動再試行が宣言的に書ける。`PruneToolResults` で肥大化しがちな tool 結果をモデルに要約させ、コンテキストを節約できる。
- 使いどころ: ストリーミングでガードレールを効かせたいエージェント。API の一過性失敗を吸収したい本番運用。長い tool 出力でコンテキストが膨らむワークフロー。
- 開発者にとっての価値: セキュリティ修正（high-severity 2 件）を含むため、harness を使っている構成は更新推奨。失敗 run の会話を `AgentRunError` から取れるようになり、エラー解析が書きやすい。
- 注意点: high-severity 修正は `pydantic-ai-harness` 側（`0.70.0`）。harness を使っている場合はバージョンを揃えて更新すること。

- 参考リンク: https://ai.pydantic.dev/
- メモ: 前回記事（11-18）は `v2.69.0`。`v2.70.0` は本記事が初出。
