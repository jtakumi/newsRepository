# 2026-11-24 AI Tools News

## 今日の要点

- **Claude Code `v2.1.331`** が公開。**MCP ツール呼び出しが不正な応答で最大 30 分ハングする問題**や、**rewind（巻き戻し）が復元失敗後にファイルを削除してしまう問題**など、使っていて痛い不具合がまとめて修正された。`claude doctor` に API 接続チェックが追加され、VS Code 拡張に「Resolve Merge Conflicts」「Fix with Claude Code」も入った。
- **Vercel AI SDK `ai@7.0.181`** が、`generateText` / `streamText` の結果・`onEnd`・finish part に **`stoppedBy`（ツールループが止まった理由）** を追加。呼び出し単位の **`onWarning` コールバック**も入り、エージェントの停止理由をコードから判別・ログ化しやすくなった。
- **LiteLLM `v1.108.16`（LTS）** が新しいバックポート版を公開。**Anthropic の `extra_body` をトップレベル送信に変更**・**Vertex AI Claude が呼び出し元の `anthropic-version` を転送**・**MCP ゲートウェイ DCR がオプトイン化**という破壊的変更を含むため、セルフホスト運用者は要確認。
- **LangChain（Python）** のパートナー統合パッケージが 11-23 に一括メジャー更新。**`langchain-ollama 1.2.0` が Ollama 0.6.3 以上を要求（thinking levels 対応のため）**、`langchain-huggingface 1.3.0` が forced tool choice とストリーミングのトークン数を修正。多くのパッケージで **Python 3.10 サポートが終了**した。

## 今日の注目

### 1. Claude Code / `v2.1.331`

- 種別: CLI
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-11-23 21:34（UTC、JST 11-24 06:34）
- 概要: 不具合修正が中心の更新。**MCP ツール呼び出しがローカル／WebSocket サーバーの不正な応答で最大 30 分ハングする問題を修正**。**rewind が復元に失敗した後にファイルを削除してしまう問題**、`/diff` が 24〜26 行の狭い画面でファイルを選べない・`git add -N` で追加したファイルを表示しない問題、非常に長い会話の圧縮（`/compact`）が特定の XML タグを含むと要約の一部を失う問題なども修正。新機能として、`claude doctor` に **API 到達性チェック**（HTTP ステータスやエラーを表示）、Bedrock / Google Cloud Agent Platform / Microsoft Foundry / Claude Platform on AWS 上のターミナルセッションでの **Code Mode 対応**、プラグインマニフェストの **`optionalDependencies`**、`claude_code.llm_request` トレーススパンへの **`gen_ai.*`（トークン使用量・モデル属性）** 追加、圧縮応答を途中で切るプロキシ向けの `CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION` などを収録。VS Code 拡張には **「Resolve Merge Conflicts」**、エラーやテスト失敗向けの **「Fix with Claude Code」**、Source Control での「Add to Chat」が加わった。
- 何が便利か: MCP ツールの長時間ハングと rewind の誤削除という、実運用で遭遇すると被害が大きい不具合が直った。`claude doctor` の API 接続チェックは、プロキシ環境や社内ネットワークでの疎通切り分けを 1 コマンドで行える。
- 使いどころ: MCP サーバーを常用する環境、rewind を使う作業、プロキシ／ゲートウェイ越しで接続トラブルの切り分けが必要な環境、VS Code でマージコンフリクトやテスト失敗を Claude に任せたいケース。
- 開発者にとっての価値: ツール呼び出しのハングとファイル誤削除の修正は、エージェント運用の安全性・信頼性に直結する。`gen_ai.*` スパン拡充は OpenTelemetry での使用量観測を改善。
- 注意点: Code Mode セッションを別の権限モードで `--resume` / `--continue` すると thinking とプロンプトキャッシュを失う問題の修正を含むが、Code Mode 自体の挙動変更に注意。**2026-11-30 以降、managed `extraKnownMarketplaces` のプラグインマーケットプレイスが既定で自動更新**になる（`"autoUpdate": false` でオプトアウト可）。Windows ではレジストリの managed 設定が起動時にチェックされるため、非 ASCII 値は起動を妨げないか事前確認を。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.331
- 参考リンク: https://code.claude.com/docs/en/changelog
- メモ: 既存記事では `v2.1.330`（11-22 記事）・`v2.1.329`（11-21 記事）まで掲載済み。本記事は未掲載の `v2.1.331` を採用。

### 2. Vercel AI SDK / `ai@7.0.181`

- 種別: OSS / SDK（TypeScript）
- 関連: Vercel AI SDK / AI Gateway
- 公開・更新日: 2026-11-23 21:09（UTC、JST 11-24 06:09）
- 概要: パッチ更新。**`generateText` / `streamText` の結果・`onEnd`・finish part に `stoppedBy` フィールドを追加**し、ツールループが停止した理由を取得できるようにした。呼び出し単位の **`onWarning` コールバック**を追加し、プロンプト変換時の警告をステップ警告に含めるように。ステアリングメッセージ（実行中・実行後に送る誘導メッセージ）について、終了理由を報告し、`prepareStep` がそのテキストをパーツ化したりプロバイダオプションを付けたりした場合も「配信済み」として数えるよう改善。抽出テレメトリではテキスト／ファイルパーツからプロバイダオプションを除外。依存の `@ai-sdk/gateway` を 4.0.154 に更新。直前の `ai@7.0.180` は依存更新のみ（`@ai-sdk/gateway` 4.0.153）。
- 何が便利か: `stoppedBy` で「ツール呼び出し上限に達した」「停止条件を満たした」などループ終了の理由をコードから判別でき、エージェントの打ち切り時の分岐やログが書きやすくなる。`onWarning` で警告を個別に拾える。
- 使いどころ: 複数ステップのツール呼び出し（エージェント）を `generateText` / `streamText` で回し、終了理由に応じてリトライ・フォールバック・UI 表示を分けたいケース。
- 開発者にとっての価値: 従来は終了理由が見えづらかったエージェントループに観測ポイントが増え、デバッグと制御がしやすくなる。既存コードへの影響は小さいパッチ。
- 注意点: パッチ版のため大きな新 API ではない。`stoppedBy` の値の種類は利用するステップ設定・停止条件に依存する。
- 公式リンク: https://github.com/vercel/ai/releases/tag/ai%407.0.181
- 参考リンク: https://github.com/vercel/ai/releases
- メモ: 既存記事では `ai@7.0.179`（Live models over WebSocket、11-23 記事）・`ai@7.0.178`（11-21 記事）まで掲載済み。本記事は未掲載の `ai@7.0.181` を採用。

#### 使用例

```bash
npm install ai@7.0.181
# 結果オブジェクトの result.stoppedBy でループ終了理由を参照できる
```
