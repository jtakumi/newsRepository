## 今日の注目

### 1. Claude Fable 5.2 / `claude-fable-5-2`

- 種別: モデル
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-11-09（Claude Code `v2.1.321` の CHANGELOG に記載）
- 概要: Fable 系列の新しい既定モデル。1M トークンのコンテキストに対応し、価格は入力 $8 / 出力 $40 per Mtok、キャッシュ読み出しは $0.20/Mtok。保存済みの Fable 5.1 の選択は自動的に総称 `fable` に寄せられ、明示的に戻すには `/model claude-fable-5-1` を使う。
- 何が便利か: 1M コンテキストを比較的安価に使えるため、長いログ・大きなコードベース・複数ファイルの要約や調査を 1 回のコンテキストに詰めやすい。キャッシュ読み出しが $0.20/Mtok と安く、同じ前提コンテキストを繰り返し使うエージェント用途でコストを抑えられる。
- 使いどころ: 大量の仕様書・議事録・ログの一括要約、巨大なモノレポを対象にした調査、同一の長いシステムプロンプトを使い回す自動化パイプライン。
- 開発者にとっての価値: Claude Code 内で `/model` を切り替えるだけで即試せる。コスト重視のバッチ処理やドラフト生成を、Opus 系より安い枠で回す選択肢が増える。
- 注意点: ベンチマークや「どのタスクで Opus/Sonnet に劣るか」は公式に数値が出ていないため、精度が要る本番処理では自分のタスクで比較してから採用するのが安全。現時点で確認できる一次情報は Claude Code の CHANGELOG 記載。
- 公式リンク: https://code.claude.com/docs/en/changelog
- 参考リンク: https://docs.claude.com/en/docs/about-claude/models
- メモ: 「既定 Fable モデルが 5.2 に切り替わった」ため、Fable を指定していた既存ワークフローは挙動が変わる可能性がある。固定したい場合はモデル ID を明示する。

#### 使用例

```bash
# Claude Code 内でモデルを切り替えて試す
/model claude-fable-5-2

# 旧 Fable 5.1 に戻したい場合
/model claude-fable-5-1
```

### 2. Claude Code / `v2.1.321`

- 種別: CLI
- 関連: Claude / Anthropic
- 公開・更新日: 2026-11-09
- 概要: 新機能として Claude Fable 5.2 の追加に加え、`claude remote-control` に `--settings <file>` が入り、起動する全セッションへ同じ設定ファイルを適用できるようになった。VS Code で認証トークンと API キーの両方が設定されている場合に警告が出る。修正は 74 件で、MCP OAuth リクエストがサーバーのリダイレクト先にリフレッシュトークンなどのシークレットを送らないよう修正、読み取り専用 Bash コマンドが権限プロンプトなしでサンドボックス外実行されていた問題の修正を含む。
- 何が便利か: `--settings` により、リモートコントロールで複数セッションを立ち上げる際の権限・設定を 1 ファイルで統一できる。セキュリティ修正は、MCP サーバー連携や自動実行を多用する環境のリスクを下げる。
- 使いどころ: CI やリモート環境で Claude Code を多数起動する運用、複数の MCP サーバーを繋いだエージェント構成、サンドボックス権限を厳密に管理したいチーム。
- 開発者にとっての価値: 設定の一元化で再現性が上がり、OAuth シークレット漏えい・サンドボックス回避という実害につながりうる穴が塞がれる。該当構成を使っているなら更新価値が高い。
- 注意点: 読み取り専用 Bash のサンドボックス挙動が変わるため、従来「無確認で通っていた」コマンドがプロンプト対象になる可能性がある。自動化スクリプトで権限設計を見直すとよい。
- 公式リンク: https://code.claude.com/docs/en/changelog
- 参考リンク: https://docs.claude.com/en/docs/claude-code/overview
- メモ: npm の `latest` / `next` 更新タイミングと `stable` タグの進み方は差があるため、安定運用は `stable`、新機能検証は最新版という使い分けが無難。

#### 使用例

```bash
# 最新版へ更新
npm install -g @anthropic-ai/claude-code@latest

# リモートコントロールで共通設定を全セッションに適用
claude remote-control --settings ./team-settings.json
```

### 3. Claude Code / `v2.1.322`

- 種別: CLI
- 関連: Claude / Anthropic / Google Cloud (Vertex AI)
- 公開・更新日: 2026-11-10
- 概要: Vertex AI 経由の利用で、global / us / eu の各リージョンに「fast mode」が追加された。Vertex 側が fast mode を拒否した場合は標準速度へフォールバックする。
- 何が便利か: Vertex AI を課金・ガバナンスの基盤にしている組織でも、応答の速いモードを使えるようになった。拒否時は自動で通常速度に落ちるため、設定を変えても処理が止まらない。
- 使いどころ: 料金やデータ所在の都合で Vertex AI 経由に統一している企業環境での対話的コーディング、レイテンシを下げたい日常のコード編集。
- 開発者にとっての価値: これまで直接 API 利用でしか得られなかった高速応答を、Vertex 経由の構成でもリージョンを選んで使える。リージョン指定でデータ所在要件と速度を両立しやすい。
- 注意点: fast mode が使えるかは Vertex 側の対応・リージョンに依存し、拒否されれば標準速度になる。別途、Opus 4.8 向け fast mode は 2026-11-30 に廃止予定（Opus 5.5 へ移行が必要）という告知も継続中なので、モデルとモードの組み合わせは確認しておく。

- 参考リンク: https://docs.claude.com/en/docs/claude-code/third-party-integrations
