# 2026-11-08 AI Tools News

## 今日の要点

- OpenCode `v2.2.6` が公開。MCP 接続のプール（`pool: true`）で同一設定の MCP サーバを 1 接続に集約でき、プロセス削減と起動高速化に効く。モデル呼び出し前に接続中の MCP サーバを最大 2 秒待つようになり、最初のプロンプトから MCP ツールが使いやすくなった。`opencode run -w`（worktree 実行）も追加。
- Qwen Code `v0.27.0`（安定版）が公開。ローカルセッション向けの `FileChanged` フック通知、URL 指定での PR ウォッチ、チャンネルの GitHub リポジトリイベントフィルタ（許可/拒否リスト）などを追加。`sed` の `.`・ブラケット処理の修正や、キャンセルしたシェルを「中断」として報告する修正も入った。
- GitHub Copilot CLI `1.0.108-1`（プレリリース）が公開。Grok 4.7/4.6 で PDF 添付がターンを失敗させず「ファイル参照」にフォールバックするよう修正。サンドボックス有効時、`/cd` 後に再起動するローカル MCP サーバが移動先ディレクトリの拒否パスを使うよう修正。安定版は引き続き `1.0.107`。

## 今日の注目

### 1. OpenCode / `v2.2.6`

- 種別: CLI / OSS（AIコーディングエージェント）
- 関連: OpenCode / MCP
- 公開・更新日: 2026-11-06（GitHub Releases, Latest / UTC 23:37、日本時間 11-07 早朝）
- 概要: MCP 接続まわりの実用改善が中心のリリース。複数プロジェクトで同じ MCP サーバを使う構成や、起動直後から MCP ツールを使いたい構成で効く。
- 何が便利か:
  - MCP 接続プール（オプトイン `pool: true`）: 同一の MCP サーバ設定を持つプロジェクト同士が 1 つの接続を共有。プロセス数が減り、起動が速くなる。
  - モデル呼び出し前に、まだ接続中の MCP サーバを最大 2 秒待機。接続が速いツールは最初のプロンプトから使える。
  - MCP の細かな修正: ローカル作業ディレクトリでの `~` 展開、レガシー stdio サーバの取り扱い、動的登録時の `logo_uri` 送信。MCP サインインが（自動リダイレクト不可時に）貼り付けたリダイレクト URL を受理し、サインイン後は TUI が `/mcp` 一覧へ戻る。
  - `opencode run -w` で worktree を対象に実行、`--archived` でスクリプト実行に対応。GUI プラグインのテーマ/スロット、モバイル用コンポーザドックも追加。
- 使いどころ: 複数リポジトリで共通の MCP サーバ（DB、検索、社内ツール等）を使い回す構成で、接続を集約してリソースを節約したい場面。git worktree を併用した並行作業。
- 開発者にとっての価値: 「MCP サーバを何本も立ち上げてプロセスが増える」「起動直後は MCP ツールがまだ使えない」といった実運用の摩擦に直接効く。worktree 実行で複数ブランチ作業にも載せやすい。
- 注意点: 接続プールはオプトイン。共有して問題ないサーバ（状態を持たない/マルチクライアント前提のサーバ）に限って有効化すること。直前の `v2.2.5` で「10MiB 超の stdio メッセージで切断しない」などの MCP 修正も入っている。
- 公式リンク: https://github.com/sst/opencode/releases/tag/v2.2.6
- 参考リンク: https://github.com/sst/opencode/releases
- メモ: `process-daemon v0.5.0`（opencode-pty 0.5.0 / protocol 8、`@opencode/pty@0.5.0`）も前後して公開。

#### 使用例

```bash
# 更新（インストール方法に応じて）
npm install -g opencode-ai   # もしくは curl -fsSL https://opencode.ai/install | bash

# MCP サーバ設定で接続プールを有効化（opencode.json の例）
#   {
#     "mcp": {
#       "my-server": { "type": "local", "command": ["my-mcp"], "pool": true }
#     }
#   }

# git worktree を対象にスクリプト実行
opencode run -w ../feature-worktree "テストを実行して失敗を要約"
```

### 2. Qwen Code / `v0.27.0`

- 種別: CLI / OSS
- 関連: Qwen / その他（Gemini CLI 系フォーク）
- 公開・更新日: 2026-11-07（GitHub Releases, Latest / 安定版、UTC 20:45）
- 概要: フック・PR 連携・チャンネル周りの機能追加と、シェル/`sed` 系の挙動修正が中心の安定版。前回記事（11-03）時点の `v0.26.6` からの更新。
- 何が便利か:
  - ローカルセッションで `FileChanged` の通知フックに対応。ファイル変更を起点にした自動処理を組みやすい。
  - PR を URL 指定で PR 状態ウォッチに追加できる。チャンネルの GitHub リポジトリイベントフィルタが許可/拒否リストに対応し、アイドルなチャンネルセッションを回収可能に。
  - マネージドエージェントの基本ツールをデーモンと整合。子エージェントへの同時質問に対応。
  - 修正面: キャンセルしたシェルを「完了」ではなく「中断」として報告、`sed` の `.` とブラケット表現の扱いを修正、Anthropic のリフューザル詳細を表示、ユーザ指示をモデルリクエストの最後に保持。
- 使いどころ: ファイル変更をトリガにした補助処理や、PR をウォッチしながらチャンネルで作業を回す運用。`sed`/シェルの取り扱いが厳密になったので、スクリプト実行の信頼性を上げたい場面。
- 開発者にとっての価値: フック・PR・チャンネルの連携が強化され、エージェントを「監視して反応する」運用に寄せやすい。TypeScript 7 のネイティブコンパイラでクリーンにビルドできるようになった点も、拡張・ビルドまわりの地固めとして効く。
- 注意点: `v0.26.9-nightly.*` など nightly も並行配布。常用は安定版の `v0.27.0` を推奨。多くの追加はウェブシェル/チャンネル基盤向けで、CLI 単体利用では恩恵が及ばない変更も含む。
- 公式リンク: https://github.com/QwenLM/qwen-code/releases/tag/v0.27.0
- 参考リンク: https://github.com/QwenLM/qwen-code/releases
- メモ: 期待どおり PR のコメントが PR バインドセッションに届く、バインド済みの開いている PR を全てウォッチする、などチャンネル連携の修正も複数。

#### 使用例

```bash
# インストール / 更新
npm install -g @qwen-code/qwen-code

# バージョン確認
qwen --version   # 0.27.0

# ヘッドレス実行（非対話）
qwen -p "変更ファイルの差分を要約して"
```

### OpenCode / MCP 接続プール `pool: true`（`v2.2.6`）

選定理由:

- 「MCP サーバを複数プロジェクトで使うとプロセスが増える／起動が遅い」という実運用の摩擦に直接効く、効果が分かりやすい機能。
- 設定ファイルにフラグ 1 つ（`pool: true`）を足すだけで試せる導入しやすさ。
- モデル呼び出し前の最大 2 秒の待機と合わせて、「最初のプロンプトから MCP ツールが使える」体験改善まで一貫している。

最初に試すこと:

```bash
# opencode.json の MCP サーバ設定に pool を追加して有効化
#   {
#     "mcp": {
#       "my-server": { "type": "local", "command": ["my-mcp"], "pool": true }
#     }
#   }

# 起動して /mcp で接続状態を確認
opencode
#   > /mcp
```
