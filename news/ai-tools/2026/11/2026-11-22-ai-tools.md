## 今日の注目

### 1. Claude Code / v2.1.330

- 種別: CLI
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-11-20（UTC 19:16 / JST 11-21 04:16）
- 概要: 追加点: Enterprise Admin Console 管理組織へのサインイン、グラフを描く組み込み mod「easel」（Pro・Max、Team／Enterprise は条件付き、macOS／Linux。`/config` で自動チャートをオフにできる）、短いサインインリンクが問題を起こす場合の `CLAUDE_CODE_FULL_SIGN_IN_LINK=1`、クラウド／セルフホストランナーのセッションで、セッションのリポジトリ以外のプラグインマーケットプレイスを取得できない場合の通知、`claude plugin install --json` の `commandPrinted`／`commandFailed`、セルフホストランナー `/metrics` の登録・初回セッションまでの時間メトリクス。改善は、`/login`・`claude auth login`・`claude setup-token` のサインインリンクが大幅に短縮されたこと、ファイル diff の高速化、`/config` 検索（「effort」で Model、「dark」「light」で Theme）、`/resume` から画面を開いただけのセッションを除外、`/mcp`・`/plugin` の Reconnect がサーバーの失敗や要サインインのとき原因を見せたままページを維持。修正は、とても長い会話の圧縮直後に数分間固まる問題、WebFetch が一部ページで数分間セッションを固めたり空の結果を返したりする問題、`ExitWorktree` や終了ダイアログが別の実行中セッションで使われている worktree を削除する問題、複数プロセスが同時に保存するとユーザー設定の変更が失われる問題、`--continue`／`--resume` が最終メッセージのタイムスタンプ欠落で空セッションを開く問題、Linux／WSL で 2 分以上スリープ後の最初のプロンプトが死んだ接続で 3 分待たされる問題。
- 何が便利か: 長い会話の圧縮後フリーズ、WebFetch の長時間固まり、worktree の誤削除など、使っていて痛い不具合がまとめて直った。サインインリンクも短くなり、端末での貼り付けや共有が楽になる。
- 使いどころ: 長時間セッションを常用するユーザー、複数の Claude Code プロセスや worktree を並行して使う運用、Enterprise Admin Console で組織管理している企業、`/mcp`・`/plugin` の再接続を多用する環境。
- 開発者にとっての価値: 別セッションが使っている worktree を消さない修正や、設定同時保存の取りこぼし修正は、並列運用の安全性に直結する。
- 注意点: easel は対象プランが限られ、macOS／Linux のみ。ほか `CLAUDE_CODE_FULL_SIGN_IN_LINK=1` はサインインリンクの形式を変えたい場合のみ。
