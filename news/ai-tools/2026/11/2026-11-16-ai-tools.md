### 1. LlamaIndex / `v0.14.26`

- 種別: OSS / RAG・エージェントフレームワーク（Python）
- 関連: LlamaIndex / Anthropic・OpenAI・AWS Bedrock・Azure
- 公開・更新日: 2026-11-13（安定版、リリースノート日付 2026-11-13・JST 11-14 早朝）
- 概要: 多数の統合パッケージをまとめて更新した安定版。**新モデル対応**として、`llama-index-llms-anthropic 0.12.3` に **Claude Opus 5.5 / Sonnet 5.5 / Haiku 5.5**、`llama-index-llms-bedrock-converse 0.15.5` に **Claude 5.5 系と OpenAI GPT-6 Sol/Luna/Astra**、`llama-index-llms-openai 0.8.4`／`llama-index-llms-azure-openai 0.6.1` に **GPT-6 Astra/Sol/Luna**（さらに OpenAI 側に **GPT-6.1 Sol**）を追加。**セキュリティ対応として全統合の `uv.lock` を再生成**（#24039、ロックのみで Python フロア変更なし）、**セキュリティ修正に伴い各統合の最低 Python バージョンを引き上げる BREAKING 変更**（#24040）を含む。`llama-index-core 0.14.26` は `langchain-community` の非推奨で壊れていた langchain ブリッジ取り込みを修正。`llama-index-protocols-ag-ui 0.6.0` はプロデューサのコンテンツ変換を **ag-ui プロトコル 1.0** へ移行。Google GenAI 0.11.3 は既定 temperature を Gemini 3 以前のモデルにのみ適用するよう変更。
- 何が便利か: RAG／エージェントの土台を保ったまま、最新世代モデル（Claude 5.5・GPT-6 系）をコード側のモデル指定だけで使えるようになる。統合のロックファイル再生成でサプライチェーン面の衛生も担保。
- 使いどころ: LlamaIndex で既存の RAG・エージェントを運用していて、Claude 5.5 や GPT-6 系に素早く載せ替えたいケース。Bedrock／Azure 経由でこれらを使う構成。
- 開発者にとっての価値: フレームワーク側がモデル追従してくれるため、プロバイダ差異を吸収したまま新モデル評価に入れる。セキュリティ再ロックは本番依存の更新判断の後押しになる。
- 注意点: **最低 Python バージョン引き上げは BREAKING**。CI やランタイムの Python が古い場合はアップグレード前に確認が必要。多数の統合パッケージが同時に版上げされるため、固定している場合は影響範囲を確認する。
- 公式リンク: https://github.com/run-llama/llama_index/releases/tag/v0.14.26
- 参考リンク: https://github.com/run-llama/llama_index/releases
- メモ: 直近の AI Tools News（11-13〜11-15）では LlamaIndex は未掲載（11-02 に別バージョンの言及あり）。本項は新規の安定版 `v0.14.26`。

### 2. LangChain（JS） / `langchain@1.6.6`・`@langchain/google@0.2.15` ほか

- 種別: OSS / SDK（TypeScript・JavaScript）
- 関連: LangChain / Google Gemini・Anthropic
- 公開・更新日: 2026-11-13 18:26 UTC（JST 11-14 早朝）
- 概要: 安定版パッチの一括公開。**`@langchain/google@0.2.15`** は **Gemini 4 Hydrogen のモデルプロファイル**と **`XHIGH` 思考レベル**に対応（未対応モデルでは `HIGH` に自動低減、レベルベースのモデルには将来のレベルもパススルー）、**Gemini 4 Carbon の capability プロファイル**も追加。**`langchain@1.6.6`** は、ツール呼び出しやサブエージェントの失敗時に `output` の Promise が未消費でもプロセスが落ちない修正と、`wrapModelCall` 経由で渡された `Command` を外側ミドルウェアが一度だけ適用する修正。**`@langchain/anthropic@1.6.5`** は `AnthropicToolsOutputParser` が `tool_calls` にフォールバックし、ストリーミング内容が `tool_call` ブロックに正規化される場合でも `withStructuredOutput` が機能するように修正。**`@langchain/core@1.4.1`** はストリーミングの `input_json_delta` ブロックを同じインデックスの直前の `tool_use`／`server_tool_use` にマージする修正。
- 何が便利か: Gemini 4 系の思考レベル（`XHIGH`）とモデルプロファイルにフレームワーク側が追従。構造化出力（`withStructuredOutput`）がストリーミング時に取りこぼさなくなり、エージェントのツール失敗がプロセス全体を落とさなくなる。
- 使いどころ: LangChain JS で Gemini／Claude をマルチステップのエージェントに組み込み、構造化出力やストリーミングを使っている構成。思考レベルを細かく制御したいケース。
- 開発者にとっての価値: パッチだが、構造化出力の信頼性とエージェント実行の堅牢性という実務上効く箇所を直接改善する。Gemini 4 への追従も先取りできる。
- 注意点: Gemini 4 Hydrogen/Carbon は利用側のモデルアクセス可否に依存する（フレームワーク対応と実際の利用可否は別）。複数パッケージを使う場合はバージョンの整合に注意。
- 公式リンク: https://github.com/langchain-ai/langchainjs/releases/tag/%40langchain%2Fgoogle%400.2.15
- 参考リンク: https://github.com/langchain-ai/langchainjs/releases
- メモ: 直近の AI Tools News（11-13〜11-15）では LangChain JS は未掲載。本項は新規の安定版パッチ群。

### 3. OpenAI Python SDK / `v3.51.0`

- 種別: OSS / SDK（Python）
- 関連: OpenAI / ChatGPT・Realtime・MCP
- 公開・更新日: 2026-11-13 21:12 UTC（リリースノート見出し 2026-11-12・JST 11-14 早朝）
- 概要: API サーフェス拡張の安定版（#4269）。**画像編集で SVG 出力を要求**でき、SVG 生成のオプションを追加。**Realtime（Live）セッションに safety identifier を設定**でき、**`live.transport.connected` webhook** を処理（webhook union に登録）。**エージェントの prompt-cache ライフタイム設定**と **MCP ツール承認リクエストの処理**（承認の入力・応答型）を追加。管理系では **OCI Vault の外部キー設定**に対応（`resources/admin/organization/external_keys.py`）。
- 何が便利か: 画像編集からベクター（SVG）を直接得られるとラスタ変換の後工程が省ける。Realtime の safety identifier と接続 webhook で音声・リアルタイム系の運用（不正利用検知・接続監視）がやりやすくなる。エージェントの MCP ツール承認が SDK レベルで扱える。
- 使いどころ: OpenAI SDK で画像編集・Realtime・エージェント（MCP 連携）を使っているアプリ。OCI 上で外部キーを管理する組織構成。

- 注意点: リリースノートは1行の要約のみで、具体的な引数・型は PR #4269／生成コードを参照する必要がある。SVG 出力・Live 機能は対象モデル／エンドポイント側の対応に依存する。

- メモ: 直近の AI Tools News（11-13〜11-15）では OpenAI Python SDK は未掲載。本項は新規の安定版 `v3.51.0`。
