## 今日の注目

### 1. Claude Code / v2.1.210 / v2.1.211

- 種別: CLI
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: `v2.1.210` は 2026-07-14（UTC 19:39 / JST 07-15 04:39）、`v2.1.211` は 2026-07-15（UTC 19:24 / JST 07-16 04:24）
- 概要: 定期更新 2 本。`v2.1.210` は、長時間のツール呼び出しが固まって見えないよう経過時間カウンタを追加し、`Write(path)`・`NotebookEdit(path)`・`Glob(path)` の権限ルール（パス指定が効かない書き方）に起動時警告を出すようにした。修正では、worktree 分離のサブエージェントが本体チェックアウトに対し git の変更系コマンドを実行できた問題、webhook ペイロードなど人以外由来の入力で `ultracode` キーワードのオプトインが発火する問題、フックのタイムアウトがユーザー拒否として誤報告され無人セッションが止まる問題、Grep が結果末尾を超えたページ送りで「No matches found」と誤表示する問題などを直した。Agent ツールに対しては、サブエージェントが読んだ内容経由の間接プロンプトインジェクション対策を強化。auto モードの権限分類器は外部セッションの既定が Sonnet 5 になった。`v2.1.211` は `--forward-subagent-text` / `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT` を追加し、チャット連携に中継される権限プレビューで双方向オーバーライドやゼロ幅文字・類似引用符を無害化、auto モードが PreToolUse フックの `ask` を上書きしないよう修正、スリープ復帰後に複数セッションが一斉ログアウトする問題・Vertex/Bedrock での不要なフォールバック通知・Bedrock/Vertex/Mantle/Foundry でプロンプトキャッシュの末尾ブロックが毎回新規入力として課金される回帰を修正した。
- 何が便利か: 無人・バックグラウンド運用で「止まって見える」「勝手に許可される」といった取りこぼしが減る。特に worktree 分離サブエージェントの封じ込めと、フックの `ask` が auto モードで尊重される点は、権限まわりの安全性に直結する。
- 使いどころ: サブエージェントを並列に走らせる開発フロー、Webhook／PR コメントを入力に取り込む自動化、Bedrock・Vertex・Foundry 経由で利用していてキャッシュ課金が気になる環境。
- 開発者にとっての価値: セキュリティ寄りの修正（間接プロンプトインジェクション対策、権限プレビューの制御文字対策、フック `ask` の優先）が複数入っており、エージェントを無人で動かすチームは早めに追従する価値が高い。
- 注意点: ルール表記が `Write(path)` / `NotebookEdit(path)` / `Glob(path)` になっている設定は、起動時警告のとおり `Edit(path)` / `Read(path)` に置き換えること。Bedrock/Vertex/Mantle/Foundry のキャッシュ課金回帰は `v2.1.211` で修正。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.210 / https://github.com/anthropics/claude-code/releases/tag/v2.1.211
- 参考リンク: https://code.claude.com/docs/en/changelog
- メモ: `v2.1.211` で、`/loop` が 1 回使うと `/resume` から消える問題、`/clear` でコストカウンタがリセットされない問題、Vim モードの `s`/`S` が NORMAL モードで効かない点なども整理されている。
