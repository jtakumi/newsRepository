## 今日の注目

### 1. Claude Code / `v2.1.304`

- 種別: CLI
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-10-19（GitHub CHANGELOG / Releases）
- 概要: `/auto-mode-setup` が追加され、プロジェクト構成と直近のセッションを読み取ってオートモードに環境を学習させるガイド付きセットアップが使えるようになった。オートモードは Bedrock / Vertex / Foundry / Claude アプリゲートウェイ / テレメトリ無効セッションでも利用可能に。
- 何が便利か: オートモードを使い始める際の設定作業を対話形式で肩代わりしてくれる。`rm -r` をマウント済みドライブや `/Volumes`・`/media`・`/mnt/c` などのトップレベルに対して実行する際、`rm -rf /Applications` と同じ安全プロンプトが出るようになり、破壊的操作の事故を防ぎやすい。
- 使いどころ: 既存リポジトリでオートモードを導入したいとき、まず `/auto-mode-setup` を走らせて環境を学習させる。LLM ゲートウェイ経由で `context_management: Extra inputs are not permitted` エラーに遭遇していたケースも自動リトライで解消される。
- 開発者にとっての価値: ゲートウェイ（Bedrock / Vertex / Foundry）利用者でもオートモードとツール検索（カスタム `ANTHROPIC_BASE_URL` 配下で既定有効化、400/422 時は外して再試行）が使えるようになり、エンタープライズ構成での取り回しが改善した。`CLAUDE_CODE_AUTO_COMPACT_WINDOW` が `k`/`M` サフィックスを受け付ける（`200k` が 100K と誤読されない）。
- 注意点: Mod（プラグインフック）の `tool.check` 応答が `decider: "person"` を受け付ける仕様変更あり。独自フックを持つ場合は挙動を確認したい。
- 公式リンク: https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- 参考リンク: https://github.com/anthropics/claude-code/releases
- メモ: 直前の `v2.1.303`（10-18）は「Bug fixes and reliability improvements」のみ。実質の機能追加は `v2.1.304`。

#### 使用例

```bash
# Claude Code を最新へ更新
npm install -g @anthropic-ai/claude-code@latest

# オートモードのガイド付きセットアップ
claude
# 対話内で
/auto-mode-setup
```

### 2. GitHub Copilot CLI / `v1.0.100`（安定版）・`v1.0.101-0`（プレリリース）

- 種別: CLI
- 関連: GitHub Copilot
- 公開・更新日: 2026-10-19（GitHub Releases）
- 概要: このページ最大の安定版リリース。GitHub のインストールリンクから検証済み Skill / Plugin を導入できるようになり、`/sessions`・`/session`・`/resume` が統合セッションブラウザ（Unified Sessions browser）に刷新。`--trust-folder` と `--disable-client-telemetry` フラグ、全画面の `/share` メニューが追加された。`.github/instructions` 配下のパス別インストラクションファイルが自動適用され、組み込みブラウザプラグインは `browser-use` に改名。
- 何が便利か: セッション管理が 1 つのブラウザ UI に集約され、過去作業の再開が探しやすい。Skill / Plugin を GitHub リンクから入れられるので配布・導入がシンプル。サンドボックスは既定でローカルネットワークアクセスを許可。
- 使いどころ: チームで共有する手順を `.github/instructions` にパス別で置いておくと、該当ファイルを触るときだけ自動適用される。`--trust-folder` でプロンプトモード時の信頼フォルダを明示できる。
- 開発者にとっての価値: プレリリース `v1.0.101-0` では対応モデルでの動的ワークフローサブエージェント向けネイティブ構造化出力と、Assisted Permissions 用の `assistedApprovalInstructions` 設定が追加。セッション途中での GPT→Gemini モデル切り替え不具合や、モデル未選択時の起動ハングも修正された。
- 注意点: 10-19 時点の最新安定版は `v1.0.100`、`v1.0.101-0` はプレリリース。Microsoft Entra サインインが改善され、管理者設定が選択モデルを上書きした場合に通知が出る。
- 公式リンク: https://github.com/github/copilot-cli/releases/tag/v1.0.100
- 参考リンク: https://github.com/github/copilot-cli/releases
- メモ: 10-19 記事で扱ったのはプレリリース `v1.0.100-1`（10-16）。今回は安定版 `v1.0.100` と新プレリリース `v1.0.101-0` で別リリース。

#### 使用例

```bash
# インストール / 更新
npm install -g @github/copilot

# 信頼フォルダを指定して起動（プロンプトモード）
copilot --trust-folder .

# 統合セッションブラウザ
copilot
# 対話内で
/sessions
```

### 3. Vercel AI SDK / `ai@7.0.144`（＋ `ai@6.0.311`）

- 種別: OSS / ライブラリ（TypeScript）
- 関連: Vercel AI SDK / Perplexity
- 公開・更新日: 2026-10-19（GitHub Releases / npm）
- 概要: `ai@7.0.144` が Perplexity の decisions API に対応。低メモリ版ストリーミングが `experimental_streamTextLowMemory` という独立関数に移され、`streamText` の戻り値型の不整合が解消された。`ai@6.0.311` は `streamText` の transform が `stopStream` を呼んだ後にバッファ済みストリームパートを出さないよう修正。
- 何が便利か: 大きな出力を扱うアプリでメモリ使用を抑えたいときに、低メモリ経路が専用関数として明確化され、型も正しくなった。Perplexity をワークフローに組み込みやすくなった。
- 使いどころ: サーバーレスやエッジでストリーミング出力のメモリ上限が気になるケースで `experimental_streamTextLowMemory` を使う。既存コードで `experimental_lowMemory` を使っていた場合は新関数への置き換えが必要。
- 開発者にとっての価値: 型の不整合が消えたことで `streamText` の戻り値を安全に扱える。`ai@6.0.x` 系にも並行してバグ修正が入っており、v6 を維持しているプロジェクトも恩恵を受けられる。
- 注意点: `experimental_lowMemory` → `experimental_streamTextLowMemory` は破壊的変更。アップグレード時に移行が必要。`@ai-sdk/*` プロバイダ各種は依存更新のみ（機能変更なし）。
- 公式リンク: https://github.com/vercel/ai/releases/tag/ai%407.0.144
- 参考リンク: https://github.com/vercel/ai/releases
- メモ: 10-16 記事で扱ったのは `ai@7.0.142` / `ai@6.0.308`。今回はより新しい版で、低メモリストリーミングの API 変更が主眼。

#### 使用例

```bash
# インストール / 更新
npm install ai@latest
```
