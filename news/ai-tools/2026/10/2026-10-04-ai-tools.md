## 今日の注目

### 1. Claude Mods（Claude Code の新モディング層）

- 種別: 拡張機能 / SDK（プラグイン機構）
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-10-02〜10-03 頃（`v2.1.287` で capability 追加、`v2.1.288` で拡張。`v2.1.286` までは 10-01 版で既報）
- 概要: Claude Mods は、従来の「指示（CLAUDE.md / スキル）」や「外部ツール（MCP）」ではなく、Claude Code のハーネス（コンテキストを組み立て、ツールを呼び、セッションを描画するソフトウェア層）そのものに関数フックで介入するプラグイン機構。エンジンのイベントや UI 描画に参加できる。
- 何が便利か: プロンプトの書き換え、ツール呼び出しのブロック/リトライ、権限判定、シークレットの秘匿、画面要素の差し替えといった「エージェントループの各所への割り込み」をコードで書ける。公開リポジトリには組み込み例（agents.md ローダー、差分パネル、テレメトリ、組織セキュリティ用 mod）が同梱され、実装を読んで学べる。`v2.1.287` では背景で問題を知らせる "You should know" 組み込み mod、`v2.1.288` ではフルスクリーン時の選択テキストを取得する `$.ui.selection()` が追加された。
- 使いどころ: 社内ポリシーの強制（危険なツール呼び出しを止める、出力からシークレットを落とす）、独自の権限フロー、チーム固有のUI/通知の追加など。MCP で十分な外部連携は MCP に寄せ、ハーネス自体の挙動を変えたいときだけ Mod を使うのが推奨。
- 開発者にとっての価値: これまで設定ファイルやスキルでは届かなかった「ツール実行や権限判定の途中」にフックできるため、Claude Code をチームの運用ルールに合わせて深くカスタマイズできる。
- 注意点: インターフェースは早期アクセスで、リリース間で API が予告なく変わり得る。最小の仕組み（まずは設定・スキル・MCP）で足りるなら Mod は避け、本当に必要な箇所に限定するのが安全。
- 公式リンク: https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- 参考リンク: https://code.claude.com/docs/en/overview
- メモ: 更新は `claude update`（または再インストール）後に `claude --version` で `2.1.287` 以上を確認。本記事の「今日試すならこれ」で最小の試し方を示す。

### 2. OpenAI Codex CLI / `v0.160.0`（+ `0.162.0-alpha` 系）

- 種別: CLI
- 関連: OpenAI / Codex
- 公開・更新日: `0.160.0` は 2026-10-01 20:19 UTC（JST 10-02 早朝）。`0.162.0-alpha.7`〜`alpha.11` が 10-02〜10-03 UTC（JST で 10-04 未明まで）に連続リリース。
- 概要: 安定版 `0.160.0` が公開。エージェント・コマンドセンターで過去タスクをキーボード操作の「Show more」でたどれるようになり、プロジェクト外からでもワークスペース既定でセッションを開始できるようになった。会話履歴を取得する Guardian レビュー機能も追加。Linux X11 端末のフルスクリーンでのミドルクリック貼り付けにも対応。
- 何が便利か: 長時間回したエージェントの過去タスクを探しやすくなり、リポジトリ外の雑多な作業でもすぐ起動できる。プラグインマニフェストのキャッシュと HTTP 接続の再利用、未使用 DB 領域の回収といった性能改善も入り、起動・反復のもたつきが減る。10-01 版で既報の `0.159.x` からの継続更新で、78 PR 相当の修正を含む。
- 使いどころ: Codex を日常のターミナル常駐エージェントとして使う開発者。プロジェクト横断の調べ物やワンオフ作業を、プロジェクトを開かずに回したいとき。
- 開発者にとっての価値: CLI ベースのエージェント運用でのUX・安定性・起動速度の底上げ。安定版を追いつつ、先行機能を見たい場合は alpha 系も選べる。
- 注意点: `0.162.0-alpha` 系はプリリリース。業務利用は安定版 `0.160.0` を基本に。alpha は詳細な変更履歴が付かない自動リリースのため、挙動確認は自己責任で。
- 公式リンク: https://github.com/openai/codex/releases
- 参考リンク: https://github.com/openai/codex
- メモ: 更新は `npm install -g @openai/codex`（または `brew upgrade codex`）後に `codex --version` で確認。

#### 使用例

```bash
# 更新してバージョン確認
npm install -g @openai/codex
codex --version   # 0.160.0 以上を確認

# 起動（プロジェクト外でもワークスペース既定で開始できる）
codex
```

### 3. Claude Code / `v2.1.287`・`v2.1.288`（Mods 以外の開発者向け更新）

- 種別: CLI / 拡張機能
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-10-02〜10-03 頃（CHANGELOG 最新。`v2.1.286` までは 10-01 版で既報）
- 概要: Mods 以外にも日常作業に効く更新が入った。`/code-review` に `--max-findings` オプション、クラウドセッションで GitHub CLI 無しでも使える組み込み `gh api`、セッション検索の Ctrl+F とグループ移動の Alt+↑/↓、Ctrl+C で消したプロンプトの復元、MCP サーバーが追加 OAuth スコープを要求した際の再認証プロンプト、エージェント一覧の `n:<text>`（セッション名）フィルタなど。
- 何が便利か: コードレビューの指摘件数を絞れて出力を扱いやすくなり、クラウド実行環境で `gh` を別途入れずに GitHub API を叩ける。長い履歴からのセッション検索、誤って消したプロンプトの復帰で、対話のやり直しコストが下がる。
- 使いどころ: Claude Code を常用し、`/code-review` をCIや日次レビューに組み込んでいるチーム。クラウド/リモートセッションで GitHub 連携を使う場合。
- 開発者にとっての価値: レビュー運用・GitHub 連携・セッション操作まわりの地味だが効く効率化。既存ワークフローにそのまま乗る。
- 注意点: バージョンにより一部は managed 設定や環境依存。`--max-findings` の既定挙動は指定が記憶される点に注意（`default` で戻す）。
- 公式リンク: https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- 参考リンク: https://code.claude.com/docs/en/overview
- メモ: `claude update` 後、`/code-review --max-findings 5` のように件数を絞って試すのが手早い。
