- 使いどころ: Claude Code を常用し、mods・プラグイン・MCP を併用しているチーム。特に 10-04 の `v2.1.287`/`288` で mods を導入した人の安定化アップデートとして。

- 注意点: 細かな修正の集合で、環境によっては該当しない項目もある。影響範囲は公式 CHANGELOG の該当エントリで確認するのが確実。
- 公式リンク: https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md

### 2. GitHub Copilot CLI / `v1.0.92` 系（`copilot config` と Ctrl+E 環境ピッカー）

- 種別: CLI
- 関連: GitHub Copilot
- 公開・更新日: 安定版 `v1.0.91`（2026-10-01 17:25 UTC）。プレリリース `v1.0.92-0`〜`-4`（10-01〜10-04 UTC）。`copilot config` は `v1.0.92-4`（10-04）、Ctrl+E 環境ピッカーは `v1.0.92-3`（10-02）で追加。
- 概要: プレリリース系で設定管理と実行環境の切替が強化された。`copilot config` サブコマンドで設定の一覧・取得・設定・削除ができ、会話を始める前に Ctrl+E でローカル実行とクラウド実行を切り替える環境ピッカーが追加。あわせてサンドボックスのプロキシ CA 信頼の確認/作成/信頼/ローテーション/削除（Windows の無人セットアップ含む）、多数の MCP サーバーを同時接続した際の起動応答改善、shell コマンドの stdout/stderr のライブストリーミング安定化なども入った。
- 何が便利か: 設定を CLI から直接いじれ、ローカル/クラウドの実行先をキー操作で切り替えられる。MCP を多数積んでも起動が重くなりにくく、長い shell 出力がリアルタイムで流れる。
- 使いどころ: Copilot CLI をエージェントとして常用し、手元とクラウドの両方で回す開発者。CI やサンドボックス環境でプロキシ CA を扱うチーム。
- 開発者にとっての価値: 設定・実行環境・MCP 周りの運用性が上がり、既存の Copilot CLI ワークフローにそのまま乗る。
- 注意点: 目玉の `copilot config` と Ctrl+E ピッカーは現状プレリリース（`v1.0.92` 系）の機能。安定運用は `v1.0.91` を基本に、先行機能を試す場合はプレリリースを明示的に入れる。
- 公式リンク: https://github.com/github/copilot-cli/releases
- 参考リンク: https://github.com/github/copilot-cli
- メモ: 変更内容は Releases の各タグのノートで確認できる。インストール手順は公式 README に従う。

#### 使用例

```bash
# バージョン確認
copilot --version

# 設定の一覧/設定（v1.0.92-4 以降）
copilot config list
copilot config set <key> <value>

# 会話を始める前に Ctrl+E でローカル⇄クラウドの実行環境を切り替え（v1.0.92-3 以降）
```

### 3. Pi / `v1.0.1`・`v1.0.2`（OSS の AI コーディングエージェント CLI）

- 種別: CLI / OSS（AI コーディングエージェント）
- 関連: その他（OSS / マルチプロバイダ / MCP）
- 公開・更新日: `v1.0.1`（2026-10-03）、`v1.0.2`（2026-10-04）
- 概要: Pi はターミナルで動く OSS の AI コーディングエージェント。40 以上のプロバイダのモデル選択、ファイル操作、bash/PowerShell 実行、TypeScript 拡張や MCP 連携を備える。`v1.0.1` で Nix flake によるインストール、プロジェクト単位の MCP サーバー上書き（`.pi/mcp.json`）、OAuth Client ID Metadata Document 認証、任意ツールのレンダラ登録を追加。`v1.0.2` で OpenAI 互換 API 向けに思考レベル別のサンプリング設定（`models.json` の `samplingParamsByThinkingLevel`）を追加した。
- 何が便利か: Nix で固定バージョンを再現性よく導入でき、リポジトリごとに MCP サーバー構成を上書きできる。モデルの思考の深さに応じてサンプリング（temperature 等）を変えられる。
- 使いどころ: Claude Code / Codex / Copilot CLI 以外の選択肢を探している人。Nix 環境でツールをピン留めしたい、プロジェクト別に MCP を切り替えたい開発者。
- 開発者にとっての価値: マルチプロバイダ・OSS で、設定の粒度（プロジェクト別 MCP、思考レベル別サンプリング）が細かく、ローカル中心の運用にも組み込みやすい。
- 注意点: まだ `v1.0.x` で変化が速い。公式では管理インストーラ（pi.dev）が推奨される一方、Nix/npm でも導入できる。安定性は自分の環境で要検証。
- 公式リンク: https://github.com/earendil-works/pi/releases
- 参考リンク: https://github.com/earendil-works/pi
- メモ: Nix flake の `stable` を指すと安定版を取得できる。

#### 使用例

```bash
# Nix flake で安定版を実行 / インストール（v1.0.1 以降）
nix run github:earendil-works/pi/stable
nix profile add github:earendil-works/pi/stable
```
