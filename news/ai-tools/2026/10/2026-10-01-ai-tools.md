- **OpenAI DevDay 2026（9/29 開催）** で開発者向けの新プリミティブが一気に発表。**Apps SDK**（ChatGPT 上で動くアプリの作成・審査提出）、**Agents API**（computer use と Codex 由来のマルチエージェント／ツール検索／コンテキスト圧縮を自前アプリに載せる）、**Decisions API**（有限の選択肢からの分類・ルーティング・承認判断に特化した軽量 API）、**Codex Cloud**（設定済みの再利用可能なクラウド開発環境）などが公開された。既定モデルは **GPT-6.1 Sol** に更新。公式まとめは https://openai.com/index/devday-2026/ 。

## 今日の注目

### 1. OpenAI Codex CLI / `0.159.0`〜`0.159.2`

- 種別: CLI / OSS
- 関連: OpenAI / Codex / GPT-6.1 Sol
- 公開・更新日: 2026-09-29（`0.159.2` まで。翌 9/30 に `0.161.0-alpha` 系）
- 概要: ターミナルで動く OpenAI のエージェント的コーディング CLI の新リリース群。`0.159.0` で **モデルが応答している最中にユーザー入力で方向づけできる `instant_interrupt`（opt-in の input steering）**、新しいセッション開始時のウェルカム画面、Mermaid 図レンダリングの改善などを追加。`0.159.1` で **既定モデルを GPT-6.1 Sol** に更新（bundled / Amazon Bedrock Mantle / Runtime の各カタログ）、`0.159.2` は Windows でバックグラウンドプロセス起動時にコンソールウィンドウが点滅する不具合を修正。
- 何が便利か: 生成の途中で「その方向ではなく先にテストを直して」といった軌道修正を、応答を止めずに差し込めるのが実務的。既定モデルが GPT-6.1 Sol になり、モデル選択なしでも新しい既定で動く。
- 使いどころ: 長めのエージェント的タスク（リファクタや一括修正）で、走りながら指示を上書きしたいとき。CI やスクリプトから呼ぶ既存の Codex ワークフローの単純なバージョン更新にも。
- 開発者にとっての価値: 「投げて待つ」だけでなく「走行中に操縦する」使い方ができ、無駄な打ち切り・やり直しを減らせる。model picker やカタログ側の既定更新なので、設定変更なしで恩恵を受けやすい。
- 注意点: `instant_interrupt` は opt-in。`0.161.0-alpha` はプレリリースなので本番は安定版（`0.159.2`）を推奨。既定モデル変更でコスト/挙動が変わるため、重要ワークフローは切り替え後に一度検証を。
- 公式リンク: https://github.com/openai/codex/releases
- 参考リンク: https://openai.com/index/devday-2026/
- メモ: 9/25 記事で扱った `rust-v0.156.1`（GPT-6 Sol/Luna を picker 追加）からの続きで、GPT-6.1 Sol が既定に昇格した点が新しい。

#### 使用例

```bash
# 更新（インストール方法に応じて）
npm i -g @openai/codex     # npm 経由の場合
# または Homebrew
brew upgrade codex

# バージョン確認
codex --version            # 0.159.2 になっていること

# 起動（既定モデルが GPT-6.1 Sol）
codex
```

### 2. Claude Code / `v2.1.285`・`v2.1.286`

- 種別: CLI / 拡張機能
- 関連: Anthropic / Claude / Claude Code
- 公開・更新日: 2026-09-29（`v2.1.285`）・2026-09-30（`v2.1.286`）
- 概要: `v2.1.285` は **`claude --desktop` でデスクトップアプリを開くコマンド**、Web Fetch ツールを無効化する **`CLAUDE_CODE_DISABLE_WEB_FETCH` 環境変数**、API プロバイダーを制限する管理設定 **`allowedProviders`**、プラグイン設定の閲覧・値管理などを追加。`v2.1.286` は **権限プロンプトが重なったときに件数（"2 of 5"）を表示**、フルスクリーンのリストで「N more」行のマウス操作対応、クラウド認証失効時のログインブラウザ多重起動の修正、`--resume`/`--continue` が並列ツール呼び出し後にターンを落とす不具合の修正、キャッシュ書き込みの課金メーター価格修正などを含む。
- 何が便利か: `CLAUDE_CODE_DISABLE_WEB_FETCH` と `allowedProviders` は、**組織ポリシーやオフライン/機密環境での挙動を管理側で締められる**のが実務的。権限プロンプトの件数表示で、まとめて許可を求められたときの見通しが良くなる。
- 使いどころ: 会社支給環境でネットワーク/プロバイダーを制限したいチーム管理、デスクトップアプリと CLI を行き来する日常運用、並列サブエージェントを多用するセッションの安定化。
- 開発者にとっての価値: セキュリティ/ガバナンス系の管理設定が増え、個人利用から組織導入まで運用しやすくなった。細かなクラッシュ/セッション不具合の修正も日々の安定性に効く。
- 注意点: `allowedProviders` などは管理設定（managed settings）側の項目で、適用スコープに注意。バージョンは頻繁に更新されるため、`claude update` で追従を。
- 公式リンク: https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- 参考リンク: https://docs.claude.com/en/docs/claude-code/overview
- メモ: 9/29 記事で扱った `v2.1.284`（既定 Sonnet を 5.5 に更新・ドル金額表示）からの続き。

#### 使用例

```bash
# 更新
claude update

# デスクトップアプリを開く
claude --desktop

# Web Fetch を無効化して起動（機密/オフライン環境向け）
CLAUDE_CODE_DISABLE_WEB_FETCH=1 claude
```

### 3. OpenAI Apps SDK（DevDay 2026）

- 種別: SDK / API
- 関連: OpenAI / ChatGPT
- 公開・更新日: 2026-09-29
- 概要: **ChatGPT の中で動くアプリを、どの開発者でも作れるようにする SDK**。DevDay 2026 で提供が示され、2026 年内に **審査つきの提出（submission）** を開放予定。承認されたアプリはディレクトリに載り、ユーザーが発見・利用できる。
- 何が便利か: 自前の UI/バックエンドを ChatGPT の会話フローの中に差し込める。既存サービスを「ChatGPT から直接呼べるアプリ」として配布する導線ができる。
- 使いどころ: 社内ツールや SaaS を ChatGPT のインターフェース経由で提供したい、対話の中で自社データ/操作を扱わせたい、といった配布・組み込み用途。
- 開発者にとっての価値: 1.2B 週間ユーザー（OpenAI 公表）という規模のユーザーベースへ、アプリという形で到達できる**新しい配布チャネル**。
- 注意点: 一般提出の開放は「2026 年内」とされ、時期・審査基準は要確認。公表数値（ユーザー規模等）はベンダー発表のため裏取り前提で扱う。
- 公式リンク: https://openai.com/index/devday-2026/

### 4. OpenAI Agents API（DevDay 2026）

- 種別: API
- 関連: OpenAI / Codex / Agents
- 公開・更新日: 2026-09-29
- 概要: 自前アプリからエージェントを構築するための API。**computer use（ソフトウェアを操作してタスクを完了させるエージェント）** に対応し、**Codex 由来のマルチエージェント、ツール検索、ツール呼び出し、コンテキスト圧縮（context compaction）** をアプリに持ち込める。あわせて最大 300 tok/s を謳う高速推論ティア **Ultrafast**（Codex で最大 8 倍、API で最大 6 倍高速）も発表。
- 何が便利か: エージェントの土台（複数エージェントの協調、必要なツールの探索、長い履歴の圧縮）を自前で作り込まずに使える。computer use で GUI 操作を含む自動化まで射程に入る。
- 使いどころ: ブラウザ/デスクトップ操作を含む業務自動化、社内ツールをまたぐエージェント、長時間・多ステップのワークフロー構築。
- 開発者にとっての価値: Codex で培われたエージェント機能を API 化して再利用できるため、独自エージェント基盤の実装コストを下げられる。Ultrafast で対話・エージェントの体感速度を上げられる。
- 注意点: computer use は操作権限の設計・サンドボックス化が前提。Ultrafast はプレミアムティアで価格に注意。速度倍率はベンダー公表値。
- 公式リンク: https://openai.com/index/devday-2026/
- 参考リンク: https://platform.openai.com/docs

### 5. OpenAI Decisions API（DevDay 2026）

- 種別: API
- 関連: OpenAI
- 公開・更新日: 2026-09-29
- 概要: **「有限の許可された答えの中から 1 つを選ぶ」判断に特化した軽量 API**。分類、リクエストのルーティング、ワークフローの承認ステップ、エージェントが次に取る行動の決定などを、狭く定義した判断として扱える。
- 何が便利か: 自由生成ではなく**選択肢を限定した決定**を安定して返させられる。プロンプトで無理やり JSON/enum を守らせるより、目的に合ったプリミティブで実装できる。
- 使いどころ: 問い合わせのカテゴリ分け、承認/却下の一次判定、エージェントの分岐（次アクション選択）、ルールベースを LLM 判断で置き換えたい箇所。
- 開発者にとっての価値: 出力が有限集合に収まるため**後段処理が壊れにくく、評価・監視もしやすい**。分類/ルーティング系のワークフローに素直に組み込める。
- 注意点: 発表直後で仕様・価格・提供範囲は要確認。判断根拠の説明性が必要な用途では別途ログ/検証を設計する。
- 公式リンク: https://openai.com/index/devday-2026/
- 参考リンク: https://platform.openai.com/docs

### 6. Codex Cloud（DevDay 2026）

- 種別: Web サービス / クラウド開発環境
- 関連: OpenAI / Codex
- 公開・更新日: 2026-09-29
- 概要: Codex をクラウドへ拡張し、**リポジトリ・依存関係・ツール・権限をあらかじめ構成した再利用可能な開発環境**を作れるようにするもの。タスクを**スマホで開始し、ブラウザやデスクトップで継続**でき、ラップトップを開きっぱなしにしなくてよい、とされる。
- 何が便利か: 「環境構築済みのサンドボックスにタスクを投げる」運用ができ、端末やネットワークをまたいで作業を引き継げる。
- 使いどころ: 複数マシン/外出先を行き来する開発、レビュー待ちや長時間ジョブをクラウドに預ける運用、環境差異による "手元では動く問題" の低減。
- 開発者にとっての価値: 環境定義を共有・再利用できるため、チームでの再現性とオンボーディングが改善しやすい。
- 注意点: クラウド実行に伴うコスト・データ取り扱い・権限設計は要確認。提供範囲/プランは公式で確認を。
- 公式リンク: https://openai.com/index/devday-2026/
- 参考リンク: https://developers.openai.com/codex
