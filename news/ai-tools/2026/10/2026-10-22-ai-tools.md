### 1. Claude Code / `v2.1.306`

- 種別: CLI
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-10-21（JST 2026-10-22 時点で最新）
- 概要: クラウドセッションおよび MCP まわりの実運用バグを潰したメンテナンスリリース。直前の `v2.1.305`（サンドボックスの `allowNestedUserNamespaces` 追加、ゲートウェイでの tool search 失敗時リトライ、`/effort`・`/autocompact` の大文字小文字／`[1m]` タグ不一致修正など）に続く。
- 何が便利か: クラウドセッションで `claude -p`（ワンショット実行）が環境変数なしでも認証エラーにならず動く。MCP サーバーを多数登録した環境で、APIエラーが「prompt is too long」にすり替わって無駄なコンパクションが走る問題が解消。
- 使いどころ: CI やスケジュール実行で `claude -p` を叩く自動化、多数の MCP サーバーを常用するエージェント構成。
- 開発者にとっての価値: 非対話の自動実行とMCP多用構成という、壊れると気づきにくい箇所の信頼性改善。
- 注意点: `v2.1.305` の `sandbox.allowNestedUserNamespaces` はサンドボックスのファイル保護を回避しうる旨が CHANGELOG に明記されている。有効化は影響を理解した上で。
- 公式リンク: https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- 参考リンク: https://github.com/anthropics/claude-code/releases
- メモ: npm の `@anthropic-ai/claude-code` から更新可能。

#### 使用例

```bash
# 更新して非対話ワンショット実行を確認
npm install -g @anthropic-ai/claude-code
claude -p "この差分の要点を3行で"
```

### 2. GitHub Copilot CLI / `v1.0.102`（安定版）

- 種別: CLI
- 関連: GitHub Copilot
- 公開・更新日: 2026-10-21
- 概要: プロンプトモード強化とサブエージェントの承認まわりを中心とした安定版。`v1.0.102-0 / -1` のプレリリースを経て安定化。
- 何が便利か: `-p` やパイプ入力のプロンプトモードがマネージドな Auto モデル選択を使うように。サブエージェントがカスタム／MCP ツールの承認を尊重し、重複する許可プロンプトが減る。プラグインマーケットプレイスが git サブディレクトリ指定に対応し、プロバイダ過負荷で切れた応答はバックオフ付きで再試行（プロバイダのメッセージとリクエストIDを表示）。
- 使いどころ: `cat spec.md \| copilot -p ...` のようなパイプ駆動の自動化、サブエージェントを多用するワークフロー、社内プラグイン配布。
- 開発者にとっての価値: 非対話実行とエージェント連携の摩擦（モデル選択・承認の重複）が減り、スクリプトに組み込みやすくなる。
- 注意点: サンドボックスのネットワークが `NO_PROXY` / `ALL_PROXY` を尊重するようになったため、プロキシ環境では挙動を再確認。
- 公式リンク: https://github.com/github/copilot-cli/releases/tag/v1.0.102
- 参考リンク: https://github.com/github/copilot-cli/releases
- メモ: 前日時点の安定版は `v1.0.101`。

#### 使用例

```bash
# パイプでプロンプトモード（Auto モデル選択）
cat CHANGES.md | copilot -p "変更点をレビュー観点で指摘して"
```

### 3. Ollama / `v0.40.8`（＋ `v0.40.7`）

- 種別: OSS / ローカルLLMランタイム（＋モデル追加）
- 関連: ローカルLLM / Recursive（Flint）/ Perplexity（pplx-decider）
- 公開・更新日: `v0.40.8` 2026-10-21 / `v0.40.7` 2026-10-18
- 概要: `v0.40.8` が 40B MoE コーディングモデル **Flint**（Recursive 製、トークンあたりアクティブ約 2.5B、262K コンテキスト）を追加。`v0.40.7` は Perplexity の 27B 判断モデル **pplx-decider** 追加に加え、OpenAI 互換 Responses の thinking 有無混在やツール呼び出し順序の修正、`ollama show` が renderer / parser / chat template を表示するように。
- 何が便利か: ローカルで動く大きめのコーディング特化 MoE を 1 コマンドで試せる。Responses 互換 API のストリーミングでクライアント側ツール呼び出しが reasoning と前後する不具合が解消。
- 使いどころ: ローカルでのコード補完・生成の検証、OpenAI 互換エンドポイント経由でのツール呼び出しを含むエージェント検証。
- 開発者にとっての価値: クラウドに出せないコードをローカルモデルで扱う選択肢が増える。`ollama show` でテンプレート構成が見えるのはプロンプト調整に有用。
- 注意点: Flint は現時点で macOS のみサポート（他 GPU 対応は後続リリース予定と告知）。40B 級のため相応のメモリが必要。
- 公式リンク: https://github.com/ollama/ollama/releases/tag/v0.40.8
- 参考リンク: https://github.com/ollama/ollama/releases/tag/v0.40.7
- メモ: 前回カバーは `v0.40.6`（10/19 付記事）。

#### 使用例

```bash
# 新しいコーディングモデル Flint をローカルで実行（macOS）
ollama run flint
```
