# 2026-10-03 AI Tools News

## 今日の要点

- **Claude Code が `v2.1.287`（10/1）で「Claude Mods」を追加**。JavaScript / TypeScript で書き、Claude Code 自身の中で動くプラグインで、ツール呼び出し・プロンプト送信・UI 描画などの**イベントハンドラとして深い挙動を拡張**できる。既定で有効。ただし **mod はサンドボックス化されておらず、環境変数や設定ファイル（API キーを含む）を読める**点が公式ドキュメントに明記されており、導入時は提供元の信頼性を要確認。
- **Claude Code `v2.1.288`** では、Ctrl+C 中断後に下書きを復元する **prompt recovery**、`/code-review` の **`--max-findings`**、**Ctrl+F のセッション検索**、クラウドセッションに **GitHub CLI を同梱**、応答途中の API タイムアウトからの部分継続、"Prompt is too long" の**自動コンパクション**など、日常運用の安定性と効率に効く改善が入った。
- **OpenAI Codex CLI `0.160.0`（10/1）** が安定版として公開。エージェントのコマンドセンターで**古いタスクを "Show more" で遡れる**、プロジェクト外でも**ワークスペース既定でセッション開始**、再接続後のメッセージ重複キューイング修正、X11 端末の middle-click ペースト、Windows サンドボックスの PowerShell フォールバック修復などを含む。

## 今日の注目

### 1. Claude Code / `v2.1.287`（Claude Mods）

- 種別: CLI / 拡張機能（プラグイン基盤）
- 関連: Anthropic / Claude / Claude Code
- 公開・更新日: 2026-10-01（npm 公開 16:59 UTC ＝ 10/02 01:59 JST）
- 概要: **Claude Mods** を追加。mod は **JavaScript / TypeScript で書くプラグイン**で、Claude Code 本体の中で実行される。「ツール呼び出し」「プロンプト送信」「インターフェースの一部が描画されるとき」などの**イベントが起きたときに呼ばれるハンドラ**から構成され、ハンドラは**イベントを観測・変更・乗っ取り**できる。mods は **v2.1.287 以降が必要で、既定で有効**。
- 何が便利か: フックやスラッシュコマンドより**一段深い挙動の改変**ができ、ツール実行やプロンプト・UI に介入する独自ワークフロー（独自のガード、整形、ロギング、UI 追加など）をコードで表現できる。
- 使いどころ: チーム独自のポリシー適用（特定コマンドの確認を差し込む等）、プロンプト/出力の自動整形、社内ツールとの連携 UI、イベント駆動の自動化。
- 開発者にとっての価値: プラグイン機構が「設定で切り替える」から「挙動そのものを書き換える」段階に進み、Claude Code を自社フローに合わせて深くカスタマイズできる。
- 注意点: **mod はサンドボックス化されていない**。公式ドキュメントは mod が**環境変数や設定ファイル（そこに置いた API キーを含む）を読める**と明記している。**信頼できる提供元の mod のみを使い**、第三者製は中身を確認すること。既定で有効なので、不要なら無効化の検討を。
- 公式リンク: https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- 参考リンク: https://docs.claude.com/en/docs/claude-code/overview
- メモ: 10/01 記事で扱った `v2.1.286`（権限プロンプト件数表示）からの続き。プラグイン → 「mods」への拡張が今回の目玉。

#### 使用例

```bash
# 更新して版数を確認（v2.1.287 以降で mods が有効）
claude update
claude --version

# 既定で有効。必要に応じて設定で mods を確認/管理
# （未知の第三者製 mod は中身を確認してから使う）
```

### 2. Claude Code / `v2.1.288`（prompt recovery・`/code-review --max-findings`・Ctrl+F 検索）

- 種別: CLI / 拡張機能
- 関連: Anthropic / Claude / Claude Code
- 公開・更新日: 2026-10-02（`v2.1.287` に続く更新）
- 概要: `v2.1.288` は実用改善が中心。**Ctrl+C で中断したときに下書きを復元する prompt recovery**、`/code-review` に**件数を制御する `--max-findings`**、**Ctrl+F でのセッション検索**と Alt+↑/↓ のグループ移動、**クラウドセッションに GitHub CLI を同梱**（未導入環境向け）、**応答途中で API がタイムアウトしても部分応答から継続**、**"Prompt is too long" を自動コンパクションで解消**、フルスクリーンのテキスト選択を mod から扱う `$.ui.selection()`、Bedrock/Mantle のモデル切替やクラウドセッションのモデル保持の修正などを含む。
- 何が便利か: 誤 Ctrl+C でプロンプトを失わない、長いセッションが「長すぎ」で止まりにくい、コードレビューの出力量を調整できる、過去セッションを検索で素早く辿れる——いずれも**毎日の操作で効く**改善。
- 使いどころ: 長時間・大規模なセッション運用、`/code-review` をCIやレビュー補助に組み込む場面、クラウド/リモート環境での GitHub 操作。
- 開発者にとっての価値: 中断復帰・自動コンパクション・タイムアウト継続といった**失敗からの回復**が強化され、エージェント運用の取りこぼし・やり直しが減る。
- 注意点: バージョンは高頻度で更新されるため `claude update` で追従を。`$.ui.selection()` は mods 向け API。
- 公式リンク: https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- 参考リンク: https://docs.claude.com/en/docs/claude-code/overview
- メモ: `v2.1.287` の Claude Mods を前提に、mod 向け UI API（テキスト選択）も拡張されている。

#### 使用例

```bash
# 更新
claude update

# コードレビューの指摘件数を絞る/広げる
claude   # 対話内で: /code-review --max-findings 5

# セッション内検索は Ctrl+F、グループ移動は Alt+↑/↓
```

### 3. OpenAI Codex CLI / `0.160.0`

- 種別: CLI / OSS
- 関連: OpenAI / Codex
- 公開・更新日: 2026-10-01
- 概要: ターミナルで動く OpenAI のエージェント的コーディング CLI の安定版。エージェントの**コマンドセンターで古いタスクをキーボード操作可能な "Show more" で遡れる**、**プロジェクト外でもワークスペース既定でセッションを開始**できる、**再接続後のメッセージ重複キューイングの修正**、ターミナル UI がサーバープロバイダー/冗長度設定を保持、X11 端末向けの **middle-click ペースト**、Guardian レビューが過去のユーザー指示を取得できる拡張、Windows サンドボックスの PowerShell フォールバックと権限修復などを含む。
- 何が便利か: 過去タスクの振り返りと再接続時の挙動が安定し、プロジェクト外のディレクトリでも気軽に起動できる。端末設定の保持で再起動後の使い勝手が揃う。
- 使いどころ: 複数タスクを行き来するエージェント運用、ネットワーク不安定時の再接続を伴う長時間作業、プロジェクト未設定のディレクトリでの単発作業。
- 開発者にとっての価値: 「投げたタスクの管理」と「切断からの復帰」という運用面が堅くなり、日々のエージェント的コーディングの信頼性が上がる。
- 注意点: 同時期に `0.162.0-alpha` 系のプレリリースも出ているが、本番は安定版（`0.160.0`）を推奨。
- 公式リンク: https://github.com/openai/codex/releases
- 参考リンク: https://developers.openai.com/codex
- メモ: 10/01 記事で扱った `0.159.x`（`instant_interrupt`・既定を GPT-6.1 Sol に）からの続きで、今回はタスク管理と再接続・プラットフォーム周りの実運用改善が中心。

#### 使用例

```bash
# 更新
brew upgrade codex          # または npm i -g @openai/codex

# バージョン確認
codex --version             # 0.160.0

# プロジェクト外のディレクトリでも起動（ワークスペース既定）
codex
```

### 4. GitHub Copilot / Computer use（デスクトップアプリ操作、public preview）

- 種別: 機能（エージェント / computer use）
- 関連: GitHub Copilot
- 公開・更新日: 2026-10-02（GitHub の Pierce Boggan 氏が公表、public preview）
- 概要: GitHub Copilot に **computer use が追加**され、**API を持たないアプリでもデスクトップ操作で自動化**できるようになった、と公表された（macOS / Windows の public preview）。アクセシビリティ上のコンテンツと画面の視覚コンテキストから操作を組み立て、**バックグラウンドで動作し、ユーザーのマウス・キーボード・フォーカス中のウィンドウを奪わない**とされる。経費処理・出張予約・エンドツーエンドテストの高速化などが用途例として挙げられている。
- 何が便利か: API のない社内ツールやレガシー GUI も**操作自動化の対象**にでき、E2E テストや定型業務の自動化を Copilot のエージェントから回せる。
- 使いどころ: GUI しかない業務アプリの操作自動化、E2E テストの補助、繰り返しのデスクトップ操作の委譲。
- 開発者にとっての価値: コード生成に加え「画面操作の自動化」まで射程に入り、API 化されていない領域の自動化コストを下げられる可能性がある。
- 注意点: **public preview** であり、対象 OS・対象プラン・権限/セキュリティ設計は要確認。本項目は **GitHub の製品責任者（Pierce Boggan 氏）による 2026-10-02 の公表**と複数の二次報道に基づく。GitHub 公式チェンジログ（github.blog）は本セッションのネットワーク制限で直接取得できなかったため、利用前に公式ドキュメント/チェンジログで最新情報を確認すること。
- 公式リンク: https://docs.github.com/en/copilot/concepts/agents/github-copilot-app
- 参考リンク: https://github.blog/changelog/label/copilot
