## 今日の注目

### 1. goose / `v1.57.0`

- 種別: CLI / デスクトップ（OSS エージェント）
- 関連: Block / goose / MCP
- 公開・更新日: 2026-10-28（GitHub Releases, Latest。前安定版 `v1.56.0` は 10-23）
- 概要: ローカル実行のオープンソース AI エージェント goose の安定版。allowlist が HTTPS を必須化しリダイレクトを検証（ポリシー違反はブロック）、呼び出し側が独自のセッション ID を指定できるようになった。
- 何が便利か: OpenRouter のバリアント接尾辞（`:free` / `:nitro`）をベースモデルに正しくマッピング、Claude モデルで要約済み thinking を要求、スケジュール実行がレシピ設定を使うよう修正。音声 WebSocket がシステム信頼ストアを利用。
- 使いどころ: 手元で動かす自律エージェント、レシピ（recipe）＋スケジュール実行による定型自動化、MCP ツール連携。
- 開発者にとっての価値: セキュリティ（allowlist 強化・信頼ストア利用）とマルチプロバイダ運用の安定性が上がり、エージェントに作業を任せやすい。MCP SDK を 1.30.0→1.32.0 に更新。
- 注意点: desktop が fork 後にエージェントを一度だけ起動するよう修正するなど挙動変更あり。cargo-deny 対応で `jsonwebtoken` 依存を削除、zstd を 0.14.3 に更新。
- 公式リンク: https://github.com/block/goose/releases/tag/v1.57.0
- 参考リンク: https://github.com/block/goose/releases
- メモ: 過去記事では `v1.45`/`v1.46`（8月）まで。本項は新規の `v1.57.0`。

#### 使用例

```bash
# 既存インストールを更新
goose update
goose --version

# 対話セッションを開始
goose session
```

### 2. OpenCode / `v2.2.0`

- 種別: CLI / デスクトップ / SDK（OSS エージェント）
- 関連: sst / OpenCode
- 公開・更新日: 2026-10-27（GitHub Releases。10-28 に追随パッチ `v1.19.5` 等）
- 概要: ターミナル/デスクトップ型 OSS コーディングエージェントのメジャー更新。デスクトップのプラグイン（作成・インストール・共有、実験的）、プラグイン/SDK への実験的な画像・意思決定（decision）生成 API、プロバイダ/モデル単位で設定できるプロンプトキャッシュ TTL を追加。
- 何が便利か: プラグインがシステムプロンプトを書き換えずにキー付きのセッション指示を追加/更新/削除できる（`ctx.session.instructions.entry`）。デスクトップに Focus/Pro レイアウトや新モデルピッカー、プラグイン管理画面を追加。
- 使いどころ: 自前プラグインで機能拡張したいチーム、キャッシュ TTL を調整してコストを詰めたいプロバイダ運用。
- 開発者にとっての価値: 拡張ポイントが増え、OSS として自組織向けに作り込みやすい。セッションメディア向けの実験的なコンテンツアドレス指定ブロブ保存なども追加。
- 注意点: 破壊的変更あり。`@opencode/ai` のルートが Promise API を公開し Effect API は `@opencode/ai/effect` へ移動（`@opencode/ai/promise` は削除）、OpenCode の GitHub Action は配信終了（ワークフローから除去が必要）、TUI プラグインは OpenTUI 0.7 以上が必須。
- 公式リンク: https://github.com/sst/opencode/releases/tag/v2.2.0
- 参考リンク: https://github.com/sst/opencode/releases
- メモ: 過去記事では `v1.18` 系まで。本項は新規のメジャー `v2.2.0`。

#### 使用例

```bash
# インストール / 更新（公式インストーラ）
curl -fsSL https://opencode.ai/install | bash
opencode
```

### 3. LiteLLM / `v1.109.0-dev.1`（開発版）

- 種別: OSS / LLM ゲートウェイ・プロキシ（dev スナップショット）
- 関連: LiteLLM / xAI / Vertex AI
- 公開・更新日: 2026-10-28（GitHub Releases, Pre-release）
- 概要: 多数の LLM プロバイダを 1 つの OpenAI 互換 API に束ねる LiteLLM の開発版スナップショット。新プロバイダとして xAI の X Search（Search API / WebSearch インターセプト）と OpenInfer に対応。
- 何が便利か: ストリーミング中に切断してもフォールバック先で続行する mid-stream fallback、外向きフェッチを無効化する `LITELLM_OFFLINE_MODE`、`model_info.pricing_provider` で別プロバイダのカタログ価格を適用。Vertex AI で Gemini 3.1 Flash の TTS（マルチスピーカー音声）対応、Admin UI にモデルハブ付きチャット UI・画像生成・利用メトリクス。
- 使いどころ: 複数 LLM を 1 本の API に集約するゲートウェイ運用、オフライン/エアギャップ環境、コスト計測。
- 開発者にとっての価値: プロバイダ切替・フォールバックをアプリ側コードを変えず吸収でき、障害時のストリーム継続で可用性が上がる。
- 注意点: 本リリースは **Pre-release（dev スナップショット）で本番非推奨**。「要対応」の仕様変更が多数（新しい Gemini 系で `drop_params: true` が必要、コスト計算が `max_input_tokens`/`max_output_tokens` 参照に変更、キーの `budget_duration`/`budget_id` 変更は管理者のみで owner/member は 403 など）。安定版を待つのが無難。
- 公式リンク: https://github.com/BerriAI/litellm/releases/tag/v1.109.0-dev.1
- 参考リンク: https://github.com/BerriAI/litellm/releases
- メモ: 2026-10-28 記事では 10-27 のバックポート（`v1.106.5` 等）を見送り。本項は新規の dev スナップショット（新プロバイダ・mid-stream fallback 等）。

#### 使用例

```bash
# 開発版スナップショットを試す場合のみ（本番は安定版を推奨）
pip install --pre "litellm==1.109.0.dev1"
```
