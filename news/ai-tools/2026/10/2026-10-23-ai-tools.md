# 2026-10-23 AI Tools News

## 今日の要点

- Claude Code `v2.1.307` / `v2.1.308` が公開。`v2.1.307` で Claude API コードを新しい API バージョンへ移行するコマンドが追加され、止められた／確認を求められたツール呼び出しごとに OpenTelemetry イベントを出すようになったほか、HTTP MCP の二重送信や「Autocompact is thrashing」エラーなど実運用バグを多数修正。`v2.1.308` は一般的なバグ修正。
- GitHub Copilot CLI `v1.0.103`（安定版）が公開。クラウドの応答が再接続後も全文を保持するようになり、レガシーの `--remote` / `--no-remote` フラグが廃止、dnx など dev-tool のサンドボックス権限の扱いが整理された。
- Vercel AI SDK `ai@7.0.150` / `ai@7.0.149` が公開。テキスト（またはテキストデルタ）から音声をストリーミングする実験的 `experimental_streamSpeech` が追加され、ツール承認は 1 ツール呼び出しにつき最初の応答だけを処理（重複・矛盾する承認での二重実行を防止）、完了シグナルなく終わるストリームに `interrupted` 終了理由を追加。6.x 系にも主要修正をバックポート。
- ローカル LLM 側は Ollama `v0.40.9`（10/22, プレリリース）が出たが内容は `llama.cpp` 更新のみで、安定版の最新は前日カバーの `v0.40.8`（Flint 追加）のまま。Gemini CLI・LiteLLM・Aider・Cline・Codex CLI に直近 24〜48 時間の安定版新リリースは確認できず。

## 今日の注目

### 1. Claude Code / `v2.1.307`（＋ `v2.1.308`）

- 種別: CLI
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-10-22（前日カバーの `v2.1.306` に続く最新 2 リリース）
- 概要: `v2.1.307` は新機能と MCP・観測性まわりの修正をまとめたリリース。`v2.1.308` は「一般的なバグ修正と信頼性改善」のメンテナンス版。
- 何が便利か: `v2.1.307` で、使っている Claude API コードを新しい API バージョンへ移行するコマンドが追加。権限ルール・オートモード・安全チェック・フック・サンドボックスがブロック／確認／差し戻ししたツール呼び出しごとに OpenTelemetry イベントが出るようになり、何が止められたかを監視・集計できる。HTTP MCP ツール呼び出しが接続切断時に二重送信される不具合を修正し、再試行は読み取り専用／冪等なツールに限定。`CLAUDE_CODE_DISABLE_1M_CONTEXT` 設定時に `[1m]` エイリアスで model-not-found になる問題や、macOS でキーチェーンロック中に MCP サーバーが誤って「要認証」と表示される問題も解消。
- 使いどころ: Claude API を直接叩くコードのバージョン移行、OpenTelemetry でツール実行ポリシーの効き具合を可視化する運用、多数の MCP サーバーを使うエージェント構成。
- 開発者にとっての価値: API 移行の手作業が減り、ツール呼び出しの「止まった理由」がテレメトリで追えるようになる。壊れると気づきにくい MCP／認証まわりの信頼性改善。
- 注意点: 自己ホストランナーのチェックアウトフックはデフォルトで 30 分でタイムアウトするようになった。長時間のセットアップがある場合は影響を確認。
- 公式リンク: https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- 参考リンク: https://github.com/anthropics/claude-code/releases
- メモ: npm の `@anthropic-ai/claude-code` から更新可能。前回カバーは `v2.1.306`（10/22 付記事）。

#### 使用例

```bash
# 更新して最新版を確認
npm install -g @anthropic-ai/claude-code
claude --version
```

### 2. GitHub Copilot CLI / `v1.0.103`（安定版）

- 種別: CLI
- 関連: GitHub Copilot
- 公開・更新日: 2026-10-22
- 概要: クラウドセッションの安定性とサンドボックス権限の扱いを中心にした安定版。プレリリース `v1.0.103-0` を経て安定化。
- 何が便利か: クラウドの応答が接続断から再接続したあとも全文を保持するようになり、長い出力が途中で欠けにくい。ACP セッションが保存済みサンドボックス設定とフラグを（再開時も含めて）尊重。`dnx` コマンドが dev-tool アクセス有効時に既存の .NET / NuGet サンドボックス権限を使え、Windows の `npm.cmd` などのシムにも npm と同じ権限が付与される。Gemini のツール呼び出しで nullable / enum フィールドが 400 スキーマ検証エラーになる問題を修正。1 リポジトリ内の複数 Git worktree 間でローカル MCP ツールのキャッシュを再利用。
- 使いどころ: クラウドセッションでの長い応答を扱う作業、.NET / dnx を含むサンドボックス実行、worktree を複数使う開発。
- 開発者にとっての価値: 再接続時の応答欠落やサンドボックス権限の取りこぼしといった摩擦が減り、クラウド／ローカル双方で実行の信頼性が上がる。
- 注意点: レガシーの `--remote` / `--no-remote` フラグが廃止され、リモート起動オプションはホスティング／接続フラグに整理された。スクリプトで旧フラグを使っている場合は要修正。
- 公式リンク: https://github.com/github/copilot-cli/releases/tag/v1.0.103
- 参考リンク: https://github.com/github/copilot-cli/releases
- メモ: 前回カバーの安定版は `v1.0.102`（10/22 付記事）。

#### 使用例

```bash
# 更新して最新版を確認
npm install -g @github/copilot
copilot --version
```

### 3. Vercel AI SDK / `ai@7.0.150`（＋ `ai@7.0.149`・6.x バックポート）

- 種別: OSS / TypeScript SDK
- 関連: Vercel AI SDK / OpenAI / Hugging Face
- 公開・更新日: 2026-10-22
- 概要: 音声ストリーミングの実験 API 追加と、ツール承認・終了理由まわりの堅牢性改善をまとめた複数リリース。主要修正は `ai@6.0.314` / `ai@6.0.313` / `ai@5.0.280` にもバックポート。
- 何が便利か: `experimental_streamSpeech` で、テキスト文字列やテキストデルタから音声をストリーミング生成できる（`ai/test` 向けにモックのストリーミング音声モデルも追加）。ツール承認は 1 ツール呼び出しにつき最初の応答だけを処理するようになり、重複・矛盾する承認で同じツールが二重実行されたり、実行と拒否が同時に走ったりしなくなった。完了シグナルなく終わるストリームに `interrupted` 終了理由が追加され、中断を明示的に扱える。Hugging Face Responses API で `toolChoice: 'none'` が効くよう修正。
- 使いどころ: 音声応答を返すアプリの試作、ツール承認フローを持つエージェントの堅牢化、ストリーム中断のハンドリング。
- 開発者にとっての価値: 承認の二重処理という見えにくいバグを塞ぎ、音声出力やストリーム中断の扱いといった実装しづらい部分を標準 API で扱えるようになる。
- 注意点: `interrupted` を公開の終了理由型に追加したことで型チェックが壊れうると告知されている。終了理由を網羅的に switch している箇所は更新が必要。実験 API（`experimental_` プレフィックス）は今後変更の可能性がある。
- 公式リンク: https://github.com/vercel/ai/releases/tag/ai%407.0.150
- 参考リンク: https://github.com/vercel/ai/releases
- メモ: 前回カバーは `ai@7.0.147` / `ai@7.0.146`（10/21 付記事）。

#### 使用例

```bash
# 最新版へ更新
npm install ai@latest
```
