# 2026-10-07 AI Tools News

## 今日の注目

### 1. Claude Code / `v2.1.290`・`v2.1.291`・`v2.1.292`

- 種別: CLI / 拡張機能
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-10-05〜10-06 頃（JST。公式 CHANGELOG 最新。`v2.1.289` までは 10-05 版記事で既報）
- 概要: `v2.1.289` 以降の連続更新。`v2.1.290` でサブエージェント差分用の `tool.check` フックへの `agentId`、Mod の `turn.step` 結果へのツール呼び出しメタデータ付き `serverToolUses`、組織の承認要件向け `ceiling` パラメータ、MCP サーバー起動時のリソース一覧チェック遅延による起動効率化、クラウドセッションの再起動後リカバリ改善を追加。`v2.1.291` はクラウドセッションで権限プロンプトの応答が落ちる回帰と、`2.1.288` 以降の終了時メッセージ消失を修正。`v2.1.292` はプラグイン導入時の `--marketplace <source>` フラグ（マーケットプレイス自動検出付き）、Agent ツールのサブエージェント実行レベルを指定する `effort`、リトライのバックオフを調整する `CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS`、Mod 向けの `prompt.autocomplete` イベントと `$.model.complete` のプロンプトキャッシュ対応（`cache: true`）を追加し、ファイルパス処理・権限バイパスのセキュリティ修正も入れた。
- 何が便利か: サブエージェントごとに実行の深さ（`effort`）を使い分けられ、プラグインをマーケットプレイス指定で入れられる。10-04 で入った Mods をさらに拡張でき（autocomplete 介入、モデル補完のキャッシュ）、過負荷時のリトライ間隔を環境変数で調整できる。クラウドセッションの権限プロンプト取りこぼしという踏みやすい回帰も解消。
- 使いどころ: Claude Code を常用し、サブエージェントやプラグイン/Mod、MCP を組み合わせて回しているチーム。クラウド/リモートセッションで権限フローを使う場合の安定化アップデートとして。
- 開発者にとっての価値: 新しい実行制御（`effort`）・配布（`--marketplace`）・拡張（Mod フック追加）と、権限/セキュリティ修正がまとまって入り、既存ワークフローにそのまま乗る。
- 注意点: Mod 関連のインターフェースは引き続き早期アクセスで、リリース間で変わり得る。セキュリティ修正を含むため、できるだけ早めに更新するのが無難。
- 公式リンク: https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- 参考リンク: https://code.claude.com/docs/en/overview
- メモ: 更新は `claude update`（または再インストール）後に `claude --version` で `2.1.292` 以上を確認。CHANGELOG はバージョンごとのエントリで日付が付かないため、公開日は直近のリリース間隔からの概算。

#### 使用例

```bash
# 更新してバージョン確認
claude update
claude --version   # 2.1.292 以上を確認

# プラグインをマーケットプレイス指定で導入（v2.1.292）
claude plugin install <plugin> --marketplace <source>
```

### 2. GitHub Copilot CLI / `v1.0.92`（安定版：`copilot config` と実行環境ピッカー）

- 種別: CLI
- 関連: GitHub Copilot
- 公開・更新日: 安定版 `v1.0.92`（2026-10-05 19:42 UTC / JST 10-06 早朝）。プレリリース `v1.0.93-0`〜`-2`（10-05〜10-06 UTC）。
- 概要: 10-05 版記事でプレリリース（`v1.0.92` 系）の機能として扱った `copilot config`（設定の list/read/set/remove）と、会話開始前にローカル実行とクラウド実行を切り替える環境ピッカーが、安定版 `v1.0.92` に正式に入った。あわせて MCP サーバーの認証情報更新と起動応答の改善、shell 出力ストリーミングとトークン使用量レポートの改善、MCP 接続のハング/OAuth 再認証の修正、サンドボックス shell の権限と Windows のファイル処理の修正、リモートセッション再開時の GitHub 認証復元などが入った。サポート対象外となった旧モデルはモデルピッカーと選択可能一覧から削除された。
- 何が便利か: 先行機能だった設定の CLI 管理と実行先の切替が安定版で使えるようになった。MCP まわりの認証・起動・接続の安定性も底上げされ、旧モデル整理でピッカーが見やすくなる。
- 使いどころ: Copilot CLI をエージェントとして常用し、手元とクラウドの両方で回す開発者。MCP を複数つないで運用するチームや、リモートセッションを使う場合。
- 開発者にとっての価値: 10-05 時点では「プレリリース限定」だった機能が安定版に降り、業務運用に乗せやすくなった。既存の Copilot CLI ワークフローにそのまま追加できる。
- 注意点: 旧モデルの削除により、特定モデルを明示指定していた設定は見直しが必要な場合がある。さらに先の機能はプレリリース（`v1.0.93` 系）側にある。
- 公式リンク: https://github.com/github/copilot-cli/releases
- 参考リンク: https://github.com/github/copilot-cli
- メモ: 変更内容は Releases の各タグのノートで確認できる。インストール手順は公式 README に従う。

#### 使用例

```bash
# バージョン確認（安定版 v1.0.92 を確認）
copilot --version

# 設定の一覧/設定（安定版で利用可能）
copilot config list
copilot config set <key> <value>

# 会話を始める前に環境ピッカーでローカル⇄クラウドの実行環境を切り替え
```

### 3. OpenAI Codex CLI / `v0.160.1`（安定版パッチ）

- 種別: CLI
- 関連: OpenAI / Codex
- 公開・更新日: 安定版 `0.160.1`（2026-10-05 18:29 UTC / JST 10-06 早朝）。プレリリース `0.162.0-alpha.17` ほか（10-06 UTC）が並行リリース中。
- 概要: `0.160.0`（10-04 版記事で既報）に続く安定版パッチ。リモート環境変数を明示設定した状態でリモート stdio MCP サーバーを起動する際に、`SYSTEMROOT`・`TEMP`・`TMP` を保持するよう修正。これにより Unix ホスト上でも Windows 実行側の起動時環境を引き継げるようになった。Windows リモート MCP 環境保持のバックポートを含む。
- 何が便利か: Windows 実行環境と組み合わせてリモート MCP サーバーを使う構成で、環境変数が落ちて起動に失敗する問題を回避できる。
- 使いどころ: Codex をリモート/クロスプラットフォーム（Unix ホストから Windows 実行）で動かし、stdio 経由の MCP サーバーを使う開発者。
- 開発者にとっての価値: 新機能というより運用修正。特定構成（Windows + リモート MCP）での安定性が上がる、該当者には効くピンポイント修正。
- 注意点: 内容は限定的で、該当構成でなければ影響は小さい。`0.162.0-alpha` 系はプリリリースのため業務利用は安定版を基本に。
- 公式リンク: https://github.com/openai/codex/releases
- 参考リンク: https://github.com/openai/codex
- メモ: 更新は `npm install -g @openai/codex`（または `brew upgrade codex`）後に `codex --version` で確認。

#### 使用例

```bash
# 更新してバージョン確認
npm install -g @openai/codex
codex --version   # 0.160.1 以上を確認
```
