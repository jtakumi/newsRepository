# 2026-10-10 AI Tools News

## 今日の要点

- Claude Code `v2.1.296` が公開。`Read` ツールの `allow_large`、サブエージェントの `autoCompactWindow`、ワークフロー専用モデル指定 `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` を追加し、Sonnet 5.5 のキャッシュ読み取り単価を $0.20→$0.10/M に引き下げ。
- ローカル LLM 関連で Ollama `v0.40.2`（安定版・Latest）が到着。初回起動時に旧ダウンロード済みモデルをバックグラウンドで自動アップグレードし、llama.cpp の性能・互換性を改善。`ollama launch claude` が全コンテキスト長を使うようになった。
- AI コーディングエージェント Cline が Oct 8 に SDK `v0.0.92` / Desktop `v0.0.45` / CLI `v3.0.70` を同時更新。推論オフ非対応モデルへの設定送信による 400 エラーを修正し、モデルカタログに Claude Haiku 5.5 を追加。CLI では `cline dashboard` → `cline hub dashboard` に改称（旧名はエイリアス）。

## 今日の注目

### 1. Claude Code / `v2.1.296`

- 種別: CLI / 拡張機能
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-10-08〜10-09 頃（JST。公式 CHANGELOG 最新。`v2.1.295` までは 10-09 版記事で既報）
- 概要: `v2.1.295` に続く定期更新。開発ワークフローに効く追加が複数。
- 何が便利か:
  - `Read` ツールに `allow_large` オプションを追加し、通常のサイズ上限を超えるテキストファイルを 1 回で読める。
  - サブエージェントの frontmatter と `--agents` 定義に `autoCompactWindow` を追加し、メイン会話より早く自動コンパクトできる。
  - `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` で、ワークフロー内の全エージェントを 1 モデルに揃えつつ、他のサブエージェントは各自のモデルを維持できる。
  - MCP ツール説明・MCP サーバー指示の既定上限を 2,048→4,096 文字に拡大。
  - `/cost`・ステータスライン・`--max-budget-usd`・SDK のコスト表示で、Sonnet 5.5 のキャッシュ読み取りを $0.10/M（従来 $0.20/M）に修正。
- 使いどころ: 大きめの設定ファイルやログを一括で読ませたいとき（`allow_large`）、長時間のサブエージェント処理でコンテキスト枯渇を避けたいとき（`autoCompactWindow`）、コスト見積もりを正確にしたいとき。
- 開発者にとっての価値: ツール単位・サブエージェント単位の細かな制御が増え、長尺タスクとコスト管理がやりやすくなる。
- 注意点: 529（overloaded）リトライの最大バックオフは `CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS` で調整可能。Edit/NotebookEdit は非 UTF-8 ファイル（Shift-JIS, GBK 等）の非 ASCII 文字置換を拒否するよう変更されたため、該当ファイルの編集挙動が変わる。
- 公式リンク: https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- 参考リンク: https://docs.claude.com/en/docs/claude-code
- メモ: 細かなバグ修正多数（managed settings のフック、プラグイン、Windows の PowerShell 権限など）。

#### 使用例

```bash
# 更新してバージョン確認
claude update
claude --version   # 2.1.296 を確認

# ワークフロー内の全エージェントを 1 モデルに固定
export CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL=claude-haiku-5-5
```

### 2. Ollama / `v0.40.2`

- 種別: CLI / OSS（ローカル LLM ランタイム）
- 関連: Ollama / ローカルLLM関連ツール
- 公開・更新日: 2026-10-08（GitHub Releases で「Latest」。`v0.40.1` は保守中心のため 10-09 版記事では本文見送り、`v0.40.2` は当時プレリリースだったが安定版に昇格）
- 概要: 初回起動時に、過去にダウンロード済みの古いモデルをバックグラウンドでアップグレードし、llama.cpp の性能と互換性を改善する更新。
- 何が便利か:
  - 旧モデルを手動で引き直さなくても、起動のたびに自動で最適化される（アップグレード後はディスク上にバックアップを保持。将来版で自動削除予定）。
  - `ollama list` が、アップグレード済みモデルの重複表示を解消。
  - `ollama launch claude` がモデルの全コンテキスト長を使うようになった。
- 使いどころ: 手元に複数のローカルモデルを溜めている環境で、性能・互換性を底上げしたいとき。CLI からローカルでエージェント実行を試すとき。
- 開発者にとっての価値: ローカル推論のパフォーマンスを、設定変更なしの「更新するだけ」で引き上げられる。オフライン・プライバシー重視の検証に向く。
- 注意点: アップグレード後はバックアップが残るためディスク使用量が一時的に増える。安定版 `v0.40.2` が Latest で、`v0.40.0`（MLX 既定化）など直近版の挙動変更も併せて確認を。
- 公式リンク: https://github.com/ollama/ollama/releases
- 参考リンク: https://github.com/ollama/ollama
- メモ: `v0.40.1` ではクラウド使用量/残高 API のサーバー側プロキシ、Windows 修正、CLI オンボーディングのアカウント手順削除なども入っている。

#### 使用例

```bash
# 更新後、インストール済みモデルの自動アップグレードは初回起動時に走る
ollama --version          # 0.40.2 を確認
ollama list               # 重複なしで一覧確認

# ローカルでエージェント起動（全コンテキスト長を使用）
ollama launch claude
```

### 5. Cline / SDK `v0.0.92`・Desktop `v0.0.45`・CLI `v3.0.70`

- 種別: 拡張機能 / Desktop / CLI / OSS（AI コーディングエージェント）
- 関連: Cline / AIコーディング・開発者ツール
- 公開・更新日: 2026-10-08（Desktop `v0.0.45` が「Latest」）。Cline は 10-07 版記事では本文見送りで、今回が実質初掲載。
- 概要: 3 つの配布形態を同時更新。推論オフ非対応モデルまわりの修正とカタログ刷新が中心。
- 何が便利か:
  - 推論を無効化できない OpenAI / Claude 系モデルへ「reasoning off」設定を送って 400 エラーになっていた問題を全形態で修正。
  - MCP サーバーやフックが早期終了した際のクラッシュを修正（stdio MCP クライアント / バックグラウンドサービス）。
  - モデルカタログを刷新し、Claude Haiku 5.5 を追加。既定モデルも複数プロバイダーで更新。
  - CLI: `cline mcp add` がウィザードを開いても `--header` の値を保持。`cline dashboard` は `cline hub dashboard` に改称（旧名は隠しエイリアスとして存続）。
  - SDK: AI SDK パッケージを 1 系統（`ai` 7.0.120）に統合。`@cline/core` から `parseMcpHeaders` をエクスポート。
- 使いどころ: VS Code 拡張・デスクトップ・CLI のいずれかで Cline を使っており、400 エラーや MCP 早期終了のクラッシュに遭遇していた場合。
- 開発者にとっての価値: MCP 連携の安定性が上がり、最新モデル（Haiku 5.5 等）をすぐ選べる。CLI のコマンド体系整理で自動化スクリプトも書きやすい。
- 注意点: CLI `v3.0.70` は破壊的変更あり。機能していなかったオプション（`cline history --page` や一部の `cline schedule` フラグ）が削除され、使用中のスクリプトは "unknown option" で失敗する。`cline schedule` の create/update/import は、結果を投稿できない配信設定を拒否するようになった。
- 公式リンク: https://github.com/cline/cline/releases
- 参考リンク: https://github.com/cline/cline
