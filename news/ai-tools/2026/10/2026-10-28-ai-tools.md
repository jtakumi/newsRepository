## 今日の注目

### 1. OpenAI Codex CLI / `0.165.0`

- 種別: CLI
- 関連: OpenAI / Codex
- 公開・更新日: 2026-10-27（GitHub Releases, Latest）
- 概要: ターミナル向けコーディングエージェント Codex CLI の安定版。Google Cloud Vertex AI を組み込みプロバイダとして追加し、`model_provider = "gcp"` で有効化できる。モデルカタログに GPT-6.1 Terra を追加。
- 何が便利か: 会話の途中で reasoning effort を変更する機能が対応モデルで既定有効になり、タスクの難易度に応じて推論の深さをその場で切り替えられる。新規プロファイルでは memory v2 が標準となり、外部エージェントのメモリ取り込みにも対応。
- 使いどころ: GCP（Vertex AI）上のモデルを社内ガバナンス下で使いたいチーム。重い設計タスクと軽い修正を同一セッションで行き来する開発フロー。
- 開発者にとっての価値: プロバイダ選択肢が増え、クラウド課金・認証を既存の GCP 基盤に寄せられる。effort のインライン切替で無駄なトークン消費を抑えやすい。
- 注意点: Vertex 連携は GCP 側の権限・課金設定が前提。`0.166.0-alpha` 系は同日公開のプレリリースで変更履歴なし、本番利用は安定版 `0.165.0` を推奨。
- 公式リンク: https://github.com/openai/codex/releases/tag/rust-v0.165.0
- 参考リンク: https://github.com/openai/codex/releases
- メモ: 直前の安定版 `0.164.0`（10/23, `/presets`・インライン引数）は 2026-10-25 版で既出。本項は新規の `0.165.0` を扱う。

#### 使用例

```bash
# インストール / 更新
npm install -g @openai/codex

# Vertex AI（GCP）をプロバイダとして使う場合は config に以下を設定
#   model_provider = "gcp"
# （GCP 側の認証・課金設定が前提）
```

### 2. Ollama / `v0.40.12`

- 種別: OSS / ローカルLLMランタイム
- 関連: Ollama / Liquid AI
- 公開・更新日: 2026-10-27（GitHub Releases, Latest）
- 概要: Liquid AI の LFM3 ファミリ（`lfm3`, `lfm3-vl`, `lfm3-audio`, `lfm3-omni`）と `d1` 決定モデル（2B 含む）に対応。Apple シリコンでは Gemma 4 / Flint / Laguna のプロンプト処理が高速化。MLX で DFlash2 ドラフトモデルによる投機的デコードに対応。
- 何が便利か: マルチモーダル（VL/Audio/Omni）まで含む軽量モデル群をローカルで動かせる。`ollama launch` が OpenCode v2 に対応し、Kimi CLI のツールのみのアシスタント応答の不具合も修正。
- 使いどころ: 手元のマシンで試す小〜中規模のローカル推論、オフライン検証、プライバシー重視のプロトタイピング。
- 開発者にとっての価値: クラウドに出せないコード・データの検証を無料でローカル完結でき、投機的デコードで生成速度も改善。
- 注意点: 公式が「lfm3 と d1 2b は本リリースでは Apple ハードウェア対応。Linux/Windows 対応は近日」と明記。非 macOS では一部モデルが未対応。
- 公式リンク: https://github.com/ollama/ollama/releases/tag/v0.40.12
- 参考リンク: https://github.com/ollama/ollama/releases
- メモ: 2026-10-25 版は `v0.40.11`（音声生成・d3）まで。本項は新規の `v0.40.12`（LFM3・d1）を扱う。

#### 使用例

```bash
# 本体を更新後、LFM3 をローカルで実行（当面 Apple シリコン向け）
ollama run lfm3
```

### 3. Claude Code / `v2.1.312`（＋ `v2.1.311`）

- 種別: CLI
- 関連: Anthropic / Claude Code
- 公開・更新日: 2026-10-27（`v2.1.312`） / 2026-10-26（`v2.1.311`）
- 概要: `v2.1.311` で標準コンテキストのセッションが 200K トークン超でも停止せず自動コンパクションして継続できるよう改善。`v2.1.312` では effort インジケータの挙動改善や、VS Code 拡張からサインイン後に組織ポリシー/管理設定が取得されない不具合の修正など。
- 何が便利か: 長い作業で「1M コンテキストにはクレジットが必要」で止まらず作業を続けられる。使用量上限のメッセージが「5-hour limit」と明示され分かりやすくなった。
- 使いどころ: 大きめのリポジトリを横断する長時間セッション、組織ポリシー配下での VS Code 併用。
- 開発者にとっての価値: セッション中断の頻度が下がり、長い調査・リファクタを分割せず進めやすい。プロンプト/エージェントフックは1セッションあたり同時24件に制限され、暴走を防ぐ。
- 注意点: `v2.1.311` で `ultrathink` が一部 5.5 系モデルと Fable 5.1 では xhigh effort で動作する挙動変更あり。`v2.1.307` で追加された `safety_event` OpenTelemetry イベントは `v2.1.312` で削除。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.312
- 参考リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.311
- メモ: 2026-10-25 版は `v2.1.310`/`309` まで。本項は新規の `v2.1.311`/`312` を扱う。

#### 使用例

```bash
# 更新して最新版を確認
claude update
claude --version
```

### 4. Gemini CLI / `v0.66.0`（安定版）

- 種別: CLI
- 関連: Google AI / Gemini CLI
- 公開・更新日: 2026-10-27（GitHub Releases, Latest）
- 概要: ターミナル UI を強化（同期出力、スピナーの分離描画、ビューポート更新時のスクロールバック保持、スクロール可能ツールコンテナの右端表示崩れ修正）。設定プレースホルダが `.env` 読み込み後に解決されるようになり、`keybindings.json` が `keys` 配列を受け付ける。
- 何が便利か: git 呼び出し時に対話型の認証/SSH プロンプトが無効化され、ユーザーレベルの `~/.gitconfig` がシェル/git 環境で保持される。MCP の OAuth フローでプライベートネットワークのエンドポイントにオプトインできる。
- 使いどころ: CI/非対話環境での git 操作を含む自動化、キーバインドを自分好みに整えたい日常利用。
- 開発者にとっての価値: 非対話実行で認証プロンプトに詰まる事故が減り、スクリプト化が安定する。
- 注意点: バナーで「Gemini 4 にはまだ最適化されていない」旨が表示される。`v0.67.0-preview.0` は同日のプレリリースで `models` コマンド（`--list-models`）を追加。
- 公式リンク: https://github.com/google-gemini/gemini-cli/releases/tag/v0.66.0
- 参考リンク: https://github.com/google-gemini/gemini-cli/releases
- メモ: 2026-10-22 版で扱ったのは `v0.66.0-preview.0`。本項は新規の安定版 `v0.66.0` を扱う。

#### 使用例

```bash

npm install -g @google/gemini-cli
gemini --version
```

### 5. GitHub Copilot CLI / `1.0.104`

- 種別: CLI
- 関連: GitHub Copilot
- 公開・更新日: 2026-10-27（GitHub Releases, Latest）
- 概要: マネージド「fusion」モデルが Auto で起動し fusionTier 設定を適用。対話型・SDK の Autopilot セッションが `COPILOT_TASK_WAIT_TIMEOUT_SECONDS` で止まらずバックグラウンドタスクを待ち続ける（`-p --autopilot` は従来どおりタイムアウトを尊重）。

- 使いどころ: 長時間のバックグラウンドビルド/テストを伴うエージェント作業、権限確認を自動化したい運用。
- 開発者にとっての価値: タイムアウトで作業が切れにくくなり、長いタスクを任せやすい。権限まわりの体験が安定。
- 注意点: `1.0.105-0` は同日のプレリリース（長コンテキストでの `/model` 選択修正）。本番は安定版 `1.0.104` を推奨。

### 6. Vercel AI SDK / `ai@7.0.155`

- 種別: OSS / SDK
- 関連: Vercel AI SDK
- 公開・更新日: 2026-10-27（GitHub Releases）
- 概要: `streamText` / `generateText` / `generateObject` / `streamObject` が、TypeScript の型で既に保証される入力（`ModelMessage` スキーマへのメッセージ検証）を実行時に再検証しないよう変更。履歴が長いほど増えていた検証コストを削減。
- 何が便利か: 整数範囲・非空コレクション・未知キー・非有限数など、型で表現できない制約は引き続き検証される。安全性を保ちつつ無駄な実行時チェックだけを除いた。
- 使いどころ: 長い会話履歴を毎リクエスト渡すチャット/エージェント実装での軽量化。
- 開発者にとっての価値: メッセージ数が多いリクエストでオーバーヘッドが減り、レスポンスが軽くなる。
- 注意点: 依存も更新（`@ai-sdk/provider-utils@5.0.70`, `@ai-sdk/gateway@4.0.128`）。6.x 系は同日 `ai@6.0.317`（依存更新のみ）。
- 公式リンク: https://github.com/vercel/ai/releases/tag/ai%407.0.155
- 参考リンク: https://github.com/vercel/ai/releases
- メモ: 2026-10-25 版は `ai@7.0.153` まで。本項は新規の `ai@7.0.155` を扱う。

#### 使用例

```bash
# 最新版へ更新
npm install ai@latest
```
