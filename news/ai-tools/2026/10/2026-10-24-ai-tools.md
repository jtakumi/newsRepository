### 1. Claude Code / `v2.1.309`

- 種別: CLI
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-10-22（UTC 深夜、JST では 10/23。前日カバーの `v2.1.308` に続く最新）
- 概要: サンドボックスと Bash 権限チェックのセキュリティ修正を中心に、エージェント間メッセージ配信・`/rewind`・VS Code・クラウドセッション・Claude Tag（Slack）まで広範な修正を含む大型リリース。
- 何が便利か: サンドボックス回避につながる穴を複数修正。macOS/Linux でサンドボックス化 Bash がコマンドごとにシェルの起動ファイルをサンドボックス外で実行していた問題、`denyWrite` の glob が symlink 経由の実パスに適用されない問題、サンドボックス化コマンドや自動承認された編集が `--mcp-config` で渡した MCP 設定ファイルを書き換えられた問題、`cd` を伴う複合コマンドが権限プロンプトを出さなかった問題などを解消。実用面では、他セッション／他エージェントから届いた未配信メッセージが ctrl+o で全文（配信待ちと明示）表示されるようになり、`/rewind` が `/code-review --fix`・subagent・シェルコマンド由来の変更を「変更なし」と誤表示する不具合も修正。巨大なネスト `CLAUDE.md` を読んだ後に繰り返しコンパクトされる問題も解消。
- 使いどころ: サンドボックスや権限ルールで実行を制御している運用、split-pane のエージェントチームや複数セッションでの協調作業、チェックポイント／`/rewind` を使った巻き戻し運用。
- 開発者にとっての価値: 権限・サンドボックスは壊れても気づきにくく、ここが固まることで無人運用やチーム作業の信頼性が上がる。未配信メッセージの可視化や巻き戻しの正確化は、日々のエージェント運用の取りこぼしを直接減らす。
- 注意点: `sed -i` は従来のファイル編集プレビュー扱いをやめ、通常の Bash プロンプトで記述どおり実行されるようになった（他の Bash 編集同様 `/rewind` の復元対象外）。`claude ultrareview` はワークスペースの信頼を要求するようになり、スクリプトでは `--trust-workspace` が必要。
- 公式リンク: https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- 参考リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.309
- メモ: npm の `@anthropic-ai/claude-code` から更新可能。前回カバーは `v2.1.307` / `v2.1.308`（10/23 付記事）。

#### 使用例

```bash
# 更新して最新版を確認
npm install -g @anthropic-ai/claude-code
claude --version
```

### 2. OpenAI Codex CLI / `v0.164.0`（安定版）

- 種別: CLI
- 関連: OpenAI / Codex
- 公開・更新日: 2026-10-23
- 概要: 再利用プロンプトやインライン引数など対話操作の改善と、エンタープライズ向けの認証・セキュリティ強化をまとめた安定版。前回安定版 `0.163.0`（10/15）以来の正式リリース。
- 何が便利か: よく使うプロンプトを番号付きの `/presets` スロットに保存して呼び出せるようになり、定型指示の使い回しが楽になる。`/model` と `/permissions` にインライン引数を渡せるため、モデルや権限をコマンド一発で切り替えられる。フルスクリーンのトランスクリプトで画像プレビューが表示され、エンタープライズ MCP 認証、リモート Bash/Zsh セッションの認証情報マスキング、Amazon Bedrock セットアップウィザードのデフォルト有効化も入った。バグ修正では、失敗したコンパクションが履歴に中途半端な要約を残さない、セッション再開でスレッド設定を復元、CLI の `-c`/`--config` オーバーライドを保持、などが挙がっている。
- 使いどころ: 定型プロンプトを多用する反復作業、モデル・権限をこまめに切り替える検証、Bedrock や社内 MCP を使うチーム導入。
- 開発者にとっての価値: `/presets` とインライン引数は日々の操作数を減らす地味だが効く改善。認証情報マスキングやエンタープライズ MCP 認証は、チーム・組織での安全な導入を後押しする。
- 注意点: 同日に `0.165.0-alpha.1` などアルファも出ているが、リリースノートの内容が記載されておらず本番利用には安定版 `0.164.0` を推奨。
- 公式リンク: https://github.com/openai/codex/releases/tag/rust-v0.164.0
- 参考リンク: https://github.com/openai/codex/releases
- メモ: 前回カバーの安定版は `0.163.0`（10/16 付記事）。`0.164.0-alpha` 系は 10/22 付記事で「ノート未記載」として見送られていた。

### 3. Ollama / `v0.40.10`（＋ `v0.40.9`）

- 種別: OSS / ローカル LLM ランタイム / モデル
- 関連: Ollama / ローカルLLM / NVIDIA
- 公開・更新日: 2026-10-23（`v0.40.10`）、2026-10-22（`v0.40.9`）
- 概要: 新モデル追加とローカル音声生成を中心にした 2 リリース。`v0.40.10` は Vision-Language モデル、`v0.40.9` は音声生成 API を追加。
- 何が便利か: `v0.40.10` で NVIDIA Nemotron 3.5 Bolt E4B を追加。チャット・画像理解・ツール利用に対応した小型の Vision-Language モデルで、128K コンテキストと投機的デコード用のドラフトモデルを備える。`v0.40.9` では Apple Silicon 上で Phonon による音声生成を追加し、`ollama run` がテキストやチャット応答を読み上げられるほか、OpenAI 互換の `/v1/audio/speech` エンドポイントを提供。分類・Yes/No・スコア付き選択肢に向く d3 系判定モデル（2B/4B/9B/27B）や、コーディングモデル Flint の Linux / Windows 対応も入った。ストリーミングの OpenAI Responses / Anthropic Messages で、生成失敗を黙って終了せずエラーとして報告するようになった。
- 使いどころ: ローカルでの画像つき対話・ツール呼び出しの検証、OpenAI 互換クライアントからのローカル TTS 試作、分類・判定タスクを軽量モデルでローカル処理したいケース。
- 開発者にとっての価値: 画像理解・ツール利用・音声生成までローカルかつ OpenAI 互換 API で試せる範囲が広がる。既存の OpenAI SDK コードのエンドポイントを差し替えるだけでローカル音声生成を試せるのは導入が容易。
- 注意点: Phonon の音声生成は現時点で Apple Silicon 限定。Flint は `v0.40.8` 時点で macOS のみだったが、本リリースで Linux / Windows に拡大（GPU サポート状況は要確認）。
- 公式リンク: https://github.com/ollama/ollama/releases/tag/v0.40.10
- 参考リンク: https://github.com/ollama/ollama/releases/tag/v0.40.9
- メモ: 10/23 付記事では `v0.40.9` を「llama.cpp 更新のみ」として見送っていたが、公式リリースノート上は音声生成・判定モデル追加など実用的な内容を含むため、本日あらためて採用。

#### 使用例

```bash
# 更新後、新しい Vision-Language モデルを試す
ollama run nemotron-3.5-bolt:e4b

# OpenAI 互換の音声生成エンドポイント（Apple Silicon）
curl http://localhost:11434/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{"model":"<speech-model>","input":"こんにちは"}' --output speech.wav
```
