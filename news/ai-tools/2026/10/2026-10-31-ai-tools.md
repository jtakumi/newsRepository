# 2026-10-31 AI Tools News

## 今日の要点

- OpenAI Codex CLI `0.166.0`（安定版）が公開。TUI にキーボード操作のトランスクリプト選択＋検索が入り、過去ログを単語/行/ページ単位でたどって検索できるように。`codex queue --resume` や `codex doctor --network-only` も追加。

## 今日の注目

### 1. OpenAI Codex CLI / `0.166.0`（安定版）

- 種別: CLI
- 関連: OpenAI / Codex
- 公開・更新日: 2026-10-29（GitHub Releases, Latest）
- 概要: ターミナル向けコーディングエージェント Codex CLI の安定版。TUI にキーボード駆動のトランスクリプト選択（単語/行/ページ移動）と統合検索、設定可能なショートカットを追加。GPT-6.1 Terra をバンドル/Vertex AI/Amazon Bedrock のモデルカタログに追加。
- 何が便利か: 長い対話ログをマウスに頼らず移動・検索でき、過去のやり取りの参照がしやすい。`codex queue --resume` でメッセージをキューした後にアンロード済みスレッドを再開でき、`codex doctor --network-only` でネットワーク/WebSocket 接続のみを切り分け診断できる。
- 使いどころ: 長時間セッションで過去の指示や出力を探して戻りたい場面。プロキシや社内ネットワーク配下で接続トラブルを切り分けたいとき。
- 開発者にとっての価値: ログ検索と接続診断が標準装備され、調査やデバッグの往復が減る。スレッドの再開/フォーク時に承認・権限設定や添付画像が保持されるため、作業の継続性が上がる。
- 注意点: 同期間（10/28〜10/29）の `0.166.0-alpha.4`〜`alpha.6` はプレリリースで変更履歴が未整備。本番は安定版 `0.166.0` を推奨。GPT-6.1 Terra の利用は各プロバイダ側の権限・課金設定が前提。
- 公式リンク: https://github.com/openai/codex/releases/tag/rust-v0.166.0
- 参考リンク: https://github.com/openai/codex/releases
- メモ: 2026-10-28 版は `0.165.0`（Vertex AI プロバイダ）まで。本項は新規の `0.166.0` を扱う。

#### 使用例

```bash
# インストール / 更新
npm install -g @openai/codex

# メッセージをキューしてから、アンロード済みスレッドを再開
codex queue --resume

# ネットワーク/WebSocket の接続だけを切り分けて診断
codex doctor --network-only
```

### 2. Claude Code / `v2.1.314`

- 種別: CLI
- 関連: Anthropic / Claude Code
- 公開・更新日: 2026-10-30（GitHub Releases, Latest）
- 概要: 新設定 `permissions.blockWritesOutsideWorkingDirectories` を追加。有効にすると Write / Edit / NotebookEdit が全パーミッションモードで作業ディレクトリ外のパスへの書き込みを拒否する。VS Code と Claude Desktop の Code タブにアイドル時コンパクションを追加。
- 何が便利か: 200K トークン超の会話を放置した場合に要約を作り、プロンプトキャッシュが切れていれば次のメッセージでその要約を使う。TLS のルート証明書がクロス署名で更新された際の `UNABLE_TO_GET_ISSUER_CERT` 失敗も修正。
- 使いどころ: エージェントに広いリポジトリを触らせつつ、リポジトリ外への誤書き込みを構造的に止めたい運用。長時間の調査セッションを VS Code で回す日常作業。
- 開発者にとっての価値: 書き込み範囲をディレクトリ単位でガードでき、自律実行時の事故リスクを下げられる。アイドル要約でセッション再開のコストが減る。
- 注意点: `claude -p` は起動失敗時に従来「終了コード 0・出力なし」だったのを、エラー表示＋終了コード 1 に変更。スクリプトで終了コードを判定している場合は挙動変化に注意。PreCompact フックの出力は各 10,000 文字に上限化された。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.314
- 参考リンク: https://github.com/anthropics/claude-code/releases
- メモ: 2026-10-28 版は `v2.1.311`/`312` まで。`v2.1.313` は公開ページに現れず、本項は新規の `v2.1.314` を扱う。

#### 使用例

```bash
# 更新して最新版を確認
claude update
claude --version

# settings.json 等で作業ディレクトリ外への書き込みを禁止する例
#   "permissions": { "blockWritesOutsideWorkingDirectories": true }
```

### 3. Ollama / `v0.40.13`

- 種別: OSS / ローカルLLMランタイム
- 関連: Ollama / Liquid AI
- 公開・更新日: 2026-10-28（GitHub Releases, Latest）
- 概要: Liquid AI の LFM3 系のうち `lfm3-audio` と `lfm3-omni` を含むモデルが、従来の Apple シリコン限定から Linux・Windows でも動作するようになった。
- 何が便利か: マルチモーダル（音声/omni）対応の軽量モデルを、macOS 以外の手元マシンでもローカルで実行できる。更新して `ollama run` するだけで試せる。
- 使いどころ: Linux サーバや Windows ワークステーションでのオフライン検証、プライバシー重視のプロトタイピング、クラウドに出せない音声/マルチモーダルデータの手元処理。
- 開発者にとっての価値: 対応プラットフォームが広がり、既存の非 macOS 環境でもローカルマルチモーダルを無料で検証できる。
- 注意点: v0.40.12（10/27）までは LFM3 の 2B や一部モデルが Apple ハードウェア限定だった。利用前に対象モデルのタグとサイズを確認すること。
- 公式リンク: https://github.com/ollama/ollama/releases/tag/v0.40.13
- 参考リンク: https://github.com/ollama/ollama/releases
- メモ: 2026-10-28 版は `v0.40.12`（LFM3・d1、当面 Apple シリコン向け）まで。本項は新規の `v0.40.13`（Linux/Windows 対応拡大）を扱う。

#### 使用例

```bash
# 本体を更新後、LFM3（音声/omni を含む）をローカルで実行
ollama run lfm3-audio
```

### 4. Vercel AI SDK / `ai@7.0.158`

- 種別: OSS / SDK
- 関連: Vercel AI SDK
- 公開・更新日: 2026-10-30（GitHub Releases）
- 概要: `Experimental_SandboxSession` に `stat` / `listDirectory` / `deleteFile` を追加。各メソッドの相対パスは `run` / `spawn` を開始したディレクトリ基準で解決されるようになった。just-bash / Vercel Sandbox 両アダプタが新メソッドを実装。
- 何が便利か: サンドボックス内でファイルの存在確認・一覧取得・削除がプログラムから扱えるようになり、エージェントのファイル操作を SDK レベルで組み立てやすい。配列先頭のマイナス記号で終わる途中 JSON の修復不具合も修正。
- 使いどころ: サンドボックス上でコードを生成・実行し、成果物を点検/整理するエージェント実装。
- 開発者にとっての価値: ファイルシステム操作の基本動作が揃い、サンドボックスを使うエージェントの実装が素直になる。
- 注意点: Sandbox は `Experimental_` 接頭辞のとおり実験的 API で、今後変更の可能性がある。just-bash アダプタはディレクトリへの書き込みをファイル置換ではなく拒否するよう変更された。依存も更新（`@ai-sdk/gateway@4.0.131` ほか）。6.x 系は同日 `ai@6.0.320`（依存更新のみ）。
- 公式リンク: https://github.com/vercel/ai/releases/tag/ai%407.0.158
- 参考リンク: https://github.com/vercel/ai/releases
- メモ: 2026-10-28 版は `ai@7.0.155` まで。本項は新規の `ai@7.0.158` を扱う。

#### 使用例

```bash
# 最新版へ更新
npm install ai@latest
```
