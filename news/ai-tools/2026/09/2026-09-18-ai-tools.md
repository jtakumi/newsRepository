- 種別: CLI（安定版）
- 関連: Anthropic / Claude / Claude Code / MCP
- 公開・更新日: 2026-09-15〜2026-09-17（v2.1.272=9/15、v2.1.273=9/15、v2.1.274=9/17）
- 概要: Claude Code の連続アップデート。`v2.1.274` は MCP まわりの不具合を集中的に修正し、Streamable HTTP の MCP ツール呼び出しが約5分でタイムアウトする問題、`http` として設定したがレガシー HTTP+SSE しか話さない MCP サーバーが接続できない問題、`list-changed` 通知で MCP のプロンプト/リソースが再取得されない問題、403 insufficient_scope の MCP ツール呼び出しが「サインイン期限切れ」と誤表示される問題を修正した。あわせてメモリ使用量が危険域に達したときに解放・再起動の手順を示す警告を追加し、非対話の初回ターンが MCP サーバー接続を待つ上限を制御する `CLAUDE_CODE_MCP_STARTUP_WAIT_MS`、OTel トレースの `claude_code.llm_request` スパンへの `effort` 属性、管理設定のソースを示す `claude_code.managed_settings_resolved` OTel イベントを追加。フック起動セッションがコンパクションせずに「Prompt is too long」で終了する問題や、コンパクション後にセッションを再開すると `/goal` が失われる問題も修正した。`v2.1.273` は LLM ゲートウェイ向けに `x-claude-code-request-class` / `x-claude-code-agent-type` などのヒントヘッダー（`CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` でオプトイン）、`claude --remote-control` / `/remote-control` で開始したセッションを Claude アプリからフォークする機能、`permissions.blockReadsOutsideWorkingDirectories` 下で Bash がプロンプトを飛ばす問題の修正などを含む。`v2.1.272` はバグ修正・信頼性改善が中心。
- 何が便利か: MCP サーバーを常用している環境で、長めのツール呼び出しがタイムアウトで落ちる・list-changed が反映されないといった実務で刺さる不具合が解消される。メモリ警告により長時間セッションでの突然の不調に事前対処しやすい。ゲートウェイ用ヒントヘッダーで、社内 LLM ゲートウェイ側のルーティング/計測がやりやすくなる。
- 使いどころ: 複数の MCP サーバー（HTTP/SSE 系を含む）を接続して日常的にコード作業する開発者。LLM ゲートウェイ経由で Claude Code を運用し、リクエスト種別やエージェント種別で分けて計測・制御したいチーム。長時間の大規模リポジトリ作業。
- 開発者にとっての価値: 追加の設定なしにアップデートするだけで MCP 接続の安定性が上がる。ゲートウェイ運用や OTel での可観測性を強化したい場合の足がかりも増えた。
- 注意点: ゲートウェイ用ヒントヘッダーは `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` を明示的に設定した場合のみ付与される（既定では送られない）。`CLAUDE_CODE_MCP_STARTUP_WAIT_MS` は非対話の初回ターンの待機上限を制御する環境変数。

### 3. Cline Desktop / v0.0.31（SSH リモートマシン対応・サブエージェントの並列実行）

- 種別: デスクトップアプリ / AI コーディングエージェント（安定版）
- 関連: Cline
- 公開・更新日: 2026-09-17
- 概要: Cline Desktop の更新。SSH 経由でリモートマシン上の作業に対応（`Cline can now work on a remote machine over SSH, with the app itself staying local`）。ホストは Settings → Remote で設定し、環境セレクタから選択。接続はリモートユーザーのホームディレクトリで開き、エージェントのツールと Git メタデータはホスト側で実行され、承認はローカルのデスクトップに戻る。SSH config のエイリアスに対応し、ホスト情報は `~/.cline/data/settings/remote-environments.json` にローカル保存。対応ホストは Linux x64/arm64。あわせて、同一ステップで生成したサブエージェントが逐次ではなく同時に実行されるようになり、実行時間が「合計」ではなく「最も遅いタスク」に律速される（ツールの順序依存は保持）。同日には VS Code 拡張版 `v4.1.19`（非対応モデルへの画像添付警告、Windows でワークスペース内の悪意ある実行ファイルの起動防止、リトライロジック改善など）も公開。

- 注意点: SSH リモート対応ホストは現時点で Linux x64/arm64。ホスト情報はローカルの `remote-environments.json` に保存される。並列化は同一ステップ内で生成されたサブエージェントが対象で、順序依存のツール実行は従来どおり直列。
- 公式リンク: https://github.com/cline/cline/releases/tag/desktop-v0.0.31

- 種別: OSS / LLM ゲートウェイ・プロキシ（安定版）
- 関連: LiteLLM / OpenAI
- 公開・更新日: 2026-09-15
