## 今日の注目

### 1. Claude Code / v2.1.275 / v2.1.276

- 種別: CLI
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: `v2.1.275` は 2026-09-17（UTC 20:20 / JST 09-18 05:20）、`v2.1.276` は 2026-09-18（UTC 01:39 / JST 10:39）
- 概要: `v2.1.275` の追加点: Claude apps ゲートウェイのサインインで、ゲートウェイが示すアカウントを確認してから認証情報を保存し `/status` にも表示、`otelHeadersHelper` が失敗したときの起動時警告、claude.ai アカウントで有効なスキルとプラグインの同期（`syncClaudeAiSkills: false`／`syncClaudeAiPlugins: false` で無効化）、`/plugin install <plugin> --marketplace <source>`。改善はキューへ入れたメッセージの表示、貼り付け・添付画像を権限プロンプトなしで開けるファイルとして保存、`__SYSTEM_PROMPT_DYNAMIC_BOUNDARY__` を含む `--system-prompt` のキャッシュ改善、Artifact ツールの公開／読み取り結果にだれが開けるかを表示。修正は、再開／圧縮後にメモリファイルの経過日数メモが変わりプロンプトキャッシュを外す問題、`--forward-subagent-text` が `context: fork` スキルのサブエージェントを取りこぼす問題、`claude plugin marketplace update` が取得失敗時にローカルコピーを削除する問題、URL に埋め込まれたパスワード／トークンがログに出る問題など。`2.1.275` には、ゲートウェイ／プロキシ経由で全リクエストが失敗する回帰があり、翌日の `2.1.276` で修正された。
- 何が便利か: send-now で、キューに溜めた指示を即座に割り込み送信できる。プラグインの URL に埋め込まれた認証情報が表示されなくなるなど、秘匿面の改善もある。
- 使いどころ: ゲートウェイ／プロキシ経由で利用している環境（`2.1.275` を飛ばして `2.1.276` 以降を使う）、複数のプラグインマーケットプレイスを使う環境。
- 開発者にとっての価値: `ANTHROPIC_BASE_URL` を使う環境は `2.1.275` を避け、`2.1.276` 以降へ更新すること。
- 注意点: `2.1.275` は `ANTHROPIC_BASE_URL` 環境で全リクエスト失敗（400）。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.275 / https://github.com/anthropics/claude-code/releases/tag/v2.1.276
- 参考リンク: https://code.claude.com/docs/en/changelog
- メモ: `syncClaudeAiSkills`／`syncClaudeAiPlugins` が既定で有効になる挙動に注意。
