### 2. Claude Code / v2.1.259（managedMcpServers・ヘッドレス用 --permission-prompts none・GitLab glab 対応）

- 種別: CLI（安定版）
- 関連: Anthropic / Claude Code / MCP / GitLab
- 公開・更新日: 2026-09-02 22:33 UTC（JST 2026-09-03 07:33）※ `v2.1.259`
- 概要: Anthropic のターミナル型コーディングエージェントの新安定版。前回扱った `v2.1.258`（起動回帰の修正のみ）に続く機能追加版。組織運用・ヘッドレス実行・GitLab 連携が中心。
- 何が便利か:
  - **`managedMcpServers`**: 組織が HTTP/SSE の MCP サーバを全ユーザーへ一括配布できる設定。個々の開発者が MCP を手で設定せずに、社内共通のツール群を配れる。
  - **`--permission-prompts none`**: 無人ホスト向けのヘッドレスモード。承認プロンプトは自動的に拒否される（勝手に承認せず、安全側で止まる）。CI やバッチ実行に。
  - **GitLab 対応**: `glab mr create/merge/close/reopen/note/update` を認識し、MR バッジを更新。GitLab を使うチームのワークフローに組み込みやすく。
  - **`claude plugin validate --json`**: プラグイン検証結果を機械可読な JSON で出力。CI での自動検証に。
  - **VS Code 拡張**: セッション一覧に Active クイックフィルタと状態フィルタ（Needs input / Working / Completed）を追加。
- 何が修正されたか:
  - 並行セッションが互いの `~/.claude.json` の変更を巻き戻す問題を修正。
  - Bash の `Read()` deny ルールがファイルオプション値・git コマンドを覆えていなかった問題を修正。
  - 拒否された thinking を含む会話が繰り返し拒否される問題、テレメトリ無効セッションで OAuth トークン更新時にプロンプトキャッシュが無効化される問題などを修正。
- 使いどころ:
  - 組織で **MCP サーバを標準配布**したいとき（`managedMcpServers`）。
  - CI/無人環境で **承認プロンプトを自動拒否して安全側に倒す**とき（`--permission-prompts none`）。
  - **GitLab** ベースのレビュー運用に Claude Code を組み込みたいとき。
- 開発者にとっての価値: `npm i -g @anthropic-ai/claude-code@2.1.259` で今日すぐ更新できる安定版。組織配布・ヘッドレス・GitLab という運用面の穴を埋める内容。
- 注意点: `--permission-prompts none` は「自動承認」ではなく「自動拒否」。承認が必要な操作は実行されずに止まる点に注意。`managedMcpServers` は組織側の設定が前提。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.259
- 参考リンク: https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- メモ: 前回採用（09-03）は `v2.1.258`。今回は機能追加版 `v2.1.259` を新規採用。

#### 使用例

```bash
# 安定版へ更新
npm i -g @anthropic-ai/claude-code@2.1.259
claude --version

# 無人ホストで承認プロンプトを自動拒否して実行
claude -p "run the test suite and summarize failures" --permission-prompts none
```
