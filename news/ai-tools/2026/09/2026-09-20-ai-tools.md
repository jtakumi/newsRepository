### 1. Claude Code / v2.1.277・v2.1.278（AGENTS.md サポート・サーバー側 auto 分類器）

- 種別: CLI（安定版）
- 関連: Anthropic / Claude / Claude Code
- 公開・更新日: 2026-09-18（v2.1.277）／2026-09-19（v2.1.278）
- 概要: `v2.1.277` で AGENTS.md サポートを追加。CLAUDE.md が存在しないプロジェクトでは Claude Code が `AGENTS.md` を代わりに読み込む（`in a project with no CLAUDE.md, Claude Code reads AGENTS.md instead`）。参照するファイルは `/config` の「Project instructions」で切り替え可能（Bedrock / Vertex / Foundry ではまだ非対応）。同バージョンでは auto モードも調整され、スキルやスラッシュコマンド内のインライン `!` シェルコマンドが分類器ではなくデフォルトモードの権限ルールに従うようになり、サブエージェントが呼び出し元へ返す内容は事後レビューではなく専用のハンドバック呼び出しとして安全分類器がレビューする方式に変わった。翌 `v2.1.278` では、Claude API / Enterprise ユーザーおよび Bedrock・Vertex・Foundry・ゲートウェイ経由の auto モード分類器がサーバー側実行を既定とし、分類器オーバーヘッド分の課金が発生しなくなった（`CLAUDE_CODE_AUTO_MODE_SERVER=0` でオプトアウト）。`/status` に `Auto mode server` 行が追加され、当該セッションの分類器がサーバー側で動くかを確認できる。なお `v2.1.276`（9/18）は 2.1.275 の回帰（プロキシ/ゲートウェイ利用時に全リクエストが `400 … Input tag 'advisor_20260301'` で失敗する不具合）の修正。
- 何が便利か: `AGENTS.md` は Codex など他のエージェント CLI でも採用が進む共通の指示ファイル。CLAUDE.md を別途用意しなくても、既存の `AGENTS.md` をそのままプロジェクト指示として使い回せる。auto モード分類器のサーバー側化で、追加のトークン課金を気にせず auto モードを常用しやすくなった。
- 使いどころ: 複数のコーディングエージェントを併用していて、指示ファイルを 1 本に集約したいリポジトリ。auto モードでレビュー付き実行を回しつつコストを抑えたいチーム運用。
- 開発者にとっての価値: エージェント横断で指示ファイルの二重管理を避けられ、リポジトリ側の設定を単純化できる。分類器課金の解消は auto モード常用時のコスト予測を立てやすくする。
- 注意点: AGENTS.md サポートは Bedrock / Vertex / Foundry では未対応。CLAUDE.md がある場合は従来どおり CLAUDE.md が優先される（AGENTS.md は CLAUDE.md 不在時の代替）。サーバー側分類器のデフォルト化は API / Enterprise とゲートウェイ系が対象で、挙動の詳細は公式ドキュメント参照。
- 公式リンク: https://code.claude.com/docs/en/changelog
- 参考リンク: https://code.claude.com/docs/en/auto-mode-classifier-billing
- メモ: 変更内容は公式 changelog で確認。過去の AI Tools News で扱った Claude Code は `v2.1.270`（9/12）までで、AGENTS.md サポートおよび 2.1.276〜2.1.278 はいずれも未掲載の新規。

#### 使用例

```bash
# Claude Code を最新化
npm install -g @anthropic-ai/claude-code@latest

# CLAUDE.md が無いプロジェクトなら AGENTS.md がそのまま読まれる
cat > AGENTS.md <<'EOF'
# Project instructions
- テストは `npm test` で実行する
- 破壊的変更を含む場合は必ず確認する
EOF

# セッション内で分類器がサーバー側で動くか確認
/status
```

### 2. OpenAI Codex / 0.155.0・0.155.1（音声会話・ライブ推論サマリ・タスク管理・Touch ID）

- 種別: CLI（安定版）
- 関連: OpenAI / Codex
- 公開・更新日: 2026-09-17（0.155.0）／2026-09-18（0.155.1）
- 概要: Codex CLI の安定版 `0.155.0` は複数の新機能を含む。ターミナル上の**実験的な音声会話**、TUI のステータス行に表示される**ライブ推論サマリ**、**タスクの管理機能（非表示・アーカイブ・削除）**、macOS 対応機で **Touch ID による MCP リクエストの確認**、デーモン更新スケジュールの設定、Amazon Bedrock 向けの AWS 資格情報管理の改善などが入った。直後のパッチ `0.155.1` は、新規ローカル TUI セッションで推論サマリを既定オフにし、推論サマリ非対応プロバイダーがリクエストを拒否する問題を修正した（`New local TUI sessions now leave reasoning summaries disabled by default, fixing request rejection by providers that do not support them`）。

- 開発者にとっての価値: 実行の可観測性（推論サマリ）とタスク整理、そして MCP 呼び出しのローカル認証まで CLI 側で揃い、日常のエージェント運用の使い勝手が上がる。安定版のパッチで非対応プロバイダー起因の失敗も潰れている。
- 注意点: 音声会話は実験的機能。推論サマリはプロバイダーによっては非対応で、0.155.1 で新規ローカルセッションは既定オフになった（必要なら明示的に有効化する想定）。Touch ID は対応 Mac のみ。`0.156.0-alpha.x`（9/18〜9/19）はアルファのプレリリースで、今日から安定して使う対象ではない。

- 種別: OSS / TypeScript SDK（安定版）
