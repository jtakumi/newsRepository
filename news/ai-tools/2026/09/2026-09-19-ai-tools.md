- 種別: CLI / エージェント開発ツール（安定版 + プレビュー）
- 関連: Google AI / Gemini / Gemini CLI
- 公開・更新日: 2026-09-15
- 概要: Gemini CLI のセキュリティ強化リリース。安定版 `v0.60.0` で MCP OAuth フローに RFC 9207 の issuer 識別（authorization response iss パラメータ）を強制し、ワークスペースのパス境界チェックとシンボリックリンク解決を強化、システム全体の設定パスに厳格な権限チェックを適用、NTFS 8.3 短縮名（SFN）パスの脆弱性を緩和した。プレビュー `v0.61.0-preview.0` は、ビルドファイルの改変を通じた間接プロンプトインジェクションと信頼できない入力の防止、ファイルシステム境界の強化とランタイム状態の分離、明示的にバージョン指定された Flash モデル ID の保持を含む。あわせて nightly 系列（v0.62.0-nightly、9/16〜9/18）では OAuth リフレッシュ時のリフレッシュトークン保持、PTY のファイルディスクリプタ後始末、MCP ツール呼び出しタイトルの構造化表示などが入っている。

- 開発者にとっての価値: 実行時の安全性が底上げされ、MCP・ワークスペース境界まわりの既知リスクに対処できる。安定版へ上げるだけで恩恵を受けられる。
- 注意点: 間接プロンプトインジェクション防止やランタイム状態分離は `v0.61.0-preview.0`（プレビュー）側の項目で、安定運用では preview の位置づけに留意。nightly は検証用で本番利用は非推奨。
