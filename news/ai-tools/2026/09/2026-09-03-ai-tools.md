### 1. Claude Code / v2.1.257・v2.1.258（Fable 5.1 既定化・auto モードの資格情報保護・作業ディレクトリ外読み取りの確認）

- 種別: CLI（安定版）
- 関連: Anthropic / Claude Code / Claude Fable 5.1
- 公開・更新日: 2026-09-01 17:53 UTC（JST 2026-09-02 02:53）= v2.1.257、2026-09-01 22:33 UTC（JST 2026-09-02 07:33）= v2.1.258
- 概要: Anthropic のターミナル型コーディングエージェント Claude Code の新安定版。前回この CLI を扱った 08-29（`v2.1.251`）以降、`v2.1.252` / `v2.1.257` を経て `v2.1.258` まで進んだ。`v2.1.257` が機能追加の本体で、`v2.1.258` は起動回帰の修正。
- 何が便利か:
  - **Fable 5.1 を追加しデフォルト Fable モデルに**: `claude-fable-5-1`。1M コンテキスト。`/model` で選択できる。
  - **auto モードの Containment Escape ルール**: クラウドメタデータ資格情報の取得、egress 回避、テナント越えアクセスを、環境が「想定内」と明示しない限り自動承認しない。CI/クラウド実行時の事故防止に効く。
  - **作業ディレクトリ外読み取りの確認**: auto モードで作業ディレクトリ外の最初のファイル読み取り前に一度確認し、`permissions.blockReadsOutsideWorkingDirectories` でそもそもブロックも可能。
  - **`CLAUDE_CODE_SUBAGENT_MODEL_FORCE`**: `CLAUDE_CODE_SUBAGENT_MODEL`（または主モデル）を全サブエージェントに強制適用し、個別指定を無視。マルチエージェント運用でモデルを揃えたいときに。
  - **時刻表示設定**: `timeFormat`（12h / 24h / 24h UTC / strftime）と `timeZone` を追加。
  - **`/effort s`**: 現在のセッションだけ effort を変更（`/model` と同様の挙動）。
  - **v2.1.258 の修正**: macOS 12（Monterey）で起動できない回帰（2.1.255 で混入）を修正、権限承認の再送後にリモート/スケジュールセッションが空メッセージで失敗する問題を修正。
- 使いどころ:
  - クラウド/CI で Claude Code を回すチームが、資格情報や作業範囲外読み取りを**既定で安全側に倒したい**とき。
  - サブエージェントを多用する運用で**モデルを一括固定**したいとき。
  - macOS 12 で起動できなくなっていた環境の**即時復旧**。
- 開発者にとっての価値: `npm i -g @anthropic-ai/claude-code@2.1.258` で今日すぐ更新できる安定版。特に Containment Escape と作業ディレクトリ外読み取りの確認は、自動化運用の安全既定として実務価値が高い。

### 2. Vercel AI SDK / ai@7.0.91（ストリーミング開始後のプロバイダエラーからの復旧: `streamRetries`）

- 種別: OSS ライブラリ（npm）
- 関連: Vercel AI SDK / エージェント / ストリーミング
- 公開・更新日: 2026-09-02 20:27 UTC（JST 2026-09-03 05:27）※ `ai@7.0.91`
- 概要: TypeScript 向け AI SDK のパッチ。`streamText` の**応答ストリーミングが始まった後**に受け取ったプロバイダエラーからの復旧を設定できるようになった。
- 何が便利か:
  - **`streamRetries`**: 従来のリトライは「呼び出し前」が中心で、いったんトークンが流れ始めた後に上流がエラーを返すと応答が途中で壊れがちだった。今回、ストリーミング開始後のエラーに対する**リトライ回数と、コールバックで復旧方針を指示するオプション**を追加。長い生成の途中切断・上流の一時エラーを吸収できる。
  - チャット UI やエージェントループで、**部分生成を無駄にせず**復旧に回せる。
- 使いどころ:
  - 長文生成・ツール連鎖で、**プロバイダ側の一時的な失敗が応答を壊す**のを防ぎたいとき。
  - ゲートウェイ/プロキシ経由で上流が不安定な本番のチャット/エージェント。
- 開発者にとっての価値: `npm i ai@7.0.91` で今日から。既存の `streamText` 呼び出しにオプションを足すだけで堅牢化でき、UX とコスト（部分生成の破棄削減）の両面に効く。
- 注意点: パッチ内の具体的なオプション名・シグネチャはリリース本文とドキュメントで確認すること。同日には依存更新のみの `ai@7.0.90` / `ai@6.0.275` / `ai@5.0.251` もある。
- 公式リンク: https://github.com/vercel/ai/releases/tag/ai%407.0.91
- 参考リンク: https://ai-sdk.dev/
- メモ: 前回採用（09-02）は `ai@7.0.89`（FilesV4 のファイル操作）。今回は別機能の `ai@7.0.91` を新規採用。

#### 使用例

```ts
import { streamText } from 'ai';

// ストリーミング開始後のプロバイダエラーからも復旧できるようにする
const result = streamText({
  model: /* provider model */,
  prompt: '...',
  // streamRetries: ストリーム開始後のエラーに対する復旧設定
  //   （回数・コールバックによる復旧指示。詳細はリリースノート/Docs 参照）
});
```
