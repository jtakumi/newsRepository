## 今日の注目

### 1. Claude Code / v2.1.274

- 種別: CLI
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-09-16（UTC 22:36 / JST 09-17 07:36）
- 概要: 追加点: メモリ使用量が危険なときの警告と対処手順、非対話の初回ターンが接続中 MCP サーバーを待つ時間を制限する `CLAUDE_CODE_MCP_STARTUP_WAIT_MS`（`0` で待たない）、`claude_code.llm_request` スパンへの `effort` 属性、managed 設定ソースとポリシーヘルパーの状態を出す OTel イベント（`OTEL_LOG_MANAGED_SETTINGS=1` で秘匿済み設定とダイジェストも）、全画面モードでの折りたたみ済みチームメイト／エージェントメッセージのクリック展開。改善は `--input-format stream-json` の起動（初回ターンが tool search で遅延される MCP サーバーを最大 2 秒待たなくなった）、Monitor ツールの通知（最終出力と終了が 1 通にまとまり、モデルのターンを 1 回節約）、Artifact ツールのエラー表示。修正は、`unexpected tool_use_id` の 400 を繰り返し再試行して固まる問題（破損トランスクリプトの自己修復、または `/rewind` のヒント付きで終了）、レガシー HTTP+SSE のみ対応の `http` 設定 MCP サーバーが 422 などで接続できない問題、Streamable HTTP の MCP ツール呼び出しが長いタイムアウト設定でも約 5 分で切れる問題、403 insufficient_scope が期限切れサインインと誤表示される問題など。
- 何が便利か: MCP まわりの接続・タイムアウト・エラー表示の取りこぼしが整理され、`/goal` などのフック駆動セッションが「Prompt is too long」で終わる問題も直る。OTel でマネージド設定の解決状況を追えるのは、組織管理側に役立つ。
- 使いどころ: MCP サーバーを多用するエージェント、長時間の `/goal`・フック駆動セッション、OpenTelemetry で可観測化している組織。
- 開発者にとっての価値: 長時間・無人セッションの落とし穴（tool_use_id エラーのループ、5 分タイムアウト、コンテキスト溢れ）を直接修正している。
- 注意点: `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` を `0` にすると初回ターンに MCP ツールが揃わない場合がある。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.274
- 参考リンク: https://code.claude.com/docs/en/changelog
- メモ: 同日付近の `v2.1.272`（09-14）は「Bug fixes and reliability improvements」のみのため割愛。

#### 使用例

```bash
npm install -g @anthropic-ai/claude-code@latest
claude --version

# 非対話で MCP 起動待ちを制限
CLAUDE_CODE_MCP_STARTUP_WAIT_MS=3000 claude -p "list available MCP tools"
```
