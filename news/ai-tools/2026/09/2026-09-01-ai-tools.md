  - **`WorkflowAgent` の署名付きツール承認（7 系 `ai@7.0.86`）**: `feat(ai): support signed tool approvals in WorkflowAgent`。ワークフロー型エージェントで**ツール実行承認を署名付きで検証**でき、破壊的操作を伴うツールの承認フローを改ざん耐性のある形で組める（`@ai-sdk/gateway@4.0.70` に更新）。前回 6 系で入った `ToolLoopAgent` のツール承認シークレットに続き、7 系のワークフローでも承認基盤が整った。

  - **`streamText` 終了コールバックでパース済み構造化出力を露出（6 系 `ai@6.0.273`）**: ストリーム完了時のコールバックで**パース済みの構造化出力を直接受け取れる**。ストリーミングしつつ最終的に型付き JSON を扱いたいケースが素直になる。

### 3. Claude Code / v2.1.252（劣化接続でのセッションハング修正・always allow 保存修正）

- 種別: CLI（AI コーディングエージェント／安定版）
- 関連: Claude / Anthropic / Claude Code
- 公開・更新日: 2026-08-31（JST 2026-09-01 頃）※ `v2.1.252`
- 概要: Anthropic 公式 CLI Claude Code の安定版で、Remote Control とパーミッション周りの信頼性を高める修正リリース。大きな機能追加（`PreModelSwitch` / `PostModelSwitch` フックなど）は前回 `v2.1.251`（08-28）で入っており、今回はその後の安定化。

  - **劣化接続時のセッションハング修正**: claude.ai への接続が劣化しているとき、**ツール完了後に Remote Control セッションが数分間停止する不具合を修正**。リモート/Web セッションの体感が改善。

  - **新規プロジェクトで許可（always allow）を使い始める**とき（設定が保存されないハマりを回避）。

- 開発者にとっての価値: 機能追加ではなく信頼性修正が中心だが、**Remote Control / Web セッションの日常運用を素直にする**実利ある更新。新規プロジェクトでのパーミッション保存修正は、セットアップ直後のつまずきを減らす。
- 注意点: 修正中心のリリースのため、新機能を目当てにするより**安定化目的の更新**として捉えるとよい。バージョンは継続的に更新されるため、`claude --version` で確認のこと。
