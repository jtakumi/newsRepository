### 1. Claude Code / v2.1.260・v2.1.261（フルスクリーン `/diff`・128K 出力上限・`/skill-doctor`）

- 種別: CLI（安定版）
- 関連: Anthropic / Claude Code
- 公開・更新日: 2026-09-03 23:48 UTC（JST 2026-09-04 08:48）= `v2.1.260`、2026-09-04 19:58 UTC（JST 2026-09-05 04:58）= `v2.1.261`
- 概要: Anthropic のターミナル型コーディングエージェントの新安定版 2 本。前回扱った `v2.1.259`（managedMcpServers / `--permission-prompts none`）以降の増分。差分表示・ヘッドレス運用・スキル管理・出力上限の調整が中心。
- 何が便利か:
  - **フルスクリーンの diff パネル（`/diff`）**: フルスクリーンモードで差分を専用パネルにトグル表示。変更の全体像をエディタを離れずに確認できる。
  - **`bashOutputMaxChars` / `taskOutputMaxChars`（最大 128K 文字）**: Bash 出力やサブエージェントのタスク出力を切り詰める上限を設定で調整可能。長大なログでコンテキストを圧迫しないよう制御できる。
  - **`/skill-doctor`**: 使われていないスキルと、それが消費するコンテキストコストを洗い出す。スキルを多数入れた環境で「効いていない/重いスキル」を棚卸しできる。
  - **`--append-subagent-system-prompt-file`**: 大きなサブエージェント用システムプロンプトをファイルから追記。長いプロンプトをコマンドラインに直書きせずに渡せる。
  - **ヘッドレスの `/reload-plugins`**: 無人セッションでプラグインを再読み込み。
  - **テキスト版 `/advisor`**: デスクトップ / Remote Control / ヘッドレスでもアドバイザーをテキスト形式で利用可能に。
  - **`/cost` にキャッシュミス推定原因**: プロンプトキャッシュのミス要因を `/cost`（および `/status`）から把握しやすく。
  - 修正系: 括弧付きの permission ルールが落ちる問題、Bash サンドボックスの誤自動承認、`blockReadsOutsideWorkingDirectories` がユーザーの git config を隠す問題、セッション途中でモデル切替がブロックされる問題、Claude Fable 5.1 のプロンプトキャッシュなどを修正。
- 使いどころ:
  - 大きめの変更をレビューする際に **`/diff` で差分を一望**したいとき。
  - スキルを多用していて **`/skill-doctor` でコンテキスト消費を最適化**したいとき。
  - CI / バッチで **出力上限を制御**して安定運用したいとき（`bashOutputMaxChars` など）。
- 開発者にとっての価値: `claude update`（または各配布経路）で今日すぐ更新できる。差分の可視化とスキル棚卸しは日常のレビュー・チューニングに直結し、128K の出力上限やヘッドレス改善は自動化・CI 用途に効く。
- 注意点: `--permission-prompts none` は前回 `v2.1.259` で追加済み。`/skill-doctor` は「未使用スキルの検出」が主眼で、自動削除ではない。バージョンは連続パッチのため、機能は 2 リリースにまたがる。
- 公式リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.261
- 参考リンク: https://github.com/anthropics/claude-code/releases/tag/v2.1.260 / https://docs.claude.com/en/docs/claude-code/overview
- メモ: 前回採用は `v2.1.259`。今回は `v2.1.260`（diff/advisor/reload-plugins）＋ `v2.1.261`（出力上限/skill-doctor/subagent prompt file）を新規採用。

#### 使用例

```bash
# 更新して差分パネルを使う
claude update
claude --version
# セッション内で:
#   /diff          … フルスクリーン差分パネルをトグル
#   /skill-doctor  … 未使用スキルとコンテキストコストを表示
```

### 2. Vercel AI SDK / ai@7.0.93（配列出力の minItems・maxItems 対応、ツールパートタイトル保持）

- 種別: OSS ライブラリ（npm）
- 関連: Vercel / AI SDK
- 公開・更新日: 2026-09-04 21:41 UTC（JST 2026-09-05 06:41）※ `ai@7.0.93`
- 概要: TypeScript 向け AI SDK の新パッチ。前回採用の `ai@7.0.92`（空 HTTP レスポンス体でのフォールバックエラー表面化）に続く、構造化出力とストリーミング/検証まわりの改善。
- 何が便利か:
  - **配列出力で `minItems` / `maxItems` に対応**: `Output`（構造化出力）で配列の要素数の下限・上限を指定できる。「必ず 3〜5 件の候補を返す」といった制約をスキーマで表現しやすくなる。
  - **UI メッセージ検証でツールパートのタイトルを保持**: `validateUIMessages` などでツール呼び出しパートのタイトルが失われない。UI 表示の一貫性が向上。
  - **メッセージ置換時に新しいメッセージ ID を生成**: メッセージを差し替えたときに ID を再生成し、重複・取り違えを防止。
  - **embedding レスポンスの検証**、**Node.js でのテキスト data URL デコード**、**abort signal 処理の改善**。
- 使いどころ:
  - `generateObject` / `streamObject` 系で **「N 件の配列を返させたい」構造化出力**を作るとき（`minItems`/`maxItems`）。
  - **チャット UI でツール呼び出しの表示**を安定させたいとき。
  - 埋め込み生成やストリーミングの**堅牢性**を上げたいとき。
- 開発者にとっての価値: `npm i ai@7.0.93` で今日すぐ更新できる。特に配列制約の対応は、LLM 出力を後段処理に安全に渡す「件数保証」の実装を簡潔にする。
- 注意点: パッチリリースのため破壊的変更はないが、`@ai-sdk/*` 関連パッケージ（`@ai-sdk/vue` など）も同時更新されている。v6 系（`ai@6.0.277`）・v5 系（`ai@5.0.253`）も同日更新あり。
- 公式リンク: https://github.com/vercel/ai/releases/tag/ai%407.0.93
- 参考リンク: https://ai-sdk.dev/docs / https://www.npmjs.com/package/ai
- メモ: 前回採用は `ai@7.0.92`。今回は `ai@7.0.93` を新規採用。

#### 使用例

```bash
npm i ai@7.0.93
```

```ts
// 配列出力に件数制約（minItems / maxItems）を付ける例
import { generateObject } from 'ai';
import { z } from 'zod';

const { object } = await generateObject({
  model,
  schema: z.object({
    ideas: z.array(z.string()).min(3).max(5), // minItems=3 / maxItems=5 が尊重される
  }),
  prompt: '新機能のアイデアを出して',
});
```
