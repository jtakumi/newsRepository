# 2026-09-30 AI Tools News

## 今日の要点

- OpenAI が **DevDay 2026（9/29・サンフランシスコ）** を開催し、20 件超の開発者向け発表を実施。中心は新モデル **GPT-6.1 Sol（API ID `gpt-6.1-sol`）** で、**GPT-6 Astra にほぼ匹敵する知能を「Astra の約 1/5 のトークン価格」で提供**し、API・Codex・ChatGPT Work に初日から投入された。
- Codex 周りが大きく更新。**Agents API が「コンピュータ操作（computer use）」に対応**し、Codex のマルチエージェント・ツール検索・ツール呼び出し・コンテキスト圧縮を自前アプリに組み込めるように。**Codex CLI は音声ステアリングと `/agents` ビュー**を追加し、複数タスクの委譲・追跡が可能に。
- **Codex Cloud** はノートを閉じていてもクラウド側でタスクを継続実行し、デバイス間でアクセス可能に。あわせて **ChatGPT デスクトップアプリの Code Review** がクラウド上で変更に自動で一次レビューを入れる体験を提供する。

## 今日の注目

### 1. GPT-6.1 Sol / `gpt-6.1-sol`

- 種別: モデル / API
- 関連: OpenAI / ChatGPT / Codex
- 公開・更新日: 2026-09-29（DevDay 2026）
- 概要: GPT-6 Sol の大型アップグレード。ベンダー説明では**エージェント的コーディング・コンピュータ操作・専門業務で GPT-6 Astra の知能にほぼ匹敵しつつ、Astra の約 1/5 のトークン価格**を実現。API・ChatGPT Work・Codex に初日から提供され（通常の Chat 面へは順次）、モデル ID `gpt-6.1-sol` で API から利用できる。
- 何が便利か: **標準 API 価格が入力 $2 / 出力 $10 per 1M、キャッシュ入力 $0.10 per 1M**（キャッシュ入力は標準入力比 95% 減、GPT-6 Sol のキャッシュ入力比でも約半額とされる）。高難度作業に近い品質を、上位 Astra より大幅に安い単価で回せる位置づけ。既存の OpenAI API 実装はモデル ID を差し替えるだけで載せ替え可能。
- 使いどころ: 日常のエージェント的コーディング、リファクタ、コードレビュー補助、コンピュータ操作を伴うエージェント処理など、**「Astra は高すぎるが Sol 世代の品質は欲しい」用途**のコスト最適化。Codex のバックエンドモデルとしても選択できる。
- 開発者にとっての価値: キャッシュ入力の値下げは、システムプロンプトや長いコンテキストを繰り返し送る RAG・エージェント構成で実効コストに効く。API・Codex・ChatGPT Work で同一モデルを使えるため、検証から本番までの導線が短い。
- 注意点: 「Astra にほぼ匹敵」「1/5 価格」はいずれもベンダー公表値のため、自分のワークロードで品質・コストを実測してから本番採用するのが安全。通常の ChatGPT Chat 面へは初日時点では未提供の面がある。
- 公式リンク: https://openai.com/index/introducing-gpt-6-1-sol/
- 参考リンク: https://www.unite.ai/openai-unveils-gpt-6-1-sol-at-devday-with-new-codex-and-chatgpt-tools/ , https://www.cnbc.com/2026/09/29/openai-devday-2026-live-updates.html
- メモ: 過去記事（09-14）で OpenAI SDK の Agents API 対応に触れたが、GPT-6.1 Sol・DevDay 2026 の発表は既存記事に未収載で新規。

#### 使用例

```bash
# Responses API でモデル ID を差し替えるだけ
curl https://api.openai.com/v1/responses \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-6.1-sol",
    "input": "Fix the failing test in this diff and explain the change."
  }'
```

### 2. Codex CLI 刷新（音声ステアリング / `/agents` ビュー）＋ Codex Cloud

- 種別: CLI / クラウドサービス
- 関連: OpenAI / Codex
- 公開・更新日: 2026-09-29（DevDay 2026）
- 概要: DevDay で Codex CLI が刷新され、**音声で作業を指示する「音声ステアリング」**と、**複数タスクを委譲・追跡する `/agents` ビュー**を追加。あわせて **Codex Cloud** が、ローカルのノート PC を閉じていてもクラウド側でタスクを継続実行し、複数デバイスからアクセスできるようになった。
- 何が便利か: `/agents` ビューでバックグラウンドの複数エージェントの状態を一画面で把握・委譲でき、長時間の並行作業が管理しやすい。Codex Cloud により、手元のマシンの稼働状態に縛られずにビルド・修正・調査などを走らせ続けられる。
- 使いどころ: 「大きめのリファクタをクラウドに投げて別作業に移る」「移動中に開始したタスクを別端末で確認する」といった、**非同期・並行のエージェント運用**。音声ステアリングは、手を動かしながら方針だけ口頭で微調整したい場面に向く。
- 開発者にとっての価値: エージェントを「都度プロンプトを打つ道具」から「委譲して回し続ける実行基盤」に寄せる更新で、CLI 単体の対話ループから複数タスク・複数デバイスのワークフローへ広げられる。
- 注意点: 音声ステアリングや Code Review の体験は対応クライアント（Codex CLI / ChatGPT デスクトップ）とプラン・地域に依存し得るため、自環境での提供状況を確認すること。クラウド実行はコード・データが OpenAI 側で処理される点を運用ポリシーと照らすこと。

### 3. Agents API がコンピュータ操作・マルチエージェントに対応

- 種別: API
- 関連: OpenAI / Codex
- 公開・更新日: 2026-09-29（DevDay 2026）
- 概要: OpenAI の **Agents API がコンピュータ操作（computer use）に対応**し、ソフトウェアを実際に操作してタスクを完遂するエージェントを構築できるように。あわせて **Codex のマルチエージェント機能・ツール検索・ツール呼び出し・コンテキスト圧縮（context compaction）** をアプリケーションに取り込めるようになった。
- 何が便利か: これまで Codex 内部で使われていたエージェント基盤（複数エージェントの協調、必要なツールの検索、長いやり取りのコンテキスト圧縮）を、自前プロダクトの API から直接呼び出せる。GUI 操作を伴う自動化も同じ API 上で組める。
- 使いどころ: 社内ツールの操作自動化、ブラウザ/デスクトップ操作を含むワークフロー、複数の専門エージェントを束ねる調査・処理パイプラインなど、**「1 プロンプト = 1 応答」を超える継続的エージェント**を自作したいケース。
- 開発者にとっての価値: コンテキスト圧縮とツール検索が API 側で提供されることで、長時間エージェントのトークン肥大・ツール選択の実装負荷を自作せずに済む。Codex と同じ設計思想の基盤を、自社アプリのバックエンドに転用できる。
- 注意点: computer use は操作対象環境への権限・サンドボックス設計が前提。誤操作・情報漏えいのリスクがあるため、権限最小化と監査ログを伴う運用が必須。料金・レート・提供リージョンは公式ドキュメントで要確認。
- 公式リンク: https://openai.com/index/devday-2026-recap/
- 参考リンク: https://www.cnbc.com/2026/09/29/openai-devday-2026-live-updates.html
- メモ: 「Agents API のコンピュータ操作対応」は DevDay 2026 の新規発表。09-14 記事の SDK 一行言及とは別内容。

### 4. ChatGPT デスクトップの Code Review（クラウドで自動一次レビュー）

- 種別: 拡張機能 / クラウドサービス
- 関連: OpenAI / Codex / ChatGPT
- 公開・更新日: 2026-09-29（DevDay 2026）
- 概要: ChatGPT デスクトップアプリに新しい **Code Review 体験**が追加され、変更内容に対してクラウド上で**自動の一次レビュー**を実行できる。Codex 刷新（音声ステアリング・`/agents`）と同時に発表された開発者向け機能群の一つ。
- 何が便利か: 人手レビュー前に、機械的な指摘や明らかな問題をクラウドで先に拾える。PR や差分をレビュー担当に回す前の「下読み」を自動化し、レビューの往復回数を減らせる可能性がある。
- 使いどころ: 個人開発での自己レビュー、チームでの一次スクリーニング、レビュー観点の抜け漏れチェックなど。既存の人手レビュー/CI を置き換えるのではなく、その前段に足す使い方が現実的。
- 開発者にとっての価値: デスクトップアプリ内で完結するため、別ツールを立てずにレビュー補助を試せる。Codex Cloud と組み合わせれば、変更生成→クラウドレビューまでを同じ導線で回せる。
- 注意点: 発表直後で提供範囲・対応プラットフォーム・料金が流動的。コードがクラウドで処理される前提のため、機密リポジトリでの利用は組織ポリシーを確認すること。自動レビューは補助であり、人手レビューや CI の代替にはしない。
